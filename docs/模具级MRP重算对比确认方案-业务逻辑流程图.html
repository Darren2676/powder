二、差异对比算法流程

flowchart TB START(["开始对比"]) --> INPUT["输入:
1. parentOrder（成品生产单）
2. mouldBomFlatten（模具BOM展平）
3. standardBomFlatten（标准BOM展平）
4. existingSemiOrders（现有预成型件生产单）"] INPUT --> B1["Step 1: 构建模具BOM预成型件映射
mouldSemiMap[material_number -> accumulated_quantity]"] B1 --> B2["Step 2: 构建标准BOM预成型件映射
standardSemiMap[material_number -> accumulated_quantity]"] B2 --> B3["Step 3: 构建现有预成型件生产单映射
existingMap[item_number -> order]"] B3 --> LOOP1{"遍历 mouldSemiMap"} LOOP1 --"还有未处理"--> C1{"existingMap 中存在?"} C1 --"否"--> C_NEW["diff_type = new_added
old_quantity = 0
new_quantity = netReq"] C1 --"是"--> C2{"数量差异 > 0.0001?"} C2 --"否"--> C_UNCHANGED["diff_type = unchanged
old_quantity = existing.planned_quantity
new_quantity = netReq"] C2 --"是"--> C_QTY["diff_type = quantity_changed
old_quantity = existing.planned_quantity
new_quantity = netReq"] C_NEW --> LOOP1 C_UNCHANGED --> LOOP1 C_QTY --> LOOP1 LOOP1 --"全部处理完"--> LOOP2{"遍历 existingMap"} LOOP2 --"还有未处理"--> C3{"mouldSemiMap 中存在?"} C3 --"是"--> LOOP2 C3 --"否"--> C4{"checkIfReplaced?
（标准BOM有但模具BOM无）"} C4 --"是"--> C_MAT["diff_type = material_changed
old_quantity = existing.planned_quantity
new_quantity = 0"] C4 --"否"--> C_REM["diff_type = removed
old_quantity = existing.planned_quantity
new_quantity = 0"] C_MAT --> LOOP2 C_REM --> LOOP2 LOOP2 --"全部处理完"--> RETURN["返回 comparison 数组"] RETURN --> END(["结束"])
核心公式：净需求 = ROUND(成品计划数量 × 累计用量比例, 4)
数量比较精度：Math.abs(oldQty - newQty) > 0.0001 视为变化

八、API 接口定义

接口1：预览模具级MRP重算差异

项目内容
方法POST
路径/api/production-orders/dispatch/mould-mrp-preview
请求体{ production_order_number, equipment_number, equipment_name, mould_number, production_date, schedule_id, ... }
响应{ success, data: { parentOrder, mouldBomNumber, standardBomNumber, comparison[], summary } }

接口2：确认执行模具级MRP重算

项目内容
方法POST
路径/api/production-orders/dispatch/mould-mrp-execute
请求体{ confirmed: true, dispatchItems[], comparisonData }
响应{ success, data: { dispatch, processTasks, materialPreparations, semiProductOrders, errors } }
