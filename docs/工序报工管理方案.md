# 工序报工管理方案

## 一、概述

### 1.1 业务背景
工序报工是MES系统中记录实际生产执行情况的核心环节。操作员在每道工序完成后，需要报告本次完成的数量、工时、操作人员、班次等信息。报工数据是计算产量、工时、效率、合格率的基础，也是回写工序任务完成数量的数据来源。

### 1.2 核心功能
- **逐工序报工**：针对每道工序任务，支持多次报工（分批完成）
- **数量管理**：记录合格数量、不合格数量，自动汇总已完成数量
- **工时记录**：记录每次报工的实际工时（开始/结束时间）
- **人员班次**：记录操作员、班组、班次信息
- **状态回写**：报工审批后自动回写工序任务的 completed_quantity 和 task_status
- **超额控制**：根据工序的 excess_reporting_ratio 控制超额报工
- **审批流程**：报工单参与统一审批流程（草稿→待审批→已审批）

### 1.3 上下游关系
```
生产单(production_order) → 工序任务(process_task) → 报工单(work_report)
                                                          ↓
                                                   回写 completed_quantity
                                                   更新 task_status
                                                   更新 actual_start/end_time
```

## 二、业务流程

### 2.1 报工流程

```
1. 选择要报工的工序任务（已审批 + 未完成/进行中）
   ↓
2. 填写报工信息：
   - 本次合格数量、不合格数量
   - 报工日期、班次
   - 操作员/班组
   - 实际开始时间、实际结束时间
   - 不合格原因（如有）
   ↓
3. 系统自动校验：
   - 累计报工数量 ≤ 计划数量 × (1 + 超额报工比例/100)
   - 工序任务必须为已审批状态
   ↓
4. 提交报工单 → 审批
   ↓
5. 审批通过后自动执行：
   - 回写 process_task.completed_quantity += 本次合格数量
   - 若为首次报工：更新 task_status → '进行中'，记录 actual_start_time
   - 若累计完成数量 ≥ 计划数量：更新 task_status → '已完成'，记录 actual_end_time
```

### 2.2 业务场景

#### 场景一：正常报工
- 工序任务计划数量1000件，操作员完成500件，报工500件
- 次日再完成500件，再报工500件
- 累计1000件=计划数量，工序任务自动变为"已完成"

#### 场景二：有不合格品
- 完成520件，其中合格500件，不合格20件
- 报工合格数量500，不合格数量20
- 仅合格数量累计到工序任务的 completed_quantity

#### 场景三：超额报工
- 计划1000件，超额报工比例10%
- 最大可报工合格数量 = 1000 × 1.1 = 1100件
- 超过1100件时系统拒绝

#### 场景四：多人轮班报工
- 早班操作员A报工300件
- 中班操作员B报工400件
- 晚班操作员C报工300件
- 同一工序任务可有多条报工记录

### 4.2 获取可报工的工序任务列表

**请求：**
```
GET /work-reports/tasks-for-report?search=xxx&page=1&limit=10
```

**筛选条件：**
- process_task.approval_status = '已审批'
- process_task.task_status IN ('未开始', '进行中')
- 即：已审批且未完成的工序任务

**返回数据增强：**
```json
{
  "process_task_number": "PT-20260319-001",
  "production_order_number": "P20260319001",
  "step_number": 10,
  "standard_process_name": "混炼",
  "item_number": "C100809",
  "item_name": "防尘罩组件",
  "planned_quantity": 8000,
  "completed_quantity": 3000,
  "remaining_quantity": 5000,
  "work_center_name": "混炼车间",
  "task_status": "进行中",
  "excess_reporting_ratio": "10",
  "max_reportable": 5800,
  "report_count": 2
}
```

其中：
- `remaining_quantity` = planned_quantity - completed_quantity
- `max_reportable` = planned_quantity × (1 + excess_reporting_ratio/100) - completed_quantity
- `report_count` = 该工序任务已有的报工单数量

### 4.3 创建报工单

**请求：**
```json
POST /work-reports
{
  "process_task_number": "PT-20260319-001",
  "qualified_quantity": 500,
  "unqualified_quantity": 20,
  "report_date": "2026/03/20",
  "schedules_id": "S001",
  "schedules_name": "早班",
  "group_number": "G001",
  "group_name": "A组",
  "operator_number": "E001",
  "operator_name": "张三",
  "actual_start_time": "2026/03/20 08:00",
  "actual_end_time": "2026/03/20 12:00",
  "unqualified_reason": "",
  "remark": ""
}
```

**后端校验逻辑：**
```
1. 验证 process_task_number 存在
2. 验证工序任务 approval_status = '已审批'
3. 验证工序任务 task_status IN ('未开始', '进行中')
4. 计算最大可报工量：
   max = planned_quantity × (1 + excess_reporting_ratio/100) - completed_quantity
5. 验证 qualified_quantity ≤ max
6. 自动计算 total_quantity = qualified_quantity + unqualified_quantity
7. 自动计算 cumulative_quantity = completed_quantity + qualified_quantity
8. 自动计算 actual_hours（若有开始结束时间）
9. 从工序任务冗余字段：production_order_number, step_number, item_*, work_center_*, planned_quantity
10. 生成编号 WR-YYYYMMDD-NNN
11. 插入数据库
```

### 4.4 审批通过后的回写逻辑

```
当报工单 approval_status 从 '待审批' 变为 '已审批' 时：

1. 获取报工单的 process_task_number 和 qualified_quantity
2. 更新工序任务：
   UPDATE process_task SET
     completed_quantity = completed_quantity + :qualified_quantity
   WHERE process_task_number = :taskNumber

3. 查询更新后的工序任务：
   - 若 completed_quantity > 0 且 task_status = '未开始'：
     UPDATE task_status = '进行中', actual_start_time = 报工单的 actual_start_time
   - 若 completed_quantity >= planned_quantity：
     UPDATE task_status = '已完成', actual_end_time = 报工单的 actual_end_time

4. 反审时逆向操作：
   completed_quantity = completed_quantity - :qualified_quantity
   重新评估 task_status
```

## 六、核心算法

### 6.1 报工数量校验

```javascript
function validateReportQuantity(task, qualifiedQty) {
  const excessRatio = parseFloat(task.excess_reporting_ratio) || 0;
  const maxAllowed = task.planned_quantity * (1 + excessRatio / 100);
  const maxReportable = maxAllowed - task.completed_quantity;
  
  if (qualifiedQty > maxReportable) {
    throw new Error(`合格数量不能超过 ${maxReportable}（计划${task.planned_quantity}，已完成${task.completed_quantity}，超额比例${excessRatio}%）`);
  }
  return true;
}
```

### 6.2 审批通过后回写

```javascript
async function onApproved(workReportNumber) {
  // 获取报工单
  const report = await getWorkReport(workReportNumber);
  const taskNumber = report.process_task_number;
  const qualifiedQty = report.qualified_quantity;
  
  // 回写工序任务完成数量
  await query(`
    UPDATE process_task SET
      completed_quantity = completed_quantity + :qty
    WHERE process_task_number = :taskNumber
  `, { qty: qualifiedQty, taskNumber });
  
  // 查询更新后的任务状态
  const task = await getProcessTask(taskNumber);
  
  if (task.task_status === '未开始' && task.completed_quantity > 0) {
    await query(`
      UPDATE process_task SET
        task_status = N'进行中',
        actual_start_time = :startTime
      WHERE process_task_number = :taskNumber
    `, { startTime: report.actual_start_time, taskNumber });
  }
  
  if (task.completed_quantity >= task.planned_quantity) {
    await query(`
      UPDATE process_task SET
        task_status = N'已完成',
        actual_end_time = :endTime
      WHERE process_task_number = :taskNumber
    `, { endTime: report.actual_end_time, taskNumber });
  }
}
```

### 6.3 反审逆向回写

```javascript
async function onReversed(workReportNumber) {
  const report = await getWorkReport(workReportNumber);
  const taskNumber = report.process_task_number;
  
  // 逆向扣减完成数量
  await query(`
    UPDATE process_task SET
      completed_quantity = CASE
        WHEN completed_quantity - :qty < 0 THEN 0
        ELSE completed_quantity - :qty
      END
    WHERE process_task_number = :taskNumber
  `, { qty: report.qualified_quantity, taskNumber });
  
  // 重新评估任务状态
  const task = await getProcessTask(taskNumber);
  
  if (task.completed_quantity <= 0) {
    await query(`
      UPDATE process_task SET task_status = N'未开始'
      WHERE process_task_number = :taskNumber AND task_status != N'已关闭'
    `, { taskNumber });
  } else if (task.completed_quantity < task.planned_quantity) {
    await query(`
      UPDATE process_task SET task_status = N'进行中'
      WHERE process_task_number = :taskNumber AND task_status = N'已完成'
    `, { taskNumber });
  }
}
```
