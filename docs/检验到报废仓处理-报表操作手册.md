## 报表概览

从检验到报废仓处理流程包含以下4个核心报表：

| 序号 | 报表名称 | 菜单位置 | 主要用途 |
|------|---------|---------|---------|
| 1 | 报废质量统计分析 | 质量管理 > 报废质量统计分析 | 统计分析报废数据、趋势和分布 |
| 2 | 报废单管理 | 质量管理 > 报废单管理 | 管理报废入库单及其明细 |
| 3 | 报废仓库存查询 | 仓储管理 > 报废仓处置 > 报废仓库存 | 查询报废仓库的库存和批次明细 |
| 4 | 报废处置单列表 | 仓储管理 > 报废仓处置 > 处置单管理 | 管理报废处置申请和确认 |

### 业务流程图

```
来料检验/生产检验/委外检验
         ↓
    发现不合格品
         ↓
  ┌─────────────────┐
  │ 不合格品处理单   │ ← 选择处理方式（报废/返修/特采等）
  └─────────────────┘
         ↓ 选择"报废"
  ┌─────────────────┐
  │ 报废入库单       │ ← 自动创建，入报废仓（08号仓）
  └─────────────────┘
         ↓ 审批通过
  ┌─────────────────┐
  │ 报废仓库存       │ ← 库存自动更新，可按批次查询
  └─────────────────┘
         ↓ 创建处置申请
  ┌─────────────────┐
  │ 报废处置单       │ ← 确认处置，FIFO扣减库存
  └─────────────────┘
         ↓ 完成
  ┌─────────────────┐
  │ 报废质量统计     │ ← 汇总分析，报表展示
  └─────────────────┘
```

## 一、报废质量统计分析报表

### 1.1 进入路径

**菜单路径**：`质量管理 > 报废质量统计分析`

**路由地址**：`/quality/scrap-quality-stats`

### 1.2 报表功能

本报表提供报废质量的全面统计分析，帮助管理者了解报废情况和趋势。

#### 核心功能

- **KPI指标卡片**：实时展示关键指标
- **处理方式分布**：饼图展示各种处理方式的占比
- **来源类型分布**：分析不合格品来源（来料/生产/委外）
- **月度报废趋势**：12个月的报废数量变化趋势
- **物料报废TOP10**：识别报废最严重的物料
- **明细表查询**：查看具体报废记录明细

### 1.3 界面布局

```
┌────────────────────────────────────────────────────────┐
│  报废质量统计分析                              [刷新]   │
├────────────────────────────────────────────────────────┤
│  日期范围：[2025-05-13] 至 [2026-05-13]    [查询] [重置]│
├────────────────────────────────────────────────────────┤
│  ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐  │
│  │不合格总数│ │已处理数量│ │报废总数  │ │待处理数量│  │
│  │   1,234  │ │   1,100  │ │   856    │ │    134   │  │
│  └──────────┘ └──────────┘ └──────────┘ └──────────┘  │
├────────────────────────────────────────────────────────┤
│  [图表概览]  [报废明细]                                 │
├────────────────────────────────────────────────────────┤
│  ┌──────────────────┐  ┌──────────────────┐           │
│  │ 处理方式分布     │  │ 来源类型分布     │           │
│  │   （饼图）       │  │   （饼图）       │           │
│  │                  │  │                  │           │
│  └──────────────────┘  └──────────────────┘           │
│  ┌──────────────────┐  ┌──────────────────┐           │
│  │ 月度报废趋势     │  │ 物料报废TOP10    │           │
│  │  （柱状+折线）   │  │  （横向柱状）    │           │
│  │                  │  │                  │           │
│  └──────────────────┘  └──────────────────┘           │
└────────────────────────────────────────────────────────┘
```

### 1.4 操作步骤

#### 1.4.1 查询数据

1. **设置日期范围**
   - 点击日期选择器，选择起始日期和结束日期
   - 默认显示最近12个月的数据
   - 建议：按月查询或按季度查询

2. **点击"查询"按钮**
   - 系统将根据日期范围刷新所有图表和数据
   - 查询结果包括KPI、图表和明细表

3. **点击"重置"按钮**
   - 恢复默认日期范围（最近12个月）

#### 1.4.2 查看图表概览

切换到"图表概览"标签页，查看以下内容：

**KPI指标卡片**：
- **不合格总数**：统计周期内所有不合格品数量
- **已处理数量**：已完成处理的不合格品数量
- **报废总数**：选择报废处理方式的物料总数
- **待处理数量**：尚未处理的不合格品数量

**处理方式分布饼图**：
- 展示5种处理方式的占比：
  - 报废：直接报废处理
  - 返修：退回工序重新加工
  - 特采：特殊采购让步接收
  - 让步接收：接受不合格品
  - 挑选：分拣后区分合格/不合格

**来源类型分布饼图**：
- 来料检验：采购来料发现的不合格
- 生产检验：生产过程中发现的不合格
- 委外检验：委外加工后检验发现的不合格

**月度报废趋势图**：
- 柱状图：每月报废数量
- 折线图：报废率变化趋势
- 帮助识别报废高发期

**物料报废TOP10**：
- 横向柱状图展示报废数量最多的10种物料
- 帮助识别质量问题集中的物料

#### 1.4.3 查看报废明细

切换到"报废明细"标签页，查看具体记录：

**搜索功能**：
- 在搜索框输入物料编号、物料名称或单号
- 点击"搜索"按钮过滤数据

**列个性化设置**：
- 点击"列设置"图标（齿轮形状）
- 勾选/取消勾选需要显示的列
- 拖动列标题调整列顺序
- 拖动列边框调整列宽

**导出数据**：
- 点击"导出"按钮
- 选择导出格式（Excel）
- 保存到本地

**分页操作**：
- 在底部选择每页显示条数：10/20/50/100
- 点击页码翻页

### 1.5 应用场景

| 场景 | 使用方法 |
|------|---------|
| 月度质量汇报 | 查看月度趋势图，识别报废高峰 |
| 供应商评估 | 筛选来料检验来源，分析供应商物料质量 |
| 质量问题排查 | 查看物料TOP10，定位问题物料 |
| 处理效率分析 | 对比不合格总数和已处理数量 |
| 年度质量总结 | 导出全年数据，制作报告 |

## 二、报废单管理报表

### 2.1 进入路径

**菜单路径**：`质量管理 > 报废单管理`

**路由地址**：`/quality/scrap-orders`

### 2.2 报表功能

本报表管理所有报废入库单，支持查询、导出和详情查看。

#### 核心功能

- **报废单列表查询**：按条件筛选报废单
- **统计分析**：显示报废单总数、报废数量等
- **详情查看**：查看报废单的完整信息和明细
- **数据导出**：导出Excel报表

### 2.3 界面布局

```
┌────────────────────────────────────────────────────────┐
│  报废单管理                              [导出] [刷新]  │
├────────────────────────────────────────────────────────┤
│  报废单号：[____________]  审批状态：[全部 ▼]  [查询]   │
├────────────────────────────────────────────────────────┤
│  统计：报废单总数 156 | 报废数量 2,345 | 草稿 12 | 已审批 144 │
├────────────────────────────────────────────────────────┤
│  报废单号      | 物料   | 报废数量 | 审批状态 | 操作      │
│  SI-20260513-001 | 物料A  |   20     | 已审批  | [查看]    │
│  SI-20260513-002 | 物料B  |   15     | 草稿    | [查看]    │
│  ...            | ...    |  ...     | ...    | ...       │
└────────────────────────────────────────────────────────┘
```

### 2.4 操作步骤

#### 2.4.1 查询报废单

1. **输入报废单号**（可选）
   - 输入完整的报废单号进行精确查询
   - 例如：`SI-20260513-001`

2. **选择审批状态**
   - 全部：显示所有状态
   - 草稿：未审批的报废单
   - 已审批：已审批通过的报废单
   - 已撤销：已撤销的报废单

3. **点击"查询"按钮**
   - 列表将根据条件刷新

#### 2.4.2 查看统计信息

报表顶部显示实时统计数据：
- **报废单总数**：符合条件的报废单数量
- **报废数量**：所有报废单的物料总数
- **草稿数**：未审批的报废单数量
- **已批准数**：已审批的报废单数量

#### 2.4.3 查看报废单详情

1. 点击操作列的 **[查看]** 按钮
2. 弹出报废单详情窗口，显示：
   - 报废单号、仓库、审批状态
   - 操作员、报废日期、备注
   - 明细列表：物料编号、名称、规格、数量、批次号
3. 点击关闭按钮退出

#### 2.4.4 导出数据

1. 点击 **[导出]** 按钮
2. 系统生成Excel文件并下载
3. 文件包含所有符合条件的报废单及明细

### 2.5 数据来源

报废单数据来源于：
- **数据表**：`stock_in`（stock_in_type='报废入库'）
- **关联表**：`stock_in_detail`、`nonconforming_product`
- **触发条件**：不合格品选择"报废"处理方式时自动创建

### 2.6 应用场景

| 场景 | 使用方法 |
|------|---------|
| 日常报废查询 | 按日期或状态筛选，查看报废情况 |
| 审批状态跟踪 | 筛选"草稿"状态，跟进未审批单据 |
| 报废数量统计 | 查看统计区的报废数量汇总 |
| 明细核对 | 导出Excel，与实物核对 |

## 三、报废仓库存查询报表

### 3.1 进入路径

**菜单路径**：`仓储管理 > 报废仓处置 > 报废仓库存`

**路由地址**：`/warehouse/scrap-disposal`（报废仓库存Tab）

### 3.2 报表功能

本报表查询报废仓库（08号仓）的实时库存，支持按物料查询和批次明细查看。

#### 核心功能

- **库存汇总查询**：按物料汇总显示报废库存
- **批次明细查询**：查看每个物料的批次明细
- **库存统计**：显示最早/最近入库日期
- **库存预警**：标识超期积压库存

### 3.3 界面布局

```
┌────────────────────────────────────────────────────────┐
│  报废仓处置                                             │
│  [报废仓库存]  [处置单管理]                             │
├────────────────────────────────────────────────────────┤
│  物料编号：[____________]  [查询] [重置]                │
├────────────────────────────────────────────────────────┤
│  物料编号  | 物料名称 | 库存数量 | 批次数 | 最早/最晚入库│
│  MAT-001  | 物料A   |   150   |   3   | 05-01/05-10  │
│  MAT-002  | 物料B   |    80   |   2   | 05-03/05-12  │
│  ...      | ...     |  ...    |  ...  | ...          │
│                                          [批次明细]    │
└────────────────────────────────────────────────────────┘
```

### 3.4 操作步骤

#### 3.4.1 查询库存

1. **输入物料编号**（可选）
   - 输入物料编号进行精确查询
   - 留空则查询所有物料

2. **点击"查询"按钮**
   - 列表刷新显示库存数据

3. **点击"重置"按钮**
   - 清空搜索条件，显示全部库存

#### 3.4.2 查看库存统计

每行物料显示以下信息：
- **物料编号**：物料的唯一标识
- **物料名称**：物料的名称
- **库存数量**：该物料在报废仓的总数量
- **批次数**：该物料有多少个批次
- **最早入库**：最早一批次的入库日期
- **最近入库**：最后一批次的入库日期

#### 3.4.3 查看批次明细

1. 点击物料行的 **[批次明细]** 按钮
2. 弹出批次明细窗口（可拖动移动位置）
3. 显示内容：
   - 批次号：唯一批次标识
   - 物料编号、名称、规格
   - 当前数量：该批次剩余数量
   - 初始数量：入库时的数量
   - 入库日期：该批次入库时间
4. 明细按入库日期升序排列（FIFO原则）

**批次明细弹窗示例**：
```
┌──────────────────────────────────────────────┐
│  批次明细 - 物料A (MAT-001)      [可拖动]     │
├──────────────────────────────────────────────┤
│  批次号      | 当前数量 | 初始数量 | 入库日期   │
│  FB-20260501-001 |   50   |   50   | 2026-05-01│
│  FB-20260505-001 |   60   |   60   | 2026-05-05│
│  FB-20260510-001 |   40   |   40   | 2026-05-10│
└──────────────────────────────────────────────┘
```

#### 3.4.4 库存预警

系统会自动标识异常库存：
- **超期积压**：入库超过30天未处置
- **数量异常**：当前数量与初始数量不符（可能已有处置记录）

### 3.5 数据来源

- **数据表**：`finished_batch_inventory`
- **筛选条件**：warehouse_type='报废仓库' AND quality_status='不合格品'
- **仓库编号**：08（报废仓）

### 3.6 应用场景

| 场景 | 使用方法 |
|------|---------|
| 库存盘点 | 查询所有物料，与实物核对 |
| 批次追溯 | 查看批次明细，追溯入库时间 |
| FIFO处置 | 按入库日期排序，先入先出 |
| 库存积压分析 | 查看最早入库日期，识别长期未处置库存 |

## 四、报废处置单列表报表

### 4.1 进入路径

**菜单路径**：`仓储管理 > 报废仓处置 > 处置单管理`

**路由地址**：`/warehouse/scrap-disposal`（处置单管理Tab）

### 4.2 报表功能

本报表管理报废处置申请单，支持创建、确认、驳回和删除操作。

#### 核心功能

- **处置单列表查询**：按条件筛选处置单
- **创建处置申请**：申请处置报废库存
- **确认处置**：审批通过，扣减库存
- **驳回处置**：退回申请
- **删除处置单**：删除草稿状态的单据
- **详情查看**：查看处置单完整信息

### 4.3 界面布局

```
┌────────────────────────────────────────────────────────┐
│  处置单管理                          [+创建] [刷新]     │
├────────────────────────────────────────────────────────┤
│  处置单号：[____________]  状态：[全部 ▼]  [查询] [重置]│
├────────────────────────────────────────────────────────┤
│  处置单号      | 状态   | 申请日期  | 确认人 | 操作      │
│  SD-20260513-001 | 待确认 | 2026-05-13 | -     | [确认][驳回][详情][删除]│
│  SD-20260513-002 | 已确认 | 2026-05-12 | 张三  | [详情]  │
│  ...            | ...   | ...      | ...   | ...       │
└────────────────────────────────────────────────────────┘
```

### 4.4 操作步骤

#### 4.4.1 查询处置单

1. **输入处置单号**（可选）
   - 例如：`SD-20260513-001`

2. **选择状态**
   - 全部：所有状态
   - 待确认：等待审批的处置单
   - 已确认：已审批通过
   - 已驳回：被驳回的处置单

3. **点击"查询"按钮**

#### 4.4.2 创建处置申请

1. 点击 **[+创建]** 按钮
2. 弹出创建处置申请窗口（可拖动）
3. 填写表单：
   - **处置原因**：必填，说明处置原因
   - **备注**：可选，补充说明
   - **明细列表**：
     - 点击"添加明细行"
     - 选择物料（可从报废仓库存中选择）
     - 输入处置数量
     - 填写备注
4. 点击 **[提交]** 按钮
5. 系统生成处置单，状态为"待确认"

**创建表单示例**：
```
┌──────────────────────────────────────────────┐
│  创建报废处置申请                [可拖动]      │
├──────────────────────────────────────────────┤
│  处置原因：[_______________________] *必填     │
│  备注：    [_______________________]          │
├──────────────────────────────────────────────┤
│  处置明细：                                   │
│  物料编号 | 物料名称 | 处置数量 | 备注        │
│  MAT-001 | 物料A  |   10    | [________]     │
│  MAT-002 | 物料B  |    5    | [________]     │
│                            [+添加明细行]       │
├──────────────────────────────────────────────┤
│                         [取消]    [提交]       │
└──────────────────────────────────────────────┘
```

#### 4.4.3 确认处置

1. 找到状态为"待确认"的处置单
2. 点击操作列的 **[确认]** 按钮
3. 系统弹出确认对话框
4. 点击"确定"
5. 系统执行以下操作：
   - 处置单状态变更为"已确认"
   - 记录确认人和确认时间
   - **按FIFO原则扣减报废仓库存**
   - 生成出库流水记录
6. 确认成功后显示提示消息

**FIFO扣减规则**：
- 优先扣减最早入库的批次
- 如果一个批次数量不足，继续扣减下一个批次
- 确保库存数据的先进先出管理

#### 4.4.4 驳回处置

1. 找到状态为"待确认"的处置单
2. 点击操作列的 **[驳回]** 按钮
3. 输入驳回原因
4. 点击"确定"
5. 处置单状态变更为"已驳回"

#### 4.4.5 删除处置单

1. 找到状态为"草稿"的处置单
2. 点击操作列的 **[删除]** 按钮
3. 系统弹出确认对话框
4. 点击"确定"删除

**注意**：只有"草稿"状态的处置单可以删除，"待确认"、"已确认"、"已驳回"状态的单据不可删除。

#### 4.4.6 查看处置单详情

1. 点击操作列的 **[详情]** 按钮
2. 弹出处置单详情窗口（可拖动）
3. 显示内容：
   - **基本信息**：处置单号、状态、仓库、处置原因
   - **申请信息**：申请人、申请日期
   - **确认信息**：确认人、确认日期
   - **备注**：补充说明
   - **处置明细**：物料编号、名称、规格、处置数量、批次号

## 六、业务流程串联

### 6.1 完整操作流程

以下是一个完整的从检验到报废仓处理的实际操作示例：

#### 场景：来料检验发现不合格品，进行报废处理

**步骤1：来料检验不合格**

1. 进入"来料检验"页面
2. 对采购入库物料进行检验
3. 填写检验结果：合格数量80，不合格数量20
4. 检验结论选择"不合格"
5. 完成检验

**步骤2：处理不合格品**

1. 系统自动创建不合格品单（NC单）
2. 进入"不合格处理单"页面
3. 找到刚创建的NC单（来源类型=来料检验）
4. 选择处理方式：**报废**
5. 填写报废信息：
   - 报废数量：20
   - 报废类型：批量
   - 处理备注：来料质量不合格
6. 提交处理

**步骤3：报废入库单自动创建**

1. 系统自动创建报废入库单
2. 入仓库：08号仓（报废仓）
3. 入库类型：报废入库
4. 状态：草稿

**步骤4：审批报废入库单**

1. 进入"报废单管理"报表
2. 找到刚创建的报废入库单
3. 点击审批按钮
4. 审批通过后：
   - 报废仓库存自动更新
   - 生成批次库存记录
   - 生成入库流水

**步骤5：查询报废仓库存**

1. 进入"报废仓库存"报表
2. 查看对应物料的库存
3. 点击"批次明细"查看批次信息
4. 确认库存数量正确（20个）

**步骤6：创建报废处置申请**

1. 进入"处置单管理"报表
2. 点击"+创建"按钮
3. 填写处置原因：供应商质量问题，退回供应商
4. 添加明细：
   - 选择物料
   - 处置数量：10（部分处置）
5. 提交申请

**步骤7：确认处置**

1. 找到刚创建的处置单（状态=待确认）
2. 点击"确认"按钮
3. 系统执行：
   - 按FIFO扣减批次库存（最早入库的批次扣减10个）
   - 生成出库流水
   - 更新处置单状态为"已确认"

**步骤8：查看报废质量统计**

1. 进入"报废质量统计分析"报表
2. 查看最新统计数据：
   - 不合格总数+20
   - 报废总数+20
   - 处理方式分布中"报废"占比上升
   - 物料TOP10可能更新

## 七、常见问题解答

### Q1：为什么报废仓库存查不到数据？

**可能原因**：
1. 报废入库单尚未审批
2. 入库单未入08号仓（报废仓）
3. 库存已被处置扣减完毕

**解决方法**：
1. 进入"报废单管理"，检查报废入库单的审批状态
2. 如未审批，先进行审批
3. 审批后等待1-2分钟，库存数据会自动更新

### Q2：批次明细中的"当前数量"和"初始数量"为什么不一样？

**原因**：
- **初始数量**：入库时的数量（不会变化）
- **当前数量**：剩余数量（处置后会被扣减）

**示例**：
- 入库50个，初始数量=50，当前数量=50
- 处置30个后，初始数量=50，当前数量=20

### Q3：确认处置时提示"库存不足"怎么办？

**可能原因**：
1. 处置数量超过了当前库存数量
2. 批次库存已被其他处置单扣减

**解决方法**：
1. 进入"报废仓库存"查看实际库存
2. 修改处置数量，确保不超过当前库存
3. 如有多个处置单，注意处理顺序

### Q4：如何导出报废数据？

**方法1：报废质量统计分析**
1. 进入报表
2. 切换到"报废明细"标签
3. 点击"导出"按钮

**方法2：报废单管理**
1. 进入报表
2. 点击"导出"按钮
3. 导出Excel文件

### Q5：FIFO扣减是什么意思？

**FIFO** = First In, First Out（先进先出）

**扣减规则**：
1. 优先扣减最早入库的批次
2. 如果一个批次数量不足，继续扣减下一个批次
3. 确保库存管理符合先进先出原则

**示例**：
```
批次1：FB-20260501，数量50（最早）
批次2：FB-20260505，数量60
批次3：FB-20260510，数量40（最晚）

处置100个：
- 批次1扣减50（剩余0）
- 批次2扣减50（剩余10）
- 批次3不变（40）
```

### Q6：如何查看某个物料的完整报废历史？

**方法**：
1. 进入"报废质量统计分析"
2. 设置日期范围（如最近1年）
3. 在"报废明细"中搜索该物料编号
4. 查看所有报废记录

**或**：
1. 进入"报废仓库存"
2. 输入物料编号查询
3. 查看批次明细和入库日期

### Q7：弹窗无法拖动怎么办？

**解决方法**：
1. 确保鼠标指针放在弹窗标题栏上
2. 按住鼠标左键不放
3. 移动鼠标拖动弹窗
4. 松开鼠标左键完成移动

**如仍无法拖动**：
1. 刷新页面（F5）
2. 清除浏览器缓存
3. 重新进入报表

### Q8：如何快速找到待处理的报废单？

**方法**：
1. 进入"报废单管理"
2. 审批状态选择"草稿"
3. 点击查询
4. 列表显示所有待审批的报废单
