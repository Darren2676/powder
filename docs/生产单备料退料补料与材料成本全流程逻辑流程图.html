文档说明：本文档完整展示生产单备料出库、退料、补料和材料成本的7个阶段：
阶段1 生产单派发与备料单生成：生产单审批 → 派发 → 自动生成备料单
阶段2 正常领料出库：选择备料单 → 填写领料数量 → 创建领料单 → 扣减库存 → 线边仓入库 → 写入成本快照
阶段3 补料：对同一备料单再次领料 → source_type=补料 → 扣减库存 → 写入成本快照
阶段4 部分退料：选择领料单 → 填写退料数量 → 创建退料单 → 库存回退 → 线边仓出线 → 写入负数成本快照
阶段5 领料撤回：删除领料单 → 库存回退 → 线边仓出线 → 删除成本快照
阶段6 退料撤回：删除退料单 → 库存重新扣减 → 线边仓回入 → 删除负数成本快照
阶段7 状态联动与成本汇总：备料状态/生产单状态联动重算 + 成本快照正负对冲汇总
涵盖状态流转、数据变更矩阵、关键业务规则及各环节的数据实体关系。

退料核心规则：
① 退料数量 ≤ 该物料已领数量 - 累计已退数量
② 同一领料单可多次退料，每次创建新退料单
③ 退料不检查报工（退料只减少领料量，不影响报工数据）
④ 退料成本快照：issued_quantity 和 material_cost 均为负数，standard_cost 为正数（锁定当时的成本单价）

退料撤回与领料撤回对比：
① 退料撤回不检查报工（退料不影响报工，所以撤回退料也不需要检查）
② 退料撤回是扣减库存（把退回的物料再扣回去），领料撤回是回退库存
③ 退料撤回恢复已领量（+=），领料撤回减少已领量（-=）
④ 退料撤回后生产单可能恢复为"已备料"，领料撤回后可能回退为"已派发"

状态联动规则：
① 首道工序 = material_preparation_detail 中 MIN(step_number) 的所有物料行
② 当首道所有物料行的 issued_quantity ≥ required_quantity 时，生产单状态从"已派发"→"已备料"
③ 当首道存在物料行 issued_quantity < required_quantity 时，生产单状态从"已备料"→"已派发"
④ 同时会回写销售订单的生产状态

成本锁定原则：
① 领料时按当时的标准成本单价表快照写入，后续成本表更新不影响已有快照
② 退料时按退料时的标准成本单价写入负数快照（如果成本表已更新，退料用新单价）
③ 领料撤回时直接删除该领料单的所有快照行
④ 退料撤回时直接删除该退料单的所有快照行
