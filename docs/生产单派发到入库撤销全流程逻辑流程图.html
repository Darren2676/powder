十三、核心计算公式

13.1 备料需求量计算

需求量 = (计划生产数量 / BOM基础量) × BOM实际用量
required_quantity = (planned_quantity / bom_base_quantity) × actual_quantity
adjusted_quantity = required_quantity（初始等于需求量）

13.2 倒冲扣减量计算

本次扣减量 = 入库数量 × (BOM单耗 / BOM基础量)
deductQty = inboundQuantity × (bomActualQuantity / bomBaseQuantity)
精度: Math.round(value × 10000) / 10000（4位小数）
封顶: deductQty ≤ required - alreadyDeducted（不超过剩余量）
