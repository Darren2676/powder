按物料类型生产调度单打印格式方案

一、需求背景

系统中不同物料类型均可能存在生产工单：

  • 成品：橡胶密封件成品生产
  • 原材料（胶料）：胶料混炼生产
  • 骨架：金属骨架冲压/磷化生产
  • 预成型件：半成品预成型生产

由于各类生产单的扩展数据不同，统一打印格式存在冗余或缺失，需按物料类型匹配差异化模板。

二、判断依据

通过 production_order.item_number JOIN item_master 获取 item_type：

五、技术实现路径

5.1 后端接口改造

文件：server/src/modules/production/order/order.controller.ts

在 getPrintData 中增加 item_type 查询：

const [orders]: any = await sequelize.query(`
  SELECT po.*, im.item_type 
  FROM production_order po
  LEFT JOIN item_master im ON po.item_number = im.item_number
  WHERE po.production_order_number = :orderNum
`, { replacements: { orderNum } });

results.push({
  order: orders[0],
  materials,
  tasks,
  item_type: orders[0].item_type  // 新增
});

5.2 前端模板路由

文件：client/src/views/production/DispatchPrint/Index.vue

在 triggerDetailPrint 中按 item_type 路由：

items.forEach((item: any, pageIdx: number) => {
  const itemType = item.item_type || '成品';
  
  switch (itemType) {
    case '原材料':
      pagesHtml += renderRawMaterialTemplate(item, pageIdx, items.length);
      break;
    case '骨架':
      pagesHtml += renderSkeletonTemplate(item, pageIdx, items.length);
      break;
    case '预成型件':
      pagesHtml += renderPreformTemplate(item, pageIdx, items.length);
      break;
    case '成品':
    default:
      pagesHtml += renderDefaultTemplate(item, pageIdx, items.length);
  }
});
