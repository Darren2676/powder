## 五、阶段二：待发货 → 生成发货申请

### 5.1 待发货数量计算

```
待发数量 = MAX(0, order_quantity - refunded_quantity - shipped_quantity)
建议发货量 = MAX(0, order_quantity - refunded_quantity - shipped_quantity - applied_quantity)
```

### 5.2 流程

```mermaid
flowchart TB
    PENDING["📦 待发货列表<br/>GET /api/shipping-requests/pending"] --> FILTER["筛选条件:<br/>shipping_status IN (未申请, 未发货, 部分发货)<br/>AND approval_status = 已审批"]
    FILTER --> SHOW["显示待发明细:<br/>订单号 / 客户 / 物料 / 订单量 /<br/>已发量 / 已申请量 / 待发量"]
    SHOW --> SELECT["用户勾选明细行<br/>输入本次发货数量"]
    SELECT --> VALIDATE{"校验发货数量"}
    VALIDATE -- "数量 ≤ 0" --> ERR["❌ 数量无效"]
    VALIDATE -- "有效" --> CREATE_SR["POST /api/shipping-requests<br/>创建发货申请"]
    CREATE_SR --> TX_START["开启事务"]
    TX_START --> INSERT_H["插入 shipping_request 主表<br/>状态 = 待审核"]
    INSERT_H --> LOOP_D["🔁 遍历明细"]
    LOOP_D --> INSERT_D["插入 shipping_request_detail"]
    INSERT_D --> UPDATE_SOD["更新 sales_order_detail<br/>shipping_status = 部分发货/全部发货"]
    UPDATE_SOD --> LOOP_D
    LOOP_D -- "完成" --> COMMIT["提交事务"]
    COMMIT --> RESULT["返回申请编号 SR-YYYYMMDD-NNN"]
```

### 5.3 发货申请状态机

```mermaid
stateDiagram-v2
    [*] --> 待审核: 创建申请
    待审核 --> 已审核: 审批通过
    待审核 --> 已取消: 取消/删除
    已审核 --> 已发货: 创建发货单后
    已审核 --> 已取消: 撤消
    已取消 --> [*]: 回写订单状态
```

| 状态 | 可执行操作 | 限制 |
|------|----------|------|
| 待审核 | 编辑 / 删除 / 提交审批 | 仅创建者可操作 |
| 已审核 | 创建发货单 / 撤消 | 撤消需回写订单发货状态 |
| 已发货 | 无（终态） | 已生成发货单 |
| 已取消 | 无（终态） | 已回写订单发货状态 |

## 六、阶段三：发货申请 → 生成发货单（支持分批）

### 6.1 核心设计：一个申请可多次分批发货

```mermaid
flowchart LR
    SR["发货申请 SR-001<br/>物料A: 100个<br/>物料B: 200个"] --> SO1["发货单 SO-001<br/>物料A: 50个<br/>物料B: 100个"]
    SR --> SO2["发货单 SO-002<br/>物料A: 50个<br/>物料B: 80个"]
    SR --> SO3["发货单 SO-003<br/>物料B: 20个<br/>（最后一批）"]
```

### 6.2 发货单创建流程

```mermaid
flowchart TB
    START["🚚 创建发货单<br/>POST /api/shipping-orders"] --> CHECK_SR{"发货申请状态 = 已审核?"}
    CHECK_SR -- "否" --> ERR1["❌ 申请未审核"]
    CHECK_SR -- "是" --> LOAD_SR["加载申请明细 +<br/>计算每行已发数量 vs 申请数量"]
    LOAD_SR --> USER_INPUT["用户输入:<br/>① 本次每行发货数量<br/>② 批次号 + 批次数量<br/>③ 仓库/承运商/运单号"]

    USER_INPUT --> VALIDATE{"∑批次数量 == 行发货数量?<br/>行发货数量 ≤ 可发数量?"}
    VALIDATE -- "否" --> ERR2["❌ 数量不匹配"]
    VALIDATE -- "是" --> TX["开启事务"]
    TX --> GEN_NUM["生成编号 SO-YYYYMMDD-NNN"]
    GEN_NUM --> INSERT_SO["插入 shipping_order 主表<br/>request_number = SR-xxx<br/>status = 待发货"]
    INSERT_SO --> LOOP["🔁 遍历发货明细"]
    LOOP --> INSERT_SOD["插入 shipping_order_detail"]
    INSERT_SOD --> INSERT_BATCH["插入 shipping_order_batch<br/>（每行可多批次）"]
    INSERT_BATCH --> LOOP

    LOOP -- "完成" --> UPDATE_SR_STATUS["更新申请明细已发数量<br/>判断是否全部发完"]
    UPDATE_SR_STATUS --> SR_DONE{"申请所有行都已发完?"}
    SR_DONE -- "是" --> SR_SHIPPED["申请状态 → 已发货"]
    SR_DONE -- "否" --> SR_PARTIAL["申请保持已审核"]
    SR_SHIPPED --> COMMIT["提交事务"]
    SR_PARTIAL --> COMMIT
    COMMIT --> RESULT["返回发货单编号"]
```

## 七、阶段四：退货管理

### 7.1 退货前提

```
退货条件: 发货单状态 IN ('已发货', '已签收')
可退数量 = 发货批次数量 - ∑已退数量(排除已驳回)
```

### 7.2 退货流程

```mermaid
flowchart TB
    START["🔙 发起退货<br/>选择发货单"] --> LOAD["GET /api/return-orders/shipping-order/:sn<br/>加载发货单明细 + 批次<br/>计算各批次可退数量"]
    LOAD --> CHECK_STATUS{"发货单状态 = 已发货/已签收?"}
    CHECK_STATUS -- "否" --> ERR["❌ 不允许退货"]
    CHECK_STATUS -- "是" --> USER_INPUT["用户输入:<br/>退货类型(退款退货/退货换货)<br/>退货仓库 / 退货原因<br/>每个批次退货数量"]

    USER_INPUT --> VALIDATE{"退货数量 ≤ 可退数量?"}
    VALIDATE -- "否" --> ERR2["❌ 超过可退数量"]
    VALIDATE -- "是" --> CREATE["POST /api/return-orders"]
    CREATE --> TX["开启事务"]
    TX --> INSERT_RO["插入 return_order 主表<br/>status = 待确认<br/>approval_status = 草稿"]
    INSERT_RO --> LOOP_D["🔁 遍历退货明细"]
    LOOP_D --> INSERT_ROD["插入 return_order_detail"]
    INSERT_ROD --> INSERT_BATCH["插入 return_order_batch"]
    INSERT_BATCH --> LOOP_D
    LOOP_D -- "完成" --> COMMIT["提交事务"]
    COMMIT --> RESULT["返回退货单号 RT-YYYYMMDD-NNN"]

    RESULT --> APPROVAL["提交审批"]
    APPROVAL --> APPROVE{"审批通过?"}
    APPROVE -- "是" --> CONFIRM["确认退货<br/>POST /confirm"]
    APPROVE -- "否" --> REJECT["驳回退货<br/>POST /reject"]
    CONFIRM --> INBOUND["退货入库<br/>更新库存"]
    CONFIRM --> WRITEBACK["回写:<br/>sales_order_detail.refunded_quantity<br/>sales_order_detail.shipping_status"]
```

### 7.3 退货单状态机

```mermaid
stateDiagram-v2
    [*] --> 待确认: 创建退货单
    待确认 --> 审批中: 提交审批
    审批中 --> 已审批: 审批通过
    审批中 --> 草稿: 撤回
    已审批 --> 已确认: 确认退货
    已审批 --> 已驳回: 驳回退货
    已驳回 --> [*]: 终态
    已确认 --> [*]: 退货入库+回写
```

| 状态 | approval_status | 可执行操作 |
|------|----------------|----------|
| 待确认 | 草稿 | 编辑 / 删除 / 提交审批 |
| 审批中 | 已提交 | 审批 / 撤回 |
| 已审批 | 已审批 | 确认 / 驳回 |
| 已确认 | 已审批 | 无（终态） |
| 已驳回 | 已审批 | 无（终态） |

## 八、撤消/删除 — 回写逻辑

### 8.1 撤消发货申请

```mermaid
flowchart TB
    CANCEL_SR["撤消发货申请"] --> CHECK{"当前状态?"}
    CHECK -- "待审核" --> DELETE["直接删除<br/>DELETE 主表+明细"]
    CHECK -- "已审核(未生成发货单)" --> CANCEL["状态 → 已取消"]
    CHECK -- "已审核(已有发货单)" --> ERR["❌ 已有发货单，不可撤消<br/>需先撤消发货单"]

    DELETE --> WRITEBACK_D["回写 sales_order_detail:<br/>重新计算 shipping_status<br/>= 扣减本次申请量后的状态"]
    CANCEL --> WRITEBACK_C["回写 sales_order_detail:<br/>重新计算 shipping_status"]
    WRITEBACK_D --> DONE["✅ 完成"]
    WRITEBACK_C --> DONE
```

**回写公式：**
```
当前已申请总量 = ∑(所有非取消申请的 ship_quantity)
if (已申请总量 == 0) shipping_status = '未申请'
else if (已申请总量 < order_quantity) shipping_status = '部分发货'  
else shipping_status = '全部发货'
```

### 8.2 撤消发货单

```mermaid
flowchart TB
    CANCEL_SO["撤消发货单"] --> CHECK{"当前状态?"}
    CHECK -- "待发货" --> CANCEL1["状态 → 已取消"]
    CHECK -- "已发货(无退货)" --> CANCEL2["状态 → 已取消"]
    CHECK -- "已发货(有退货)" --> ERR1["❌ 已有退货单<br/>需先处理退货单"]
    CHECK -- "已签收" --> ERR2["❌ 已签收不可撤消"]

    CANCEL1 --> WRITEBACK_SR["回写发货申请:<br/>扣减已发数量<br/>重新判断申请状态"]
    CANCEL2 --> WRITEBACK_SR
    WRITEBACK_SR --> WRITEBACK_SOD["回写 sales_order_detail:<br/>shipped_quantity -= 本单发货量<br/>重新计算 shipping_status"]
    WRITEBACK_SOD --> DONE["✅ 完成"]
```

### 8.3 撤消/驳回退货单

```mermaid
flowchart TB
    CANCEL_RT["撤消/驳回退货单"] --> CHECK{"当前状态?"}
    CHECK -- "待确认(草稿)" --> DELETE["直接删除<br/>DELETE 主表+明细+批次"]
    CHECK -- "已审批未确认" --> REJECT["驳回: status → 已驳回"]
    CHECK -- "已确认" --> ERR["❌ 已确认不可撤消<br/>需要反向操作(换货入库等)"]

    DELETE --> DONE["✅ 无需回写"]
    REJECT --> DONE2["✅ 驳回后不影响已发数据<br/>可退数量自动恢复(排除已驳回)"]
```

## 九、核心量级关系

```mermaid
flowchart TB
    subgraph "销售订单明细 (每行)"
        OQ["order_quantity 订单数量"]
        SQ["shipped_quantity 已发数量"]
        RQ["refunded_quantity 已退数量"]
        AQ["applied_quantity 已申请数量"]
        PQ["pending_qty 待发数量<br/>= order_qty - refunded_qty - shipped_qty"]
    end

    subgraph "发货申请明细"
        SHIP_QTY["ship_quantity 本次申请数量"]
    end

    subgraph "发货单明细"
        SO_QTY["quantity 本次发货数量"]
    end

    subgraph "退货单明细"
        RT_QTY["return_quantity 退货数量"]
    end

    OQ --> PQ
    RQ --> PQ
    SQ --> PQ
    SHIP_QTY -->|"创建时累加"| AQ
    SO_QTY -->|"确认发货后累加"| SQ
    RT_QTY -->|"确认退货后累加"| RQ
```

**关键不变式：**
```
shipped_quantity = ∑(所有已确认发货单的发货数量)
refunded_quantity = ∑(所有已确认退货单的退货数量)  
实际净发 = shipped_quantity - refunded_quantity
```
