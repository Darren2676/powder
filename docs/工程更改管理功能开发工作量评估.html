工程更改管理功能 — 开发工作量评估

Seals MES System  |  2026年5月

一、功能概述

业务描述：管理产品从样品申请、样件通过、客户变更要求到工艺调整记录的全生命周期。以产品为主键聚合变更日志，主表一行对应一个产品的生命周期，子表记录该产品的多条变更事件。

1.1 流程状态机

新建产品生命周期 → 进行中
     │
     ▼ 状态推进
已完成
     │
     ▼ 状态推进
已关闭

注：任意状态均可逆向回退至「进行中」
    无审批环节，状态由操作人直接切换

1.2 变更类型字典

类型说明
样件通过样品经客户验证合格，正式通过
客户要求变更客户提出产品规格/工艺/参数等变更需求
工艺调整内部工艺路线/参数/配方等调整
其他不属于以上分类的变更

1.3 角色权限

操作管理员经理普通用户
新建生命周期✅✅✅
编辑基础信息✅✅✅
状态切换✅✅✅
删除生命周期（无日志时）✅✅✅
新增变更日志✅✅✅
编辑/删除变更日志✅✅✅

六、关键影响因素

因素影响说明
无审批流程✅ 省时状态直接由操作人切换，不需要 approval.service.ts 集成，免去审批节点编排约 2-3 天
冗余字段事务同步⚠️ 增耗时子表写入时需在事务内同步更新主表 change_count / latest_change_type / latest_change_at，增加 Service 层复杂度约 0.5 天
详情页双视图⚠️ 增耗时时间轴 + 表格双视图切换，Detail.vue 约 500 行，比纯表格详情多 0.5-1 天
3个外部下拉关联⚠️ 增耗时关联样品单/工艺路线/BOM 三个外部模块下拉，需额外拉取数据且须确认各模块 API 实际导出函数名，增加 0.3 天
复用现有 composable✅ 省时直接复用 useTableList + useColumnPreference，列表页搜索/分页/列设置零开发成本
按产品 upsert 新建⚠️ 增耗时新建时需检查 product_number 是否已存在生命周期记录，已存在则返回原 id，增加后端逻辑约 0.2 天
无需编号生成✅ 省时主键为 INT IDENTITY 自增，不需要 documentNumber.service.ts 编号生成，省 0.5 天
无需导入/导出✅ 省时基础方案不需要 Excel 导入模板（后期可追加约 1 天）
