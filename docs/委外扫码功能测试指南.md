## 📱 测试流程

### 测试 1：委外发料扫码

#### 步骤：

1. **打开移动端**
   - 浏览器访问：`http://localhost:5175`
   - 使用测试账号登录（admin / admin123）

2. **进入委外发料**
   - 首页点击"委外发料"橙色圆形按钮
   - 或直接访问：`http://localhost:5175/outsourcing/issue-scan`

3. **扫描订单二维码**
   - 点击右上角扫描图标
   - 允许摄像头权限
   - 扫描委外订单二维码

   **或手动输入订单号：**
   - 在搜索框输入委外订单号（如：`OS-20260429-001`）
   - 点击"查询"按钮

4. **查看订单信息**
   - 确认订单详情显示正确
   - 查看发料进度条
   - 查看物料清单

5. **输入发料数量**
   - 方式一：使用 +/- 按钮调整数量
   - 方式二：直接输入数字
   - 方式三：扫描物料条码自动填充

6. **确认发料**
   - 点击底部"确认发料"按钮
   - 确认弹窗中点击"确定"
   - 等待提交成功提示

7. **验证结果**
   - 提示"发料成功"
   - 自动返回列表
   - 检查库存是否扣减

## ⚠️ 注意事项

1. **摄像头权限**
   - 需要在 HTTPS 环境下使用（localhost 除外）
   - 浏览器会请求摄像头权限，需要允许

2. **网络配置**
   - 确保移动端能访问后端 API（`http://localhost:3000`）
   - 检查 Vite 代理配置

3. **库存准备**
   - 发料前确保线边仓有足够库存
   - 收回后成品仓库存会增加

4. **订单状态**
   - 订单必须处于"待发出"或"已发出"状态
   - 已完成的订单不能发料/收回

## 🐛 常见问题

### Q1: 后端服务器启动失败

**原因：** 端口 3000 被占用

**解决：**
```bash
# 查找占用端口的进程
Get-NetTCPConnection -LocalPort 3000 -ErrorAction SilentlyContinue | Select-Object OwningProcess

# 终止进程
Stop-Process -Id <进程ID> -Force
```

### Q2: 扫码无法识别

**原因：** 二维码格式错误或光线不足

**解决：**
- 确保二维码格式正确（JSON）
- 增加环境光线
- 调整摄像头距离

### Q3: 发料失败，提示库存不足

**原因：** 线边仓库存不足

**解决：**
```sql
-- 检查库存
SELECT * FROM inventory WHERE item_number = 'ITEM001' AND warehouse_number = 'LINE_WH';

-- 增加库存（测试用）
UPDATE inventory SET quantity = 1000 WHERE item_number = 'ITEM001' AND warehouse_number = 'LINE_WH';
```

### Q4: 移动端无法访问后端 API

**原因：** 跨域问题或代理配置错误

**解决：**
- 检查 `vite.config.ts` 中的代理配置
- 确保后端 CORS 配置正确
