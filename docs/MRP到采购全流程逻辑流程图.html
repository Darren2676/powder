流程概述：MRP运算根据物料BOM分解需求，business_scope为"仅采购"的物料自动生成采购申请。采购申请审批后转采购订单，供应商送货后创建入库单。入库时系统检查item_master.incoming_inspection字段，值为'Y'则自动创建来料检验单，检验合格后方可确认入库；值为'N'则直接确认入库。确认入库后自动写入批次库存、更新汇总库存、记录库存流水，并回写采购订单的到货状态。

  • MRP统一使用制造BOM（mfg_bom）而非设计BOM（bom）

九、关键业务规则汇总

9.1 MRP到采购的触发条件

  • MRP统一使用制造BOM（mfg_bom_header/mfg_bom_detail）进行运算
  • business_scope="仅采购"的物料由MRP自动生成采购申请
  • 采购申请也可由生产备料缺料、安全库存预警或手动发起
  • 采购申请审批通过后，可转采购订单（支持部分转单）

9.2 来料检验触发规则

  • 入库单创建时，系统自动遍历入库明细行
  • 对每个物料查询 item_master.incoming_inspection 字段
  • incoming_inspection='Y' → 自动创建来料检验单（purchase_quality_inspection）
  • incoming_inspection='N' → 无需检验，入库数量直接视为合格数量
  • 检验单自动匹配来料检验方案（incoming_inspect_plan，plan_name=物料编号）
  • 检验单自动匹配来料检验规范（incoming_inspect_spec，spec_name=物料编号）
  • 检验完成后自动回写入库单明细的合格/不合格数量

9.3 入库规则

  • 确认入库时，仅按 qualified_quantity（合格数量）执行入库操作
  • 入库自动生成批次号（MB-YYYYMMDD-###），写入批次库存
  • 同步更新汇总库存（material_inventory）
  • 记录库存流水（material_inventory_transaction）
  • 回写采购订单明细的 received_quantity 和 receive_status
  • 全部到货后采购订单 order_status 更新为"已完成"

9.4 不合格品处理规则

  • 不合格品支持5种处理方式：挑选 / 拒收 / 报废 / 特采 / 退货
  • 挑选：重新检验，更新合格/不合格数量
  • 特采：将不合格品转为合格（让步接收），可入库
  • 拒收/退货：退回供应商
  • 报废：记录报废处理
  • 不合格品处理后自动回写入库单明细的合格/不合格数量和检验状态

9.5 删除与取消规则

  • 草稿状态的采购申请/订单可直接删除
  • 已审批的单据需先反审才能删除
  • 草稿状态的入库单可删除，已入库的不可删除
  • 已审批的采购订单在未到货前可取消
