核心分流逻辑：派发时解析工艺路线，若首道工序 flowing_backward='是'，则该工序对应的物料走倒冲路线（先移库到线边仓，入库后自动扣减），其余物料走备料领料路线（先领料出库到线边仓，报工消耗）。倒冲物料仓库按三级优先级确定：routing_header.default_backflush_warehouse → routing_detail.default_repository → bom_detail.default_warehouse。入库倒冲前必须通过齐套检查，确认所有倒冲物料线边仓库存充足，否则阻止入库。

5. 入库触发倒冲扣减流程

FIFO排序ORDER BY inbound_date ASC, id ASC

9.6 倒冲扣减失败处理机制

核心原则：倒冲扣减失败 → 阻止入库 → 回滚事务。产品/半成品入库与倒冲物料消耗必须在同一事务中原子完成，否则会导致材料账务不平。
失败场景处理方式后续操作
仓库未指定抛出 BusinessError 阻止入库，回滚事务先设置线边仓，再重新入库
线边仓库存不足抛出 BusinessError 阻止入库，回滚事务先将材料从原料仓移至线边仓，再重新入库
批次不存在抛出 BusinessError 阻止入库，回滚事务先创建/移库批次到线边仓，再重新入库
扣减异常抛出 BusinessError 阻止入库，回滚事务排查原因后修复，再重新入库
