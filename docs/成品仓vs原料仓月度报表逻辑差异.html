成品仓 vs 原料仓月度报表 — 计算逻辑差异

Seals MES System | 仓储模块月度出入库报表对比分析

1. 报表入口方式

维度成品仓原料仓
入口 选择盘点单 → 自动推算报表月份 选择仓库 + 会计期间 + 可选盘点单
报表月份确定 count_period + 1个月（代码推算） 用户直接选择的 accounting_period
盘点单依赖 必选，没有则无法生成报表 可选，默认取最近的；无盘点单则期初为 0

2. 数据分组维度

维度成品仓原料仓
SQL GROUP BY item_number, quality_status item_number
Map Key ${item_number}|${quality_status} item_number
分类字段 质量状态（合格品 / 不合格品） 物料类型（原材料 / 半成品）
同物料多行 是 — 同一物料按质量状态拆行 否 — 同一物料仅一行

3. 流水表来源

维度成品仓原料仓
流水表 inventory_transaction material_inventory_transaction

4. 入库分类对比

成品仓入库分类字段原料仓入库分类字段
生产入库in_production 采购入库in_purchase
退货入库in_return 生产入库in_production
盘盈in_surplus 盘盈in_surplus
其他入库in_other 其他入库in_other
入库合计in_total 入库合计in_total

* 成品仓无"采购入库"（成品不采购）；原料仓无"退货入库"（原材料不涉及客户退货）

5. 出库分类对比

成品仓出库分类字段原料仓出库分类字段
发货出库out_shipping 领料出库out_issue
—— 倒冲出库out_backflush
—— 委外备料出库out_outsourcing
盘亏out_shortage 盘亏out_shortage
其他出库out_other 其他出库out_other
出库合计out_total 出库合计out_total

* 成品仓出库仅 3 类（发货/盘亏/其他）；原料仓出库 5 类（领料/倒冲/委外/盘亏/其他）

6. 期末计算公式

closing_qty = opening_qty + in_total - out_total

两者完全相同，按行逐条计算后再汇总合计行。

7. 表格列数

维度成品仓原料仓
总列数 16 列 18 列
基础信息列 5（编号/名称/规格/单位/质量状态） 5（编号/名称/规格/单位/物料类型）
入库子列 5（生产/退货/盘盈/其他/合计） 5（采购/生产/盘盈/其他/合计）
出库子列 4（发货/盘亏/其他/合计） 6（领料/倒冲/委外/盘亏/其他/合计）
期初 + 期末 2 列 2 列

8. 期初数据与交易筛选

维度成品仓原料仓
期初来源 stock_count_detail 按 item_number, quality_status 汇总 stock_count_detail 按 item_number 汇总
交易筛选条件 accounting_period = :reportMonth OR (ISNULL(accounting_period, '') = '' AND operation_date BETWEEN ...)
交易 GROUP BY item_number, quality_status item_number

两者交易筛选 SQL 结构相同，均优先使用 accounting_period 字段，兼容无该字段的历史数据。
