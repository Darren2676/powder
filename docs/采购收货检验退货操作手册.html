采购 → 收货 → 检验 → 退货 全流程操作手册

Seals MES System · 采购域功能操作指南

📋 手册涵盖模块
物料安全库存 → MRP运算 → 采购申请 → 采购订单 → 收货通知 → 来料入库 → 来料检验 → 合格入库/不合格处理 → 采购退货

一、原材料安全库存设置

1.1 在物料主数据中配置安全库存

安全库存是为防止物料短缺而设置的缓冲库存量。在物料主数据模块中，可以为每个原材料设置安全库存。

操作步骤：
  1. 进入 主数据管理 → 物料主数据 页面
  2. 选择 原材料 分页签
  3. 点击需要设置安全库存的物料记录，进入编辑模式
  4. 在 库存与成本 折叠面板中找到以下字段：
    • 安全库存管理（safety_stock_enabled）：选择 "Y（是）" 启用安全库存管理
    • 安全库存数（safety_stock_qty）：输入具体的安全库存阈值数量
  5. 在 生产与计划 面板中设置：
    • 采购提前期(天)：影响MRP计算中计划到货时间的估算
    • 生产提前期(天)：影响自制件计划开工时间的估算
  6. 在 质量检验 面板中设置：
    • 来料检验（incoming_inspection）：选择 "需要(Y)" 或 "不需要(N)"
    • 如果选择"需要"，可进一步设置 来料启用质量特性（enable_quality_chars）
说明：安全库存数在MRP运算中会被纳入净需求计算：
净需求 = 毛需求 - 库存现有 - 采购在途 - 生产在途 + 安全库存
即安全库存会被作为额外需求叠加到净需求中。

1.2 安全库存预警监控

系统提供独立的安全库存预警页面，实时监控库存低于安全库存阈值的物料。

操作路径：仓库管理 → 安全库存预警
页面显示以下信息：
列名说明
物料编号 / 物料名称低于安全库存的物料标识
类型原材料/半成品等物料类型
安全库存当前设定的安全库存阈值
当前库存实际在库数量（红色高亮）
差额安全库存 - 当前库存的缺口（红色高亮）
调整安全库存可直接在此页面修改安全库存数量并保存

二、MRP运算生成采购申请

2.1 MRP运算概述

MRP（Material Requirements Planning，物料需求计划）根据生产计划展开BOM，计算各级物料的毛需求与净需求，并区分自制、采购或双源决策。

MRP计算公式（采购件）
毛需求 = 上层物料净需求 × BOM用量（逐层展开）
净需求 = 毛需求 − 库存 − 在途采购 − 待执行PR + 安全库存
操作类型取决于物料属性：采购（纯外购件）、生产（自制件）、生产+采购（双源物料，需人工决策分配比例）

2.2 执行MRP运算

操作步骤：
  1. 进入 计划管理 → MRP运算 页面
  2. 在 选择生产计划 区域，系统列出所有"计划中"状态的生产计划
  3. 通过搜索条件筛选计划编号/物料编号/名称，或通过日期范围过滤计划完成时间
  4. 勾选需要参与MRP运算的生产计划（可多选），点击 "运行 MRP 计算"
  5. 等待计算完成后，下方展示MRP计算结果，包含以下关键列：
    列名说明
    BOM层物料在BOM中的层级（0=成品，1=半成品，2=原材料...）
    毛需求未扣除库存前的总需求量
    库存/在制品/在途采购可抵消需求的各类供给
    待执行PR已生成但尚未转单的采购申请数量
    安全库存物料的安全库存阈值（从物料主数据带出）
    净需求最终需要补充的数量（红色加粗表示>0）
    操作类型生产（蓝色）/ 采购（绿色）/ 双源（橙色）
    业务范围标识物料可用于"生产"还是"采购"
    计划开工/完工根据提前期自动推算的时间节点
  6. 系统默认选中所有净需求 > 0 的行
  7. 通过分页签可快速筛选：全部 / 生产单 / 采购申请 / 双源待决策

2.3 双源物料决策

当物料同时支持生产和采购时（action_type = '生产+采购'），系统弹出 "双源物料分配决策" 窗口：

  1. 窗口列出所有双源物料，显示净需求、库存、在制品、在途采购等信息
  2. 显示该物料是否有制造BOM（无BOM选择生产需后续补建）
  3. 为每行填写 生产数量 和 采购数量，两者之和须等于净需求
  4. 可使用"全部生产"或"全部采购"批量操作选中的行
  5. 生产数量与采购数量联动：修改其中一个，另一个自动调整使总和=净需求
  6. 确认后点击 "确认并执行"

2.4 确认执行MRP

  1. 确认对话框显示将执行的物料数量
  2. 点击 "确认执行" 后系统自动：
    • 为"采购"类型的物料生成 采购申请单
    • 为"生产"类型的物料生成 生产工单
    • 双源物料根据分配比例同时生成两种单据
  3. MRP运行状态变为 "已确认"
⚠ 重要约束：MRP执行后生成的生产工单与采购申请为 配套关联单据。删除时必须同时删除二者，不可单独删除其中一个。已在MRP结果区域有明确提示。

2.5 查看MRP历史

通过 计划管理 → MRP运算历史 可查看所有历史MRP运行记录： - 支持按状态筛选（已计算/已确认/已取消） - 点击 "查看" 可回溯具体的运算详单 - "已计算" 状态的记录可 取消（不再执行），"已取消" 状态可 删除

三、采购申请单管理

3.1 采购申请单列表

进入 采购管理 → 采购申请单 页面。采购申请单是MRP运算自动生成或手动创建的采购需求单。

列表关键字段：
字段说明
采购申请号系统自动生成的唯一编号
来源单号MRP运算编号（自动生成时）或手动填写的来源
生产计划编号关联的生产计划（逗号分隔，多条计划用逗号拼接）
审批状态草稿 → 待审批 → 已审批 / 已驳回
执行状态未执行 → 部分转单 → 已转单
申请原因生产缺料 / 安全库存补充 / 其他

3.2 新建/编辑采购申请

  1. 点击 "新建" 按钮打开编辑弹窗
  2. 填写表头信息：申请日期、申请人、部门、申请原因（下拉选择）、来源单号、生产计划编号
  3. 在物料明细区域点击 "添加行"，搜索并选择物料：
    • 选择物料后自动带入物料名称、规格、单位
    • 填写申请数量、期望到货日
    • 可选填建议供应商（支持搜索选择）
  4. 保存后采购申请单状态为 "草稿"

3.3 审批流程

  1. 草稿状态：可编辑、删除 → 点击 "提交审核" 进入待审批
  2. 待审批状态：审核人可 "审核通过" 或 "撤回提交"
  3. 已审批状态：可 "反审退回" 回退到草稿
  4. 支持批量操作：批量提交、批量审批、批量撤回、批量反审

3.4 采购申请明细视图

通过 采购管理 → 采购申请明细 可跨单据查看所有采购申请的明细行。支持： - 按行状态筛选（未执行/部分转单/已转单） - 选中多行后一键 "转采购订单" - 导出选中行到Excel

四、采购申请转采购订单

4.1 从采购申请单转订单

  1. 在采购申请单列表中，找到 审批状态=已审批 且 执行状态≠已转单 的记录
  2. 点击更多操作 → "转采购订单"
  3. 系统弹出转单窗口，显示该申请单下 可转数量 > 0 的明细行
  4. 填写转单信息：
    • 供应商（必选）：选择后系统自动填充供应商的采购负责人、联系人、联系方式
    • 交货日期
    • 采购负责人（自动填充当前用户名，支持模糊搜索）
  5. 勾选要转单的明细行（默认显示"申请数量-已转单数量=可转数量"）
  6. 自动从 采购价目表 查询该供应商对应物料的单价，也可手动输入
  7. 如果同一采购申请中存在相同物料编码的多条明细，系统会弹窗询问是否合并
  8. 确认后生成 采购订单
自动取价机制：选择供应商后，系统调用 queryPurchasePrice 接口自动从已审批的采购价目表中匹配该供应商+物料的有效单价。如果查不到价格，单价为空需手动填写。

4.2 从采购申请明细转订单（跨单据批量）

在 采购管理 → 采购申请明细 页面：

  1. 勾选多个采购申请单的明细行（必须已审批且有剩余数量）
  2. 点击 "转采购订单"
  3. 系统按申请单号分组，每组生成一个采购订单
  4. 同样支持相同物料编码合并提示

五、采购订单管理

5.1 采购订单列表

进入 采购管理 → 采购订单 页面。

列表关键字段：
字段说明
采购订单号系统自动生成的唯一编号
来源申请生成该订单的采购申请号
审批状态草稿 → 待审批 → 已审批
执行状态待执行 → 执行中 → 已完成 / 已关闭
退货状态显示关联的退货数量和状态（待退货/换货中/已退货）

5.2 订单操作

  • 编辑：仅草稿状态可编辑（供应商选择后自动填充联系人信息）
  • 提交审批 → 审批 → 撤回 → 反审批：标准审批流程
  • 打印：已审批状态的订单支持打印（调用服务端生成打印页面）
  • 入库：已审批且非已完成/已关闭的订单可操作入库（详见第六章）
  • 退货：已审批且有入库记录的订单可操作退货
  • 关闭：手动关闭订单，关闭后不可再入库
  • 批量操作：批量提交/审批/撤回/反审/关闭

5.3 查看订单详情

点击 "查看" 可查看订单的物料明细（订单数量、单价、金额、已入库数量、到货状态）以及关联的退货单列表。

六、来料入库与检验流程

6.1 流程概览

来料收货完整流程
采购订单（已审批） → 选择明细行 → 创建收货通知 → 确认收货 → 生成入库单
└─ 物料的 incoming_inspection = 'Y' → 自动入 待检仓 → 自动生成 来料检验单
└─ 物料的 incoming_inspection = 'N' → 直接入 默认原料仓（无需检验）

6.2 从采购订单直接入库

  1. 在 采购订单 列表页，点击已审批订单的更多 → "入库"
  2. 系统弹出"来料入库"窗口，显示该订单下 已入库 < 订单数量 的明细行
  3. 每行显示：
    • 来料检验：是/否（来自物料主数据的 incoming_inspection）
    • 入库仓库（目标仓库）：
      • 如果 需要来料检验 → 显示"待检仓"（橙色标签），合格/不合格数量不可编辑
      • 如果 免检 → 显示物料的默认仓库，合格数量=本次入库数量，不合格数量=0
    • 本次入库：填写入库数量（免检时修改入库量会自动同步合格数量）
  4. 系统根据物料检验标志自动选择默认仓库：
    • 全部需检验 → 默认"待检仓"
    • 全部免检 → 默认第一个物料的默认仓库
    • 混合 → 默认"待检仓"
  5. 点击 "确认入库" 后系统：
    • 创建 来料入库单 并立即确认
    • 对需要检验的物料自动创建 来料检验单，提示检验单号

6.3 从采购订单明细创建收货通知

通过 采购管理 → 采购订单明细 页面操作：

  1. 勾选同一采购订单的明细行（必须已审批且未全部到货）
  2. 点击 "收货通知" 按钮
  3. 填写收货通知信息：
    • 采购订单号（自动带入，不可修改）
    • 送货单号（供应商的送货单据号）
    • 收货日期
  4. 每行自动计算可收货数量（= 订单数量 - 已入库），支持手动调整本次收货数量
  5. 确认创建后生成 采购收货通知

6.4 收货通知管理

进入 采购管理 → 采购收货通知 页面。

新建收货通知（另一种方式）：
  1. 点击 "新建"，搜索并选择采购订单号（自动筛选已审批且未关闭的订单）
  2. 选择订单后自动加载可收货明细，默认收货数量=剩余未入库数量
  3. 填写送货单号和收货日期，调整收货数量
  4. 保存生成收货通知
确认收货：
  1. 在收货通知列表中，点击 "确认收货"（仅"待确认"状态可用）
  2. 在确认弹窗中：
    • 批量设置仓库：选择一个仓库后填充到所有行
    • 每行可单独选择入库仓库
    • 填写每行的 合格数量 和 不合格数量（两者之和=收货数量）
  3. 确认后生成入库单，物料进入对应仓库

七、来料检验管理

7.1 来料检验单列表

进入 质量管理 → 采购质量检验 页面。检验单由入库时自动生成（物料来料检验=Y时），也可手动创建。

统计看板：
指标说明
来料合格率合格总量/来料总量 × 100%（≥95%绿色，否则红色）
检验单总数/已完成当前范围内检验单的整体概况
合格总量/来料总量数量维度统计
不合格总量不合格品数量汇总
列表关键字段：
字段说明
检验单号系统自动生成（格式 IN-xxxxxxxx）
入库单号关联的来料入库单
到货数量本次收货数量
抽检数抽样检验数量
检验方案自动匹配的来料检验方案
检验状态待检验（橙色）→ 检验中（蓝色）→ 已完成（绿色）
检验结论合格（绿色）/ 不合格（红色）/ 让步接收（橙色）
缺陷分类缺陷所属类别
处理方式挑选/拒收/报废/特采/退货（彩色标签）

7.2 新建检验单（手动）

  1. 点击 "新建检验单" 按钮
  2. 填写：物料编号（自动匹配检验方案）、物料名称、规格、单位、供应商、到货数量、来料入库单号、采购订单号、批次号
  3. 系统自动匹配该物料对应的 收料检验方案 和 来料检验规范

7.3 执行检验

  1. 在检验单列表中，点击 "检验" 按钮进入检验执行界面
  2. 检验界面展示：
    • 基本信息区：检验单号、入库单号、采购订单、供应商、物料信息、到货数量、抽样数量、检验方案、检验方法、抽检方式
    • 质量特性检测区（当物料启用了来料质量特性时显示）：列出所有质量特性项，每项包含：
      • 下限/标准值/上限（来自检验规范）
      • 实测值（检验员填写）
      • 判定：系统根据实测值与限值自动判定合格/不合格
        • 计量型：实测值与上下限比较
        • 计件型/计点型：实测值与标准值比较
    • 缺陷记录与检验结论区（编辑模式）：
      • 汇总数量行：显示到货数量、抽检数量、合格数量（自动计算）、不合格数量（汇总）
      • 缺陷明细表格：按缺陷名称分行录入
        • 每行填写：不合格数量、缺陷分类（下拉选择）、缺陷名称（联动过滤）、缺陷原因、检验结论（合格/不合格/让步接收）
        • 可添加多行缺陷记录
        • 不合格数量汇总自动同步到主表
        • 合格数量 = 到货数量 - 不合格数量汇总（自动计算）
      • 检验员：自动默认为当前用户，可修改
      • 备注：自由文本
  3. 点击 "保存" 保存检验数据（状态仍为检验中，可继续修改）
  4. 点击 "完成检验"：
    • 系统校验：检验结论必须已填写
    • 如果启用了质量特性，校验所有特性行是否都已填写实测值
    • 完成后检验单状态变为 "已完成"，不可再修改
    • 合格数量回写入库单，并触发后续入库流程
⚠ 注意：完成检验前请确保所有质量特性实测值已填写、缺陷记录完整、检验结论正确。完成后数据不可再修改。

八、检验合格入库与不合格品处理

8.1 检验合格后入库

检验完成后，合格数量的物料从待检仓转移到物料的 默认原料仓。

合格物料流转路径
采购收货 → 入库到待检仓（需检验物料）→ 检验完成 → 合格数量 → 自动转移至物料 默认仓库（default_warehouse）
默认仓库设置：物料的默认仓库在物料主数据中的 库存与成本 面板设置（default_warehouse字段）。入库时如未指定仓库，系统默认使用该设置。

8.2 来料入库单管理

进入 仓库管理 → 来料入库 页面查看所有采购入库单。

  • 草稿 状态的入库单可 "确认入库" 或 "删除"
  • 已入库 状态的入库单可 "撤回入库"（反转所有库存变动，关联检验单将被作废）
  • 点击 "查看" 可查看入库单详情：每行显示订单数量、已入库、本次入库、合格数量、不合格数量、检验单号、检验状态、批次号

8.3 不合格品处理——创建NC单

当检验结论为 "不合格" 时，需进行不合格品处理。

  1. 在 采购质量检验 列表页，找到状态为"已完成"且检验结论为"不合格"的检验单
  2. 点击 "不合格品处理" 按钮
  3. 系统弹出"不合格品处理"窗口：
    • 显示检验单基本信息：检验单号、物料、不合格数量、合格数量
    • 显示 不合格项明细：每个缺陷行显示缺陷分类、缺陷名称、不合格数量、检验结论、NC单状态
    • 让步接收的行标注"无需NC单"
    • 不合格的行标注"待创建NC单"
  4. 点击 "确认创建NC单"，系统为每个不合格缺陷行创建独立的 不合格品处理单（NC单）
提示：NC单创建后，需要在 "待处理不合格品" 页面分别对每个NC单选择处理方式。让步接收的缺陷行不创建NC单。

8.4 待处理不合格品

进入 质量管理 → 待处理不合格品 页面。

处理步骤：
  1. 在列表中找到来源类型为 "来料检验" 的待处理NC单
  2. 点击 "处理" 按钮打开处理窗口
  3. 选择 处理方式（根据来源类型动态显示）：
    处理方式适用来源说明
    挑选来料检验对不合格批进行挑选，填写挑选后合格数量和不合格数量
    拒收来料检验直接拒收不合格数量，不入库
    报废来料/生产将不合格品报废，选择批量/单件，填写报废数量
    特采来料检验特别采用，选择特采入库仓库（默认物料默认仓库），填写特采数量
    退货来料检验退回供应商，选择退货退款/退货换货。系统自动创建采购退货单
    返修生产检验返回生产工序返修，填写返修目标工序号（不适用于来料）
    让步接收生产检验让步接收不合格品（不适用于来料）
  4. 填写对应的处理参数（数量、仓库等）和处理备注
  5. 点击 "确认处理"
退货处理自动化：选择"退货"处理方式后，系统将自动创建采购退货单，并在退货单审批后执行退货出库。处理完成后的NC单可通过 "撤销" 回退。

8.5 不合格处理单列表

进入 质量管理 → 不合格处理单 查看所有已处理的NC单。 - 支持按来源类型（来料检验/生产检验/委外检验）筛选 - 显示关联单号（返修单号/入库单号/退货单号） - 已处理的可撤销处理

九、采购退货管理

9.1 采购退货概述

采购退货用于将已入库的来料退回供应商。退货分为两种类型：

  • 退货退款：退回物料并索回货款
  • 退货换货：退回不合格物料，等待供应商补发替换品

9.2 创建采购退货单

方式一：从采购订单页进入
  1. 在 采购订单 列表页，点击已审批订单的更多 → "退货"
  2. 系统自动跳转到采购退货页面并预填采购订单号
方式二：手动创建
  1. 进入 采购管理 → 采购退货 页面
  2. 点击 "新建"
  3. 选择 采购订单号：系统自动加载该订单的已入库物料明细
  4. 选择 退货类型：退货退款 / 退货换货
  5. 选择 退货仓库：物料将从该仓库出库退回
  6. 填写 退货原因
  7. 在明细区填写每行的 退货数量（不能超过已入库数量）和 单价
    • 退货金额 = 退货数量 × 单价（自动计算）
    • 如果选择"退货换货"，还需填写换货数量
  8. 保存退货单

9.3 退货单审批与执行

状态流转：
  1. 草稿 → 提交审批 → 待审批 → 审批通过 → 已审批
  2. 已审批的退货单 → 点击 "执行退货"：
    • 系统扣减对应仓库库存
    • 回写采购订单的退货数量
    • 退货状态变为 "已退货"
  3. 如果是 退货换货 类型，退货完成后：
    • 等待供应商补发替换物料
    • 收货后点击 "换货入库"，将替换物料入库
    • 换货状态变为 "已换货"
采购退货单关键字段：
字段说明
退货单号系统自动生成
采购订单号关联的采购订单
退货类型退货退款（红色）/ 退货换货（橙色）
退货状态待退货（蓝色）→ 已退货（绿色）
换货状态仅在退货换货时显示：待换货（橙色）→ 已换货（绿色）

十、采购退货出库

退货执行后，物料的出库操作通过 仓库管理 → 采购退货出库 页面管理。该页面展示所有因采购退货产生的出库记录。

10.1 原材料手工入库（补充）

对于非采购订单驱动的入库场景，可使用 仓库管理 → 采购入库 进行原材料手工入库：

  1. 选择入库仓库和会计期间
  2. 添加物料行：搜索物料编号，自动带出名称、规格、单位
  3. 填写数量、批次号、供应商
  4. 提交入库

十一、完整操作流程演示

🔗 采购全流程端到端走查
步骤1：设置物料安全库存与检验属性
在 物料主数据 中设置原材料的安全库存数量、来料检验标志（Y/N）、默认仓库、采购提前期。
步骤2：执行MRP运算
进入 MRP运算 → 选择生产计划 → 运行MRP计算 → 查看结果 →（如有双源物料则决策分配）→ 确认执行。系统自动为采购件生成采购申请单。
步骤3：审批采购申请
进入 采购申请单 → 找到MRP生成的草稿申请 → 提交审核 → 审核通过。
步骤4：转采购订单
已审批的采购申请 → 更多 → "转采购订单" → 选择供应商（自动取采购价）→ 勾选明细行 → 确认转单 → 生成采购订单。
步骤5：审批采购订单
采购订单 → 提交审核 → 审核通过。
步骤6：创建收货通知
方式A：采购订单 → "入库" → 填写入库数量 → 确认入库（同时创建入库单和检验单）
方式B：采购订单明细 → 勾选行 → "收货通知" → 填写送货单号 → 生成收货通知 → 采购收货通知 → 确认收货
步骤7：来料检验（仅需检验的物料）
进入 采购质量检验 → 点击检验单的 "检验" 按钮 → 填写实测值 → 录入缺陷记录 → 确定检验结论 → "完成检验"。
合格数量自动回写入库单并转移至默认原料仓。
步骤8a：检验合格 → 正常入库
合格物料从待检仓转移至默认原料仓，流程结束。
步骤8b：检验不合格 → 不合格品处理
检验单 → "不合格品处理" → 确认创建NC单 → 待处理不合格品 → 选择处理方式：
  • 挑选 → 填写挑选后合格/不合格数量
  • 拒收 → 不入库直接拒收
  • 报废 → 选择报废类型和数量
  • 特采 → 选择特采仓库入库
  • 退货 → 选择退货类型，系统自动创建采购退货单 → 审批 → 执行退货出库
步骤9：采购退货流程
如果选择了退货处理或手动创建退货单：
采购退货 → 新建退货单（选择采购订单）→ 填写退货数量和原因 → 保存 → 提交审批 → 审批 → "执行退货"（扣减库存）→ 如果是换货：收货后 "换货入库"。
步骤10：查看采购入库单
仓库管理 → 来料入库 可查看所有采购入库单记录，包含合格/不合格数量、检验单号、检验状态等完整追溯信息。
