样品申请管理功能方案

Seals MES System  |  2026年5月

一、业务流程

销售部新建申请 → 草稿
      │ 提交
      ▼
   待研发（技术部待接收）
      │ 接收
      ▼
   研发中（技术部填写实验室数据）
      │ 完成
      ▼
   已完成 → 自动通知销售部 + 管理人员
状态可操作角色可用操作
草稿销售部编辑、提交、删除
待研发销售部 / 技术部撤回（销售）/ 接收（技术）
研发中技术部填写实验室数据、完成研发
已完成全部查看

二、数据库设计

2.1 主表 sample_request

request_number NVARCHAR(30) PK -- 编号，格式 SR-YYYYMMDD-NNN
request_date DATE -- 申请日期
deadline_date DATE -- 需要完成日期
applicant NVARCHAR(50) -- 申请人
urgency NVARCHAR(20) DEFAULT '一般' -- 紧急程度
customer_name NVARCHAR(200) -- 客户名称
market NVARCHAR(100) -- 市场
competitor NVARCHAR(200) -- 竞争对手
estimated_price DECIMAL(18,4) -- 预估售价
potential_usage DECIMAL(18,4) -- 潜在用量
has_order NVARCHAR(10) -- 是否已有订单
coating_workpiece NVARCHAR(200) -- 喷涂工件
substrate NVARCHAR(100) -- 基材
pretreatment NVARCHAR(100) -- 前处理
spray_gun_type NVARCHAR(100) -- 喷枪类型
recovery_system NVARCHAR(100) -- 回收系统
oven_type NVARCHAR(100) -- 烤炉类型
color_spec NVARCHAR(500) -- 颜色
product_type NVARCHAR(200) -- 产品类型
film_thickness NVARCHAR(100) -- 膜厚范围
gloss_range NVARCHAR(100) -- 光泽范围
curing_condition NVARCHAR(100) -- 固化条件
other_requirements NVARCHAR(1000) -- 其它性能要求
status NVARCHAR(20) DEFAULT '草稿' -- 流程状态
approval_status NVARCHAR(20) DEFAULT '草稿' -- 审批状态
created_by NVARCHAR(50) -- 创建人
created_at DATETIME DEFAULT GETDATE()
updated_at DATETIME DEFAULT GETDATE()

2.2 明细表 sample_request_item

id INT IDENTITY(1,1) PK
request_number NVARCHAR(30) FK
item_type NVARCHAR(50) -- 样板/样粉/相溶性测试/测试报告/其他
quantity DECIMAL(18,4)
unit NVARCHAR(20) -- 片/公斤/次/份
is_requested BIT DEFAULT 0
sort_order INT DEFAULT 0

2.3 实验室结果表 sample_request_lab

id INT IDENTITY(1,1) PK
request_number NVARCHAR(30) FK
lab_panel_qty DECIMAL(18,4) -- 寄出样板数量
lab_powder_qty DECIMAL(18,4) -- 寄出样粉数量(kg)
completion_date DATE -- 完成日期
product_number NVARCHAR(50) -- 产品编号
formula_cost DECIMAL(18,4) -- 配方成本
lab_remark NVARCHAR(2000) -- 备注
received_by NVARCHAR(50) -- 接收人
received_at DATETIME -- 接收时间
completed_by NVARCHAR(50) -- 完成人
completed_at DATETIME -- 完成时间
