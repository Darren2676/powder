生产执行全流程逻辑流程图

睿信橡胶密封件MES系统 | 从备料出库、按工序报工、完成自检、包装入库，到在制品VIP报告，以及工序错误撤销重报的全链路业务流程
文档说明：本文档完整梳理生产执行阶段的全链路业务逻辑，涵盖8个阶段：
阶段1 备料领料出库 — 领料出库/补料出库/退料入库及仓库流水
阶段2 按工序报工 — 首道→末道逐步报工，含门控检查与状态联动
阶段3 生产检验 — 自检/专检自动创建、检验执行、检验门控
阶段4 不合格品处理 — 返修/报废/让步接收三种方式
阶段5 包装入库 — 成品批次化入库、倒冲扣减、装箱管理
阶段6 在制品VIP报告 — 按生产单/工作中心/线边仓流水
阶段7 工序错误撤销与重报 — 发现已报工工序错误的完整撤销再报工流程
阶段8 状态变化矩阵与关键数据实体

仓库流水类型汇总：
① 出库/领料出库 — 领料扣减原料仓库存
② 入库/退料入库 — 退料恢复原料仓库存

④ 入库/领料撤回 — 撤消领料，恢复库存
⑤ 入线边/领料入线 — 领料进入线边仓
⑥ 出线边/退料出线 — 退料出线边仓（条件性）

⑧ 入线边/退料撤回 — 撤消退料入线边仓（条件性）

检验门控规则：
① 上道工序 inspect_status = 检验合格 → 放行
② 上道工序 inspect_status = 无需检 → 放行
③ 上道工序 inspect_status = 已处理 → 放行（返修/让步接收后）
④ 上道工序 inspect_status = NULL（旧数据/未检验）→ 阻止报工，提示请先完成检验
⑤ 上道工序 inspect_status = 待检验 → 阻止
⑥ 上道工序 inspect_status = 检验中 → 阻止
⑦ 上道工序 inspect_status = 检验不合格 → 阻止，需先处理不合格品
