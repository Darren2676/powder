一、总体概览与业务流程

1.1 核心业务流程图

端到端流程：
销售预测 ──┐
    ├──→ MPS 计算 → 生产计划 → 生产派发 → 报工 → 入库
销售订单 ──┘
    └──→ 待发货列表 → 发货申请 → 仓库审核 → 发货单 → 签收
                  │
                  └──→ 客户退货

1.2 涉及的功能模块

二、销售价目表管理

2.1 功能概述

销售价目表用于维护不同客户、不同成品的销售价格。在后续销售订单录入时，系统会根据客户和物料自动匹配有效的价目表价格。

2.2 列表页操作

  • 搜索：输入编号/名称/客户进行模糊搜索
  • 审批状态筛选：草稿 / 待审批 / 已审批
  • 导出/导入：支持 Excel 导出全部记录，支持下载模板后批量导入
  • 列设置：个性化列显示、调整列顺序、列宽拖拽调整

2.3 新建/编辑销售价目表

操作步骤：
  1. 点击「新建」按钮，打开创建弹窗
  2. 填写价目表名称（必填）
  3. 选择客户（下拉搜索），选择后自动带出客户编号、名称、分类
  4. 设置单价类型：含税 / 未税
  5. 选择币种：CNY / USD / EUR
  6. 设置有效期开始和结束日期
  7. 在物料明细表中点击「添加行」，逐行添加物料：
    • 选择物料（下拉搜索），自动带入名称、规格、分类
    • 填入含税单价或未税单价，系统自动按税率互相换算
    • 税率默认为 13%，可修改
    • 可选勾选分段价格，设置起始数量和结束数量（空=无上限）实现阶梯价
    • 可选设置含税最低价和不含税最低价作为销售底价
  8. 点击「保存」

2.4 审批操作

  • 草稿状态：可编辑/删除 → 提交审批
  • 待审批状态：审批通过 / 撤回审批
  • 已审批状态：反审批（退回草稿）
💡 关键特性：
  • 含税单价与未税单价双向自动换算：\(未税 = 含税 ÷ (1 + 税率\%)\)
  • 支持分段阶梯定价：不同数量区间适用不同价格
  • 已审批的价目表才能被销售订单自动引用

三、销售预测管理

3.1 功能概述

销售预测用于提前规划未来一段时间内各成品的预期需求量。预测数据将作为 MPS 主生产计划的重要需求来源之一。

3.2 列表页功能

  • 搜索：预测编号 / 客户名 / 创建人
  • 审批状态筛选：草稿 / 审批中 / 已审批
  • 导出 / 导入：支持 Excel 格式导出和导入
  • 表格展开：每行可展开，查看预测明细行（物料、数量、开始/结束日期、消耗状态）

3.3 新建销售预测

操作步骤：
  1. 点击「新建预测」
  2. 选择客户（下拉搜索）
  3. 设置预测日期
  4. 在预测明细中点击「添加行」，逐行填写：
    • 物料：下拉搜索成品，自动带入名称、规格、单位
    • 客户物料号：可输入客户方物料号，回车自动反向查询产品
    • 开始日期 / 结束日期：定义该预测的时间范围
    • 预测数量
  5. 验证：至少一条有效明细（物料已选 + 数量>0 + 日期已填）
  6. 点击「创建」

3.4 审批流程（工作流引擎）

  • 草稿 → 提交审核（启动工作流审批）
  • 审批中 → 撤回提交
  • 已审批 → 反审退回（退回草稿）
  • 支持批量提交：勾选多条草稿记录后，批量启动审批流程

3.5 消耗追踪

  • 当销售订单创建时，系统会自动消耗对应的销售预测
  • 点击「消耗记录」查看：哪个销售订单、消耗了多少数量、消耗时间
  • 消耗状态有：未消耗 部分消耗 已消耗

四、成品安全库存设置

4.1 功能概述

安全库存是 MPS 计算时的重要参数。MPS 在计算净需求时会将安全库存作为"最低保有量"考虑在内，确保生产计划不会导致库存低于安全线。

4.2 设置入口

路径：基础数据 → 物料管理，在「成品」Tab 下找到目标物料。

4.3 关键字段

字段说明MPS影响
safety_stock_enabled安全库存管理开关（是/否）开启后才参与MPS安全库存计算
safety_stock_qty安全库存数量净需求=毛需求-库存现有+安全库存
lead_time_days生产提前期（天）用于计划完成时间倒推
batch_production_quota批次产量定额用于计算所需台班数
💡 MPS 中安全库存的作用：
如果某成品库存现有 100 件，安全库存设为 50 件，则"可用库存"实际为 50 件（100-50）。MPS 计算时净需求 = max(毛需求 - 库存现有, 0) + 安全库存，确保生产后库存水平在安全线以上。

五、销售订单录入

5.1 功能概述

销售订单是正式的客户合同录入。录入时系统会自动从销售价目表匹配价格、自动从客户物料对照表查找客户方物料号、自动消耗销售预测。

5.2 列表页功能

  • 搜索：销售订单编号 / 客户 / 产品
  • 表格列：订单编号、客户信息、订单/交货日期、订单状态、审批状态等
  • 多交期标识：如明细行存在不同交货日期，表头交货日期列显示红色
  • 批量操作：批量提交、批量审批、批量撤回、批量反审、批量关闭

5.3 新建销售订单

操作步骤：
  1. 点击「新建」按钮
  2. 客户信息区：
    • 选择客户（下拉远程搜索），自动带入：客户名称、销售负责人、联系人、联系方式
  3. 订单信息区：
    • 订单日期、交货日期、订单状态（待执行/生产中/已完成/已取消）
    • 客户采购订单号
  4. 产品明细行（每一行）：
    • 搜索选择成品物料，自动带入：名称、规格、单位、产品图号
    • 自动关联客户物料对照（客户物料号、客户物料描述）
    • 自动获取价目表价格：调用 getSalesPriceForOrder 接口，根据客户+物料从已审批价目表中匹配有效价格
    • 修改数量后，金额自动计算：\(金额 = 数量 × 单价\)
    • 支持输入客户物料号回车反向查询产品
    • 支持每行独立设置交货日期和承诺交货日期
  5. 验证：客户必选、明细行不得有空单价的物料行
  6. 点击「保存」

5.4 详情弹窗操作

  • 点击「详情」打开详情弹窗
  • 详情弹窗中可直接新增明细行、编辑明细行（草稿和已审批状态均可）
  • 修改明细行的产品、数量、单价、交货日期、承诺交货日期

5.5 审批流程

  • 草稿：可编辑、可删除 → 提交审核
  • 待审批：审核通过 / 撤回提交
  • 已审批：反审退回（草稿），已审批后不可删除
  • 支持批量审批操作（批量提交/审批/撤回/反审/关闭）
💡 价格自动获取机制：
录入明细行的物料时，系统自动根据客户编号 + 物料编号搜索已审批的销售价目表。如果匹配到有效价格（在有效期内的），自动填入单价并计算金额。如果未匹配到价格，单价默认为 0，用户需手工填写。
📎 客户物料对照：
如果该客户-物料在「客户物料对照表」中有映射记录，录入产品后会自动填入客户方物料号和描述。也可以手工输入客户物料号并回车，系统反向查询出对应的内部产品信息。
⚠️ 创建校验：
新建订单时，如果明细行中某产品单价为 0，系统会拒绝提交并提示具体行号。请确保所有产品均已录入有效的单价信息。

六、MPS 主生产计划计算

6.1 功能概述

MPS（Master Production Schedule）是计划模块的核心。它综合销售预测 + 销售订单的需求，扣除库存现有 + 在途数量，考虑安全库存，计算出每个成品的净生产需求。

6.2 页面入口

路径：计划 → MPS主计划

6.3 MPS 计算公式

MPS 计算逻辑：
① 毛需求 = max(预测需求, 订单需求) + 退货数量
② 订单需求 = 原始订单数量 - 已发数量
③ 净需求 = 毛需求 - 库存现有 - 采购在途 - 生产在途 + 安全库存
净需求 > 0 表示需要安排生产；净需求 ≤ 0 表示库存充足，无需生产

6.4 操作步骤

  1. 可选设置日期范围（筛选特定时间段的预测和订单）
  2. 可选设置客户筛选（仅看指定客户的需求）
  3. 点击「计算 MPS」按钮
  4. 系统显示计算结果：
    • 顶部统计：物料种数、需生产种数
    • 表格列：物料编号/名称/规格、预测需求、订单需求、毛需求、库存现有、采购在途、生产在途、安全库存、净需求
    • 净需求 > 0 以红色加粗显示，≤ 0 以绿色显示

6.5 从需求来源导入生产计划

  1. 在 MPS 结果表格中选中一行（单选，仅净需求 > 0 的行可选）
  2. 点击「从销售订单导入」按钮
  3. 弹出对话框中，显示该物料所有未完成的销售订单明细行和销售预测明细行（混合列表）
  4. 勾选需要导入的需求来源行，点击「确认导入」
  5. 系统自动创建生产计划，并回写对应源单的生产状态
💡 导入说明：
  • 来源类型包含：销售订单（未完成发货的）、销售预测（未开始的）
  • 导入后，销售订单明细行的「生产状态」将更新为"已加入计划"
  • 导入后，预测明细行的「计划状态」将更新为"计划中"
  • 可以在导入对话框中搜索订单号/客户/产品编号等

七、生产计划管理

7.1 功能概述

生产计划（计划管理）存储所有需要生产的成品清单。除了从 MPS 导入外，也可以手工创建、从销售订单导入、从预测导入。

7.2 列表页功能

  • 搜索：生产计划编号 / 产品编号 / 产品名称
  • 审批状态筛选：草稿 / 待审批 / 已审批
  • MRP状态筛选：未运行 / 已运行
  • 导出 / 导入：Excel 格式
  • 批量审批操作

7.3 新建生产计划

  1. 点击「新建」
  2. 搜索选择成品物料（AutoComplete 远程搜索），自动带入：名称、单位、规格、产品图号、胶料编号、班产定额
  3. 填写计划数量，系统自动计算台班数（计划数量 ÷ 班产定额，向上取整）
  4. 设置计划完成时间
  5. 保存

7.4 从销售订单 / 预测导入

除了从 MPS 导入，生产计划还可以直接从销售订单或销售预测导入：

  • 从销售订单导入：选择未完成的销售订单明细行
  • 从预测导入：选择未开始的预测明细行

7.5 生产计划状态流转

草稿 → 提交审批 → 待审批 → 审批通过（已审批）→ 加入生产任务 → 生产单派发 → 备料出库 → 连续报工 → 生产检验 → 生产入库

八、待发货与发货管理

8.1 待发货列表

路径：销售 → 待发货列表

展示所有已审批、未完成发货的销售订单明细行。关键信息包括：订单号、产品信息、订单数量、已发数量、已申请数量、待发数量（红色）。

8.2 生成发货申请

  1. 在待发货列表中勾选需要发货的明细行（可多选）
  2. 系统校验：选中的行必须属于同一客户（不同客户无法合并发货）
  3. 点击「生成发货申请」按钮
  4. 弹出确认窗口，显示选中的明细行，每行本次发货数量默认为待发数量上限
  5. 可修改本次发货数量（支持部分发货）
  6. 可选填写备注
  7. 点击「确认提交」
  8. 系统生成发货申请单，回写销售订单明细行的"已申请数量"
⚠️ 注意：
  • 待发数量 = 订单数量 - 退货数量 - 已发货数量
  • 一次只能为同一客户的订单生成发货申请
  • 已申请但未发货的数量会占用额度，不可重复申请

8.3 发货申请管理

路径：销售 → 发货申请管理

8.3.1 列表页

  • 搜索：申请编号 / 客户
  • 状态筛选：待审核 / 已审核 / 已发货 / 已取消
  • 批量操作：批量审核、批量取消、批量删除（仅待审核）

8.3.2 状态流转

发货申请状态机：
待审核 ──→ 已审核 ──→ 已发货
　│　　　　　│　　　　　│
　└──→ 已取消　└──→ 已取消　└──→ 撤回出库（恢复为已审核）

8.3.3 操作详解

操作条件说明
查看任意状态打开详情弹窗，查看申请头信息和发货明细
编辑待审核修改发货数量、备注
审核通过待审核仓库确认发货申请，状态变为已审核（可生成发货单）
撤消审核已审核撤销审核，退回待审核
确认发货已审核仓库确认实际出库，生成发货单，扣减库存
撤回出库已发货撤回最近一次出库记录，库存恢复，状态回到已审核
取消申请待审核或已审核取消发货申请，释放已申请额度
删除待审核物理删除发货申请
💡 批量审核：
勾选多条"待审核"的发货申请，点击「批量审核」一键通过。

九、发货单管理

路径：销售 → 发货单管理

9.1 发货单生成

当发货申请的状态变更为「已发货」时，系统自动生成对应的发货单。发货单记录了实际的出库信息。

9.2 列表页功能

  • 搜索：发货单号 / 客户 / 承运商 / 运单号
  • 状态筛选：已发货 / 已签收 / 已取消
  • 列信息：发货单号、客户名称、出库仓库、发货日期、状态、承运商、运单号、运费等

9.3 发货单操作

① 查看详情

点击「详情」查看发货单完整信息：

  • 头信息：发货单号、客户、仓库、日期、状态、物流信息
  • 发货明细：关联的发货申请号、销售订单号、产品信息、发货数量
  • 批次明细：展开明细行查看每批次的具体出库批次号和数量
  • 开票状态：点击可查看关联的销售发票（未开票/部分开票/已开票）

② 编辑物流信息

点击「物流」填写或修改：承运商、运单号、运费、收货地址、联系人、联系电话。

③ 打印发货单

点击「打印」，系统自动生成格式化的发货单页面（A4），包含：

  • 发货单抬头（单号）
  • 客户信息、仓库、物流信息
  • 发货明细表（序号、产品编号、名称、规格、单位、数量、销售订单号）
  • 批次明细（如有多批次）
  • 签名区（制单人、发货人、收货人）
  • 一键浏览器打印

④ 签收确认

当客户收到货物后，点击「签收」确认，发货单状态变更为"已签收"。

十、客户退货管理

路径：销售 → 退货管理

10.1 功能概述

客户退货基于已发货的发货单创建，支持按批次精确退货。退货类型包括退款退货和退货换货。

10.2 列表页功能

  • 搜索：退货单号 / 发货单号 / 客户名称
  • 筛选：退货类型（退款退货/退货换货）、状态（待确认/已确认/已驳回）、审批状态
  • 列信息：退货单号、退货类型、发货单号、客户、退货仓库、状态、审批状态、退货原因、入库状态

10.3 新建退货单

操作步骤：
  1. 点击「新建退货单」
  2. 选择退货类型：退款退货 / 退货换货
  3. 选择退货入库仓库
  4. 填写退货原因和备注
  5. 在「选择发货单」区域输入发货单号（如 SM-20260328-001），点击「加载发货单」
  6. 系统自动加载发货单的客户信息和所有已发产品明细：
    • 每条产品明细下显示该产品的各批次信息
    • 每批次显示：批次号、发货数量、已退数量、可退数量（绿色）
    • 在「本次退货数量」列输入该批次的退货数量
    • 明细退货数量自动汇总所有批次输入的数量
  7. 验证：至少一条明细的退货数量 > 0；每批次退货数量不超过可退数量
  8. 点击「创建退货单」

10.4 审批流程

  • 草稿 → 提交审核（启动工作流）
  • 审批中 → 撤回提交
  • 已审批 → 反审退回

10.5 详情查看

退货单详情展示：退货单号、类型、状态、发货单号、客户、仓库、退货原因、确认信息。明细区域可展开查看每行的退货批次详情。

10.6 退货数据指标

字段说明
shipped_quantity该批次原始发货数量
returned_quantity该批次已退货数量（所有退货单累计）
returnable_quantity该批次可退货数量 = 发货数量 - 已退货数量（其他退货单）
inbound_status入库状态：待入库 / 已入库
⚠️ 注意事项：
  • 退货单必须关联一个已发货的发货单
  • 退货数量按批次控制，不能超过该批次的可退数量
  • 编辑退货单时，系统会将当前退货单的退货数量加回可退数量，避免重复扣减
  • 退货单创建后需要在审批流程中审核通过才能确认入库

十一、完整操作流程演示

11.1 完整端到端流程

第1步：建立销售价目表（销售 → 销售价目表）
 → 新建价目表，维护客户-物料-价格关系，提交审批

第2步：设置成品安全库存（基础数据 → 物料管理）
 → 找到成品物料，开启安全库存管理，设置安全库存数量

第3步：录入销售预测（销售 → 销售预测）
 → 新建预测，选择客户，添加预测明细（物料+日期范围+数量），提交审批

第4步：录入销售订单（销售 → 销售订单）
 → 新建订单，选择客户，添加产品明细（系统自动匹配价目表价格和客户物料对照），提交审批

第5步：运行MPS计算（计划 → MPS主计划）
 → 设置条件，点击"计算 MPS"，查看净需求结果
 → 选中需生产的物料行，点击"从销售订单导入"
 → 勾选需求来源，确认导入 → 自动生成生产计划

第6步：生产执行（生产域）- 参见《生产执行操作手册》
 → 计划管理 → 生产单派发 → 备料出库 → 连续报工 → 生产检验 → 入库

第7步：生成发货申请（销售 → 待发货列表）
 → 勾选同一客户的待发货明细行，点击"生成发货申请"
 → 确认发货数量，提交

第8步：审核发货申请（销售 → 发货申请管理）
 → 审核通过 → 确认发货（生成发货单，扣减库存）

第9步：管理发货单（销售 → 发货单管理）
 → 编辑物流信息（承运商/运单号/运费）
 → 打印发货单
 → 客户签收确认

第10步：处理客户退货（销售 → 退货管理）
 → 新建退货单，输入发货单号加载，按批次填写退货数量
 → 提交审批 → 审批通过 → 入库

11.2 相关模块关系图

数据流：
客户主数据 → 销售价目表 → 销售订单（自动取价）
物料主数据（安全库存）→ MPS 计算（安全库存作为缓冲）
销售预测 + 销售订单 → MPS 计算（需求汇总）→ 生产计划 → MRP → 生产单
销售订单 → 待发货列表 → 发货申请 → 发货单 → 客户退货

11.3 销售订单明细行状态一览

状态字段可能值说明
status未开始 / 进行中 / 已完成明细行的执行状态
shipping_status未申请 / 未发货 / 部分发货 / 全部发货发货进度
production_status未加入计划 / 已加入计划 / 生产中 / 生产完成生产进度
return_status未申请 / 已申请退货状态
