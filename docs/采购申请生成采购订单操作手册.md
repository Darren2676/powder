# 采购申请生成采购订单 — 操作手册

## 一、业务概述

采购申请（PR）经审批通过后，可**转采购订单（PO）**，将申请的物料需求正式下达给供应商。一条采购申请可分多次转单，每次选择部分明细行，指定供应商生成一张采购订单。

## 二、前置条件

| 条件 | 说明 |
|------|------|
| 采购申请审批状态 | **已审批** |
| 采购申请执行状态 | 未转单 或 部分转单（非"已转单"） |
| 明细行状态 | 行内"申请数量" > "已转单数量"（即仍有未转量） |

## 三、操作步骤

### 步骤 1：进入采购申请列表

导航至 **采购管理 → 采购申请单**，打开采购申请列表页。

### 步骤 2：找到已审批的采购申请

- 在列表中找到审批状态为 **"已审批"** 的记录
- 可通过顶部「审批状态」筛选器快速筛选
- 确认执行状态不是"已转单"

### 步骤 3：点击「更多 → 转采购订单」

在操作列点击 **"查看"** 旁边的 **"更多"** 下拉按钮，选择 **"转采购订单"**。

> 该菜单项仅在审批状态为"已审批"且执行状态非"已转单"时可见。

### 步骤 4：填写转单信息

弹窗打开后，需填写以下信息：

| 字段 | 是否必填 | 说明 |
|------|----------|------|
| 供应商 | **必填** | 选择本次采购的供应商，选择后自动带出采购负责人/联系人/联系电话 |
| 交货日期 | 选填 | 期望供应商交货日期 |
| 采购负责人 | 选填 | 默认从供应商信息自动带入，可手动修改 |

### 步骤 5：勾选要转单的明细行

弹窗下方显示该采购申请中**尚有未转单数量**的物料明细：

- 勾选本次需要转单的物料行（勾选左侧复选框）
- 系统自动显示每行的"申请数量""已转单数量"和"可转数量"

### 步骤 6：确认转单

1. 检查供应商、交货日期和勾选的明细行无误
2. 点击 **"确认转单"** 按钮
3. 系统自动生成采购订单（编号格式：`PUR-YYYYMMDD-NNN`）

## 四、转单后数据变化

### 采购申请侧

| 对象 | 字段变化 |
|------|----------|
| 明细行 | `ordered_quantity`（已转单数量）增加 |
| 明细行 | `status` 更新为"部分转单"或"已转单" |
| 主表 | `order_status` 更新为"部分转单"或"已转单" |

### 采购订单侧

| 对象 | 字段值 |
|------|--------|
| 主表 | `approval_status` = "草稿"，`order_status` = "待执行" |
| 主表 | `source_req_number` 关联源采购申请号 |
| 明细行 | `order_quantity` = 本次转单数量（申请数量 - 已转单数量） |
| 明细行 | `receive_status` = "未到货"，`received_quantity` = 0 |
| 明细行 | `source_req_number` + `source_req_detail_id` 回溯源申请 |

## 五、后续流程

```
采购申请(已审批) → 转采购订单(草稿) → 提交审批 → 审批通过 → 打印 → 供应商送货 → 创建收货通知 → 确认入库
```

转单生成的采购订单默认为 **"草稿"** 状态，需经审批后方可执行后续收货入库流程。

## 六、注意事项

1. **一张申请可转多张订单**：每次转单可选择部分明细行，剩余行后续可指定不同供应商再次转单
2. **同一明细行不可重复转单**：已全额转单的行自动过滤，不会出现在转单弹窗中
3. **转单后不可撤回**：转单操作无逆向回退，如需调整请通过采购订单的"反审批"或"关闭"处理
4. **供应商必填**：未选择供应商无法提交转单
5. **采购订单需单独审批**：转单生成的采购订单为草稿状态，需在采购订单页面另行提交审批

## 七、常见问题

### Q1：看不到"转采购订单"菜单？
- 检查采购申请审批状态是否为"已审批"
- 检查执行状态是否已为"已转单"（已转完则菜单自动隐藏）

### Q2：转单弹窗中没有显示想要的明细行？
- 仅显示"申请数量 > 已转单数量"的行，已全额转单的行自动过滤

### Q3：一张申请能否拆分给多个供应商？
- 可以。每次转单选择不同供应商和不同明细行即可，系统会生成多张采购订单

### Q4：转单后采购申请还能编辑吗？
- 已审批的采购申请不可编辑。如需修改，需先"反审退回"至草稿状态
