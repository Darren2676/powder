📐 一、核心公式

净需求 = MAX(0, 毛需求 − 可用供应 + 安全库存)
可用供应 = 现有库存 + 在制品数量 + 采购在途 + 采购申请待执行
子件需求量 = 父件净需求 × (BOM子件实际用量 / BOM基准数量)
开始日期 = 完成日期 − 提前期天数
