一、生产单派发

1.1 功能概述

生产单派发是将已审批的生产单分配给具体的设备和模具，指定生产日期和班次，系统自动完成以下操作：

  • 更新生产单状态为"已派发"
  • 根据工艺路线自动生成工序任务
  • 根据制造BOM自动生成备料单
  • 如果模具关联了专属BOM，还会触发模具MRP重算，自动生成预成型件生产单

1.2 导航路径

生产管理 → 生产单管理 → 选中生产单 → 点击底部"派发"按钮

1.3 派发前置条件

检查项要求
审批状态必须为已审批
计划状态必须为未开始
工艺路线产品必须维护了审批通过的工艺路线（否则无法生成工序任务）

1.4 操作步骤

  1. 在生产单列表页，勾选需要派发的生产单（可多选）
  2. 点击底部批量操作栏的 "派发 (N)" 按钮
  3. 系统自动执行派发预检：
    • 红色提示：审批状态非"已审批"或计划状态非"未开始"的记录将被跳过
    • 橙色提示：工艺路线未维护/未审批的产品会给出警告，但不阻止派发
  4. 确认预检结果后，进入派发编辑对话框
  5. 在派发表格中逐行或批量填写以下信息：

派发信息填写说明

字段说明填写方式
设备编号选择该生产单使用的生产设备自动完成搜索（输入编号或名称），选后自动带出设备名称
模具编号选择该生产单使用的模具自动完成搜索，选后自动带出：成型件规格、成型件单耗、实际模腔数、实际模穴数、实际班产
生产日期计划生产的日期日期选择器
班次生产班次下拉选择

批量修改功能

派发对话框中提供批量修改区域，可同时为勾选的多行设置相同的设备、模具、生产日期和班次：

  1. 勾选需要批量修改的行
  2. 在批量修改区域填写设备/模具/日期/班次
  3. 点击 "应用到勾选行" 按钮

排产冲突检查

提交派发前系统会检查本批次内是否存在冲突：

  • 模具冲突：同一模具在同一日期和班次被分配给多条生产单
  • 设备冲突：同一设备在同一日期和班次被分配给多条生产单

如有冲突，系统会弹出冲突详情并阻止提交。

确认派发

点击 "确定派发" 后：

  • 弹出确认对话框："将派发 N 条生产调度单，同时自动生成工序任务和备料单。"
  • 确认后系统执行派发，完成后弹出派发结果面板

派发结果面板

展示本次派发的汇总信息：

可展开每条记录查看详细的工序任务生成和备料明细信息。

提示：如果在新建/编辑生产单时已经填写了设备和模具信息，派发对话框中会自动带入这些信息，无需重复填写。

1.5 生产单状态流转

生产单从创建到完成经历以下状态：

指标含义
成功派发成功派发的生产单数量
工序任务根据工艺路线自动生成的工序任务总数
备料单根据制造BOM自动生成的备料单份数
预成型件生产单模具关联专属BOM时，MRP重算自动生成的预成型件生产单
跳过派发失败的记录数及原因
状态说明触发条件
未开始审批通过但尚未派发审批通过后
已派发已完成设备/模具/日期分配，生成工序任务和备料单执行派发操作
已备料备料单物料已全部领料出库备料完成
生产中已经开始报工，部分工序进行中首次报工
已完成所有工序报工完成最后一道工序完成报工

二、备料出库

2.1 功能概述

备料出库是将生产所需的物料从仓库领出到生产线的过程。系统支持两种备料模式：

  • 按生产单备料清单备料：根据整个生产单的BOM清单一次性领料
  • 按工序备料：按工序分组，逐工序领料（适合多工序生产场景）

2.2 导航路径

  • 按生产单备料：生产管理 → 生产备料（material-issue）
  • 按工序备料：生产管理 → 按工序备料（material-issue-by-process）

2.3 按生产单备料清单备料

操作步骤

  1. 在顶部搜索框扫码或输入生产单编号，按回车查询
  2. 系统显示生产单信息（编号、产品、规格、计划数量、状态）和备料单摘要（备料单号、BOM、物料种类、备料状态）
  3. 点击 "开始备料" 或 "补料" 按钮打开备料弹窗
  4. 在备料明细表格中填写每项物料的实际领用数量和批次号
  5. 可点击 "填充未领量" 按钮，通过FIFO批次选择自动填充剩余待领物料数量
  6. 填写本次领料备注（可选）
  7. 点击 "保存领料" 完成出库

备料类型说明

类型说明
领料首次领料，从备料单中按BOM需求领用物料
补料补充领料，当首次领料不足或物料损耗需要补充时使用

FIFO批次选择功能

点击"填充未领量"按钮后，系统弹出FIFO批次选择窗口：

  • 左侧显示未领料物料列表，含物料编号、名称、剩余需求量和默认仓库
  • 点击物料后右侧显示该物料在各仓库的可用批次
  • 支持切换仓库查看不同仓库的库存
  • 勾选批次并输入分配数量，系统按FIFO原则自动排列批次
  • 确认选择后自动填充到备料明细表格中
提示：如果生产单尚未生成备料单，系统会提示"该生产单尚未生成备料单，请先派发生产单"。备料单在派发时自动生成。

2.4 按工序备料

按工序备料将BOM物料按工序分组展示，每个工序的物料可独立领料：

  1. 扫码或输入生产单编号查询
  2. 系统展示按工序分组的物料清单（折叠面板形式）
  3. 每个工序面板显示：工序号、工序名称、工作中心、物料种类数、领料状态
  4. 点击工序面板右侧的 "备料" 按钮
  5. 在弹窗中填写该工序物料的实际领用数量和批次号
  6. 点击保存完成该工序的备料

2.5 历史领料记录与退料

查看历史领料

备料页面下方展示该生产单的历史领料记录，每次领料显示：

  • 领料类型标签（领料/补料）
  • 领料单号、物料种类数、领料状态
  • 领料人、领料时间、备注
  • 明细行：物料编号、名称、仓库、需求数量、实际领用数量

批量退料

支持对历史领料记录进行退料操作：

  1. 在历史领料记录中勾选需要退料的明细行
  2. 输入退料数量（最大可退数量=已领数量）
  3. 点击 "批量退料" 按钮
  4. 系统自动生成退料单，恢复物料库存并回退备料单/生产单状态

三、连续报工

3.1 功能概述

连续报工是针对一个生产单的所有工序，在一个页面内连续逐道完成报工的功能。支持：

  • 扫码快速定位生产单
  • 逐工序输入合格数量和不合格数量
  • 单道报工、全部报工、完成生产单
  • 快捷数量批量应用
  • 查看历史报工记录

3.2 导航路径

生产管理 → 连续报工（continuous-report）

3.3 操作步骤

  1. 在顶部搜索框扫码或输入生产单编号，按回车查询
  2. 系统加载该生产单的所有工序任务，并显示生产单基本信息
  3. 填写公共参数（应用于所有工序）：
    • 报工日期（默认当天）
    • 班次（自动继承生产单的班次）
    • 班组、操作员
    • 快捷数量：输入后可一键应用到所有可报工序
  4. 在每道工序行中填写报工信息
  5. 点击报工按钮提交

3.4 工序行说明

每道工序显示为一张卡片，包含上下两行：

上行（信息+进度）

元素说明
勾选框用于标记该工序参与批量操作
工序号徽章圆形数字标识，绿色=已完成，灰色=不可报
工序名称标准工序名称
状态标签未开始/进行中/已完成/已关闭
审批状态工序任务审批状态
报工次数已报工次数（支持同一工序多次报工）
进度数据计划数量 / 完成数量 / 可报数量 + 进度条百分比

下行（输入区域）

输入项说明必填
合格数本次报工的合格品数量是
不合格本次报工的不合格品数量否
缺陷分类不合格数量>0时必须选择条件必填
缺陷名称不合格数量>0时必须选择（级联于缺陷分类）条件必填
操作员可每工序单独指定，默认使用公共参数的操作员是

验证规则

  • 合格数量必须大于0
  • 合格数+不合格数 ≤ 最大可报数量
  • 有不合格数量时必须选择缺陷分类和缺陷名称
  • 报工总量不得超过实际班产×(1+超额报工比例)

3.5 报工操作按钮

按钮说明
报工提交当前工序的单次报工，成功后可继续对该工序再次报工
完成仅在最后一道工序显示。提交报工的同时将生产单标记为"已完成"
历史展开/收起该工序的历史报工记录表格
撤销重报撤销该工序及之后所有工序的报工，详见第六章操作出错处理
全部报工底部操作栏按钮，一次性提交所有已填写合格数量的工序
提示：报工提交后会自动审批（系统自动审批），无需人工审批流程。报工成功后工序的完成数量会即时更新，后续工序的可报数量会相应解锁。
注意事项：
  • 如果工序设置了物料关卡（material gate），未完成备料的工序不可报工，会显示阻拦原因
  • 工序审批状态必须为"已审批"才可报工
  • 完成后报工按钮消失，仅显示"已完成"状态和"撤销重报"按钮

四、生产检验

4.1 功能概述

生产检验是对报工完成后的工序进行质量检验的模块。检验单在报工后自动生成，检验类型分为：

  • 自检：由操作员自行检验
  • 专检：由专职检验员检验

4.2 导航路径

质量管理 → 生产检验管理

4.3 检验单列信息

字段说明
检验单号系统自动生成的唯一编号
生产单号关联的生产单
工序序号/名称关联的工序
检验类型自检（blue）/ 专检（green）
报工数量该工序的报工总数量
检验方案应用的检验方案名称
检验规范应用的检验规范名称
检验结果合格/不合格
合格/不合格数量合格品与不合格品数量
状态待检/检验中/已完成/已处理
不合格处理不合格品处理方式（返修/报废/让步接收）
检验人执行检验的人员姓名

4.4 操作步骤

检验流程

  1. 在检验列表找到待检/检验中的记录，点击 "检验" 按钮
  2. 弹出检验弹窗，显示该检验单关联的质量特性检验明细项
  3. 每项质量特性显示：特性名称、检验方法、标准值、上限、下限
  4. 在实测值列输入实际测量值，系统实时预览判定结果：
    • 实测值在上限和下限范围内 → 合格
    • 实测值超出上限或下限 → 不合格
  5. 填写完成后点击 "保存"，检验状态变为"检验中"
  6. 所有检验项填写完毕后，点击 "完成" 按钮
  7. 系统自动判定检验结果：全部合格 → 合格；任一项不合格 → 不合格

不合格品处理（从检验单）

当检验结果为不合格时，操作栏出现 "处理" 按钮：

  1. 点击"处理"按钮，弹出不合格品处理弹窗
  2. 选择处理方式：返修 / 报废 / 让步接收
  3. 处理方式需填写的信息
    返修返修目标工序序号（指定返修后回到哪道工序）
    报废报废类型（批量/单件）、报废数量
    让步接收让步接收数量
  4. 填写备注（可选）
  5. 点击"确认处理"，系统创建不合格品处理单
提示：只有在检验状态为"已完成"且检验结果为"不合格"时，"处理"按钮才可见。删除检验记录仅允许删除"待检"或"检验中"状态的记录，删除后关联工序的检验状态将被清除。

五、不合格处理

5.1 功能概述

不合格品处理模块集中管理所有来源的不合格品，包括生产检验、来料检验和委外检验。提供待处理列表（快捷处理入口）和全部列表（管理与追溯）。

5.2 导航路径

  • 待处理列表：质量管理 → 不合格品待处理（PendingList）
  • 全部列表：质量管理 → 不合格处理单（List）

5.3 不合格品待处理列表

聚焦待处理状态的不合格品，便于快速处理：

  • 列表展示：不合格品单号、来源类型、检验单号、物料编号/名称、不合格数量、缺陷分类/名称、处理状态
  • 操作：详情（查看完整信息）、处理（执行处理）

5.4 处理方式详解

根据来源类型不同，可用的处理方式不同：

生产检验 / 委外检验来源

处理方式说明需填参数
返修将不合格品退回生产线返工返修目标工序号、返修数量
报废将不合格品做报废处理报废类型（批量/单件）、报废数量
让步接收降级接收不合格品让步接收数量

来料检验来源

处理方式说明需填参数
挑选对来料进行挑选，分出合格与不合格挑选后合格数量、不合格数量
拒收拒绝接收来料拒收数量
报废将来料做报废处理报废类型、报废数量
特采特殊采购接收，入库到指定仓库特采入库仓库、特采数量
退货退回供应商，系统自动创建采购退货单退货类型（退货退款/退货换货）、退货数量
提示：选择"退货"处理时，系统将自动创建采购退货单，并在退货单审批后执行退货出库。

5.5 不合格处理单列表

全部列表提供完整的统计和管理功能：

  • 统计卡片：待处理数量、不合格总数、已处理数量、总记录数
  • 筛选条件：搜索单号/物料、来源类型（来料检验/生产检验/委外检验）、处理状态（待处理/处理中/已完成/返修不合格）
  • 关联单据：处理完成后可在列表查看关联的返修单号、入库单号、退货单号
  • 撤销处理：已完成或处理中的记录可撤销处理，回退相关单据

六、操作出错处理

6.1 功能概述

生产执行过程中不可避免地会出现操作失误，系统提供了多种纠错和回退机制，确保数据准确性：

6.2 报工撤销重报

适用场景

  • 报工数量填写错误（多报/少报）
  • 报错了工序
  • 缺陷信息选择错误
  • 需要重新报工修正数据

操作步骤

  1. 在连续报工页面，找到需要撤销的工序
  2. 点击该工序的 "撤销重报" 按钮（有报工记录的工序才显示）
  3. 系统弹出撤销预览弹窗，展示：
    • 受影响工序数（从目标工序到末道工序）
    • 受影响工序当前状态和完成数量
    • 将被删除的报工单列表（按工序号降序排列）
    • 关联的检验记录（需手动处理）
  4. 确认无误后点击确认，系统删除相关报工单并回退工序完成数量
  5. 重新填写正确的报工数据并提交
重要：
  • 撤销重报会删除从目标工序到末道工序的所有报工记录，不仅仅是当前工序
  • 如果关联了检验记录，需手动处理检验单
  • 无法单独撤销中间的某一条报工记录

6.3 领料撤回

适用场景

  • 领料数量填写错误
  • 领错了物料
  • 领料后发现生产单取消

操作步骤

  1. 在备料页面，查看历史领料记录
  2. 找到需要撤回的领料单
  3. 点击领料单右侧的 "撤回" 按钮
  4. 确认撤回操作（系统提示："物料库存、备料单状态、生产单状态将同步回退"）
提示：撤回领料单后，系统会自动恢复物料库存、回退备料单状态和生产单状态到领料前的状态。

6.4 批量退料

适用场景

  • 部分物料领多了需要退回
  • 需要退掉特定批次的物料

操作步骤

  1. 在历史领料记录中，勾选需要退料的明细行
  2. 输入退料数量（限制为最大可退数量）
  3. 点击 "批量退料" 按钮
  4. 系统生成退料单，恢复库存并更新备料单状态

6.5 不合格处理撤销

适用场景

  • 不合格品处理方式选择错误
  • 处理数量填写错误
  • 需要更改处理决策

操作步骤

  1. 在不合格处理单列表，找到需要撤销的记录
  2. 仅"已完成"或"处理中"状态的记录可撤销
  3. 点击 "撤销" 按钮
  4. 确认："将回退相关单据的数量和状态"
  5. 撤销后不合格品恢复为"待处理"状态，可重新选择处理方式

6.6 检验记录删除

适用场景

  • 检验数据填写错误且未完成检验
  • 检验单生成有误需要重做

操作步骤

  1. 在生产检验列表，找到需要删除的记录
  2. 仅"待检"或"检验中"状态的记录可删除
  3. 点击 "删除" 按钮
  4. 确认删除（系统提示："删除后关联工序的检验状态将被清除"）
注意："已完成"状态的检验记录不可删除。如需修正已完成检验的数据，请先通过不合格处理撤销流程回退。

6.7 生产单审批撤回与反审

操作适用状态说明
撤回提交待审批将已提交审核的生产单退回到草稿状态，可重新编辑
反审退回已审批将已审批的生产单退回，取消审批状态
批量关闭任意手动关闭不再需要的生产单

以上操作均可在生产单列表的"更多"下拉菜单或底部批量操作栏中找到。

6.8 各模块纠错能力汇总

模块纠错操作影响范围前提条件
连续报工撤销重报目标工序及之后所有工序的报工记录有报工记录
备料出库撤回领料单物料库存、备料单状态、生产单状态领料单存在
备料出库批量退料物料库存（部分退回）有已领物料
生产检验删除检验记录工序检验状态清除状态为待检或检验中
不合格处理撤销处理回退相关单据的数量和状态状态为已完成或处理中
生产单管理撤回提交审批状态回退到草稿状态为待审批
生产单管理反审退回审批状态回退状态为已审批
生产单管理批量关闭生产单状态标记为关闭任意状态
最佳实践：发现操作错误后应立即纠正，避免错误数据向后续环节传播。例如：报工数量错误 → 先撤销重报 → 重新报工 → 检验数据会自动同步更新。
