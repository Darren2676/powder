设备管理功能 — 开发工作量评估

Seals MES System  |  2026年5月

一、功能概述

业务描述：管理工厂设备台账与模具的全生命周期，涵盖设备状态监控、停机记录、保养计划、OEE效率分析，以及模具寿命追踪、维修记录等。设备与模具两大业务线相互独立但共享管理范式（审批/导出/列个性化）。

1.1 模块关系

设备台账 (equipment)
    │ equipment_number
    ├──▶ 设备停机记录 (equipment_downtime)
    │       │ 故障记录 + 维修成本
    ├──▶ 保养计划 (equipment_maintenance_plan)
    │       │ 自动生成 + 执行/完成/取消
    └──▶ OEE效率看板 (equipment_oee)
            │ 可用率×性能率×质量率 = OEE
            │ 支持从生产数据自动计算

模具台账 (mould)
    │ mould_number
    ├──▶ 模具维修记录 (mould_maintenance)
            │ 冲次累积 + 寿命追踪 + 报废

1.2 子模块一览

子模块数据结构核心功能审批导入导出特色功能
设备台账单表 + 9个扩展字段CRUD + 状态管理 + 保养设置✅ 审批/撤审✅ 导出+导入状态概览 + 状态变更 + 保养周期设置
设备停机单表 + 4个索引CRUD + 故障/维修记录✅ 审核/撤审✅ 导出停机类型分类 + 维修成本 + 替换零件
保养计划单表 + 4个索引CRUD + 自动生成 + 执行/完成/取消✅ 审核/撤审✅ 导出按保养周期自动生成计划 + 保养项清单
OEE看板单表 + 唯一约束记录管理 + 看板 + 自动计算❌❌可用率/性能率/质量率计算 + ECharts仪表盘 + 从生产数据自动取值
模具台账单表CRUD + 冲次管理 + 寿命设置 + 报废✅ 审批/撤审✅ 导出+导入冲次累积 + 寿命预警 + 报废处理 + 使用中模数统计
模具维修单表CRUD❌✅ 导出+导入维修类型 + 关联模具 + 维修成本

六、关键影响因素

因素影响说明
OEE ECharts看板⚠️ 增耗时OEE看板页需 ECharts 仪表盘（总OEE环形图、可用率/性能率/质量率三率图、趋势折线、设备排名柱状图），前端约 3 天，比纯表格列表多 1.5 天
保养计划自动生成⚠️ 增耗时按设备保养周期 + 上次保养日期自动批量生成计划，完成后回写设备表 next_maintenance_date，级联逻辑约 0.5 天
OEE自动计算⚠️ 增耗时从生产报工数据自动取值计算可用率/性能率/质量率，需关联 production_task + equipment_downtime，约 1 天
模具冲次+寿命管理⚠️ 增耗时冲次累积、寿命预警(冲次/最大冲次比)、报废处理、使用中模数统计，增加后端约 1 天、前端约 1 天
设备台账字段多⚠️ 增耗时设备台账 25+ 字段 + 9 个扩展字段，弹窗表单复杂，前端 562 行
模具台账字段多⚠️ 增耗时模具台账 30+ 字段 + 冲次/寿命操作弹窗，前端 752 行（最复杂的列表页）
简单审批而非工作流✅ 省时设备/停机/保养计划/模具均使用简单审批/撤审，不走工作流引擎，免去审批节点编排约 2-3 天
复用现有基础设施✅ 省时复用 useTableList/useColumnPreference/useModalDrag + exportToExcel/exceljs，减少重复编码
无移动端✅ 省时设备管理无移动端需求
