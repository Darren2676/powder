## 1. 业务背景与整体流程

### 1.1 为什么要这样装袋

传统袋标签带有袋号（如 BAG20260429001），但现场装袋时工人并不按袋号操作，导致系统中袋号与实际袋子无法对应，批次追溯出错。

**新方案核心改变**：袋标签不再使用袋号，直接以**入库批次号**为标识。每张标签对应一个批次的实际数量，标签粘在物理袋上，保证标签与袋内产品完全一致。

### 1.2 全流程总览

```
生产完工报工
    ↓
成品入库 → 系统自动生成批次号（FB-YYYYMMDD-NNN）
    ↓
创建装箱单 → 选择仓库、产品、勾选批次 → 系统按批次自动计算标签数
    ↓
打印批次标签 → 每张标签含批次号+产品信息+数量+QR码
    ↓
现场装袋 → 按标签上的批次号和数量，将产品装入袋中，标签粘贴在袋上
    ↓
装箱操作 → 在系统中将标签分配到箱（同批次/多批次均可）
    ↓
打印箱标签 → 含箱号+QR码+批次明细
    ↓
确认装箱单 → 系统扣减批次库存
    ↓
扫码出库/盘点
```

## 2. 前提条件：成品入库与批次号生成

### 2.1 系统自动生成批次号

生产完工后，质检/库管在系统中执行**成品入库**操作时，系统自动为每个入库产品生成一个唯一的**批次号**：

- 格式：`FB-YYYYMMDD-NNN`
- 示例：`FB-20260509-001`、`FB-20260509-002`
- 每次入库产生一个批次号，与入库数量绑定

### 2.2 批次号含义

| 字段 | 含义 | 示例 |
|------|------|------|
| FB | Finished Batch（成品批次） | FB |
| 20260509 | 入库日期 | 2026年5月9日 |
| 001 | 当日顺序号 | 第1个批次 |

### 2.3 批次库存表

入库后系统自动写入 `finished_batch_inventory` 表，记录：

| 字段 | 说明 |
|------|------|
| batch_number | 批次号 |
| item_number | 产品编号 |
| item_name | 产品名称 |
| warehouse_number | 仓库编号 |
| quantity | 库存数量 |
| quality_status | 质量状态（合格品/不合格品） |

## 3. 步骤一：创建装箱单

### 3.1 操作入口

系统菜单：**仓库管理 → 成品仓 → 装箱管理**

点击页面右上角 **「新建装箱单」** 按钮。

### 3.2 填写基本信息

| 字段 | 操作 | 说明 |
|------|------|------|
| 仓库 | 下拉选择 | 选择成品仓库 |
| 产品 | 下拉搜索 | 选择要装箱的产品（仅成品） |
| 装箱总数量 | 手动输入 | 本次要装箱的总数量 |
| 每袋数量 | 自动带出（可修改） | 来自物料主数据的 inner_pack_qty |
| 每箱袋数 | 自动带出（可修改） | 来自物料主数据的 outer_pack_qty |

> 选择产品和仓库后，系统自动加载可用批次列表。

### 3.3 选择批次

系统显示该产品在该仓库下的所有可用批次（按入库日期排序，先进先出）：

| 列 | 说明 |
|----|------|
| 批次号 | 入库时系统生成的批次号 |
| 库存数量 | 该批次当前可用数量 |
| 质量状态 | 合格品（绿色）/ 不合格品（红色） |
| 满袋标签 | 该批次可生成多少个满袋标签（floor(数量÷每袋数量)） |
| 尾袋标签 | 是否有尾袋（数量÷每袋数量的余数 > 0 时显示余数） |
| 选择 | 勾选框，默认勾选合格品，不合格品禁用 |

### 3.4 标签数预估

选择批次后，系统自动计算：

- **预计标签数** = 所有已选批次的满袋标签数 + 尾袋标签数
- **预计箱数** = ceil(预计标签数 ÷ 每箱袋数)

### 3.5 提交创建

确认信息无误后，点击 **「创建」** 按钮。

系统自动完成：
1. 按批次维度生成标签记录（每批满袋标签 + 尾袋标签）
2. 按每箱袋数自动将标签分配到箱
3. 生成装箱单号（PK-YYYYMMDD-NNN）
4. 装箱单状态为 **「草稿」**

## 4. 步骤二：打印批次标签（袋标签）

### 4.1 进入详情

在装箱管理列表中，点击对应装箱单的 **「查看」** 按钮，切换到 **「批次标签」** 标签页。

### 4.2 标签列表说明

| 列 | 说明 |
|----|------|
| 序号 | 标签在该装箱单内的顺序 |
| 批次号 | 入库批次号，标签的核心标识 |
| 产品 | 产品名称 |
| 标签数量 | 本张标签对应的产品数量 |
| 标准数量 | 每袋标准包装数量 |
| 满袋 | 满袋（绿色）/ 尾袋（橙色） |
| 所属箱号 | 该标签被分配到的箱号 |

### 4.3 打印方式

- **单张打印**：点击标签行右侧 **「打印」** 按钮
- **批量打印**：点击标签列表上方 **「批量打印标签」** 按钮

### 4.4 标签内容

每张批次标签包含以下信息：

```
┌─────────────────────────────────┐
│  内包装标签（批次）        [QR] │
│─────────────────────────────────│
│  批次号：FB-20260509-001        │
│  产品：  O型密封圈              │
│  编号：  ITEM-001               │
│  规格：  50x3.5                 │
│  数量：  110 个                 │
│  标准：  110 个                 │
└─────────────────────────────────┘
```

尾袋标签额外显示：**「不足一袋，实际数量见上方」**

### 4.5 QR码说明

- QR码内容格式：`批次号|产品编号|数量`
- 示例：`FB-20260509-001|ITEM-001|110`
- 用途：扫码可快速识别袋内产品的批次和数量

## 5. 步骤三：现场装袋操作

> **这是本手册最核心的部分，直接关系到批次追溯的准确性。**

### 5.1 装袋基本原则

1. **一张标签 = 一个物理袋**
2. 标签上写的什么批次、什么数量，袋里就装什么
3. 标签粘贴在袋子的外侧显眼位置
4. 不需要关注标签序号，只看**批次号和数量**

### 5.2 满袋装袋操作

满袋标签上显示的数量 = 每袋标准数量（如110个）。

**操作步骤**：

1. 取一个空袋
2. 数出标签上标注数量的产品（如110个）
3. 将产品装入袋中，封口
4. 将该张批次标签粘贴在袋子上

**示例**：

```
批次 FB-20260509-001，库存550个，每袋标准110个
→ 系统生成5张满袋标签，每张标注数量110
→ 现场：装5袋，每袋110个，每袋粘1张标签
```

### 5.3 尾袋装袋操作

尾袋标签上显示的数量 < 每袋标准数量，是批次不足一袋的剩余量。

**操作步骤**：

1. 取一个空袋
2. 数出标签上标注的实际数量（如30个）
3. 将产品装入袋中，封口
4. 将该张尾袋标签粘贴在袋子上

**示例**：

```
批次 FB-20260509-002，库存580个，每袋标准110个
→ 系统生成5张满袋标签（各110个）+ 1张尾袋标签（30个）
→ 现场：装6袋，前5袋各110个粘满袋标签，第6袋30个粘尾袋标签
```

### 5.4 混批装袋操作

当同一批次产品不够一袋时，本方案采用**"每批次独立标签，多张标签粘同一袋"**的方式。

**场景**：

```
批次 FB-20260509-003，库存75个，每袋标准110个
→ 无满袋标签，只有1张尾袋标签（75个）
```

```
批次 FB-20260509-004，库存35个，每袋标准110个
→ 无满袋标签，只有1张尾袋标签（35个）
```

**现场操作**：

1. 取一个空袋
2. 先装入 FB-003 批次的产品75个
3. 再装入 FB-004 批次的产品35个（合计110个，刚好一满袋）
4. 将 **FB-003 的尾袋标签**（75个）和 **FB-004 的尾袋标签**（35个）**两张标签都粘贴在同一个袋子上**
5. 这样一个袋子上有两张标签，清晰标识了袋内两个批次及其各自数量

**关键要点**：

- 同一袋上多张标签时，每张标签的批次号和数量必须与袋内对应批次的产品数量完全一致
- 扫码任一标签的QR码，即可识别该批次信息
- 混批袋不影响箱内追溯，装箱操作时两张标签都分配到同一个箱即可

### 5.5 装袋操作速查表

| 标签类型 | 数量 | 装袋方式 | 标签粘贴 |
|----------|------|----------|----------|
| 满袋标签 | = 标准数 | 1标签 = 1袋 | 1张标签粘1袋 |
| 尾袋标签（单批） | < 标准数 | 1标签 = 1袋 | 1张标签粘1袋 |
| 尾袋标签（混批） | 各<标准数 | 多标签 = 1袋 | 多张标签粘同一袋 |

## 6. 步骤四：装箱操作（分配标签到箱）

### 6.1 进入装箱操作

在装箱单详情中，切换到 **「装箱操作」** 标签页（仅草稿状态可用）。

左侧为**标签列表**，右侧为**箱列表**。

### 6.2 装箱原则

- **优先同批次装箱**：尽量将同一批次的标签装在同一箱
- **多批次装箱**：如果一箱装不满，可以从其他批次补充
- **一箱可含多批次**：系统支持一箱内包含不同批次的产品

### 6.3 操作步骤

1. 在左侧标签列表中，**勾选**要装到同一箱的标签
2. 在右侧选择**目标箱号**（下拉选择已有箱号）
3. 点击 **「分配到箱」** 按钮
4. 右侧箱列表实时更新，展示每箱的标签和批次信息

### 6.4 移除标签

如果需要将标签从一个箱移到另一个箱：

1. 勾选要移除的标签
2. 点击 **「移除选中」** 按钮，标签变为"未装箱"状态
3. 重新勾选，分配到新箱

### 6.5 重新自动装箱

如果需要全部重新分配：

1. 点击右侧 **「重新自动装箱」** 按钮
2. 系统清除所有箱分配，重新按顺序自动装箱

### 6.6 装箱示例

**示例：产品O型密封圈，3个批次，每箱10袋**

```
箱 BOX-20260509-001：
  - FB-001: 110个 × 5袋（满袋）= 550个
  - FB-001: 30个 × 1袋（尾袋）
  - FB-002: 110个 × 4袋（满袋）= 440个
  共10袋，1020个

箱 BOX-20260509-002：
  - FB-002: 110个 × 1袋（满袋）
  - FB-002: 30个 × 1袋（尾袋）
  - FB-003: 75个 × 1袋（尾袋）
  - FB-004: 35个 × 1袋（尾袋）
  - ... 补充更多批次
  共10袋
```

### 7.1 操作位置

### 7.2 打印方式

## 8. 步骤六：确认装箱单

### 8.1 确认前检查

确认前请核实：
- 所有标签已正确分配到箱
- 袋标签已打印并粘贴在对应的物理袋上
- 箱标签已打印并粘贴在对应的物理箱上

### 8.2 执行确认

在装箱管理列表中，点击对应装箱单的 **「确认」** 按钮。

> **注意**：确认后系统将扣减批次库存，不可修改！

### 8.3 确认后影响

| 操作 | 说明 |
|------|------|
| 扣减批次库存 | 按标签上的批次和数量，扣减 finished_batch_inventory |
| 库存流水 | 写入 inventory_transaction 出库流水 |
| 状态变更 | 装箱单状态从「草稿」变为「已确认」 |
| 箱状态 | 箱状态为「在库」 |

## 9. 常见场景与注意事项

### 9.1 场景一：单批次刚好装满若干袋

```
批次 FB-001 入库550个，每袋标准110个
→ 5张满袋标签 × 110个 = 550个
→ 现场装5袋，每袋粘1张标签
→ 没有尾袋，操作最简单
```

### 9.2 场景二：单批次有尾袋

```
批次 FB-002 入库580个，每袋标准110个
→ 5张满袋标签（110个）+ 1张尾袋标签（30个）
→ 现场装6袋，前5袋粘满袋标签，第6袋（30个）粘尾袋标签
→ 尾袋标签上标注"不足一袋，实际数量见上方"
```

### 9.3 场景三：两个批次不足一袋，合装一袋

```
批次 FB-003 入库75个，批次 FB-004 入库35个
→ FB-003: 1张尾袋标签（75个）
→ FB-004: 1张尾袋标签（35个）
→ 现场取1个袋，先装FB-003的75个，再装FB-004的35个（合计110个）
→ 两张标签都粘贴在同一个袋上
```

### 9.4 场景四：大批次跨箱

```
批次 FB-001 入库1200个，每袋标准110个，每箱10袋
→ 10张满袋标签 + 1张尾袋标签（100个）= 11张标签
→ 箱1: 10张标签（全部FB-001）= 1100个
→ 箱2: 1张标签（FB-001尾袋100个）+ 其他批次标签补充
```

### 9.5 注意事项

| 序号 | 注意事项 |
|------|----------|
| 1 | **标签上的批次号必须与袋内产品批次一致**，否则追溯会出错 |
| 2 | 尾袋标签的数量是实际数量（不是标准数量），装袋时按标签上的实际数量装 |
| 3 | 混批袋上必须粘贴所有相关批次的标签，不能只粘一张 |
| 4 | 确认装箱单前，请确保标签已全部打印并粘贴到位 |
| 5 | 确认后不可修改，如需调整请先取消再重建 |
| 6 | 不合格品批次默认不勾选，如需装箱请手动勾选 |
| 7 | QR码是追溯的关键，请确保标签上QR码清晰可读 |

## 10. 附录：标签规范

### 10.1 批次标签（袋标签）

| 属性 | 规格 |
|------|------|
| 尺寸 | 80mm × 60mm |
| 标题 | 内包装标签（批次） |
| QR码内容 | 批次号\|产品编号\|数量 |
| QR码尺寸 | 18mm × 18mm |
| 核心字段 | 批次号、产品名称、产品编号、规格、数量、标准数 |
| 尾袋标识 | "不足一袋，实际数量见上方" |

### 10.2 箱标签

| 属性 | 规格 |
|------|------|
| 尺寸 | 100mm × 80mm |
| 标题 | 外包装标签（箱） |
| QR码内容 | 箱号（如 BOX-20260509-001） |
| QR码尺寸 | 22mm × 22mm |
| 核心字段 | 箱号、产品名称、产品编号、规格、总数、标签数、仓库、批次明细 |
| 扫码用途 | 扫码出库、扫码盘点 |

### 10.3 标签数量计算公式

| 公式 | 说明 |
|------|------|
| 满袋标签数 = floor(批次数量 ÷ 每袋标准数量) | 整除部分 |
| 尾袋数量 = 批次数量 - 满袋标签数 × 每袋标准数量 | 余数部分 |
| 尾袋标签 = 1（当尾袋数量 > 0） | 不足一袋也打一张标签 |
| 总标签数 = 满袋标签数 + 尾袋标签数 | 每个批次的标签总数 |
| 箱数 = ceil(总标签数 ÷ 每箱袋数) | 所有批次的标签分配到箱 |
