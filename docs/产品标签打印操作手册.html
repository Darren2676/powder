1. 功能概述

产品标签打印功能实现了"标签模板 → 产品标签方案 → 标签打印"的三层管理架构，支持按产品+客户灵活配置不同的标签样式和内容，并自动匹配打印方案。

核心能力

能力说明
模板管理定义标签的纸张尺寸、QR码格式、字段列表
方案管理将模板绑定到具体产品或产品+客户组合，附加自定义字段
智能匹配打印时自动按"精确匹配 → 默认匹配 → 全局默认"三级规则选择方案
标签预览打印前可预览标签渲染效果，确认无误再打印
打印日志每次打印自动记录操作人、时间、内容，便于追溯

菜单路径

主数据管理 → 包装管理 → 标签模板管理 / 产品标签方案

打印入口：仓储管理 → 成品库存 → 操作列 → 打印标签

3. 标签模板管理

3.1 功能说明

标签模板定义了标签的物理规格和字段布局。系统预置了一个"标准成品标签"模板（编码 STANDARD_PRODUCT_LABEL），用户也可创建自定义模板。

3.2 操作步骤

1
进入标签模板管理页面
菜单路径：主数据管理 → 包装管理 → 标签模板管理
2
点击"新增"按钮
在弹出的表单中填写模板信息
3
填写模板基本信息
模板名称、模板编码、纸张宽度(mm)、纸张高度(mm)
4
配置QR码
QR码格式（使用 {field_key} 占位符）、QR码尺寸(mm)、QR码位置（右上/右下/底部居中）
5
配置模板字段
添加系统字段和自定义字段，设置显示顺序、可见性、是否编入QR码等属性
6
保存模板
点击确定保存模板，模板状态默认为"启用"

3.3 模板字段说明

字段键标签数据来源默认编入QR
item_number产品编号item_master.item_number是
item_name产品描述item_master.item_name否
batch_number批号运行时输入是
production_date生产日期运行时输入是
box_number箱号运行时输入是
net_weight净重运行时输入是
remark备注运行时输入否
specifications规格item_master.specifications否
shelf_life保质期计算自 item_master.shelf_life_days否
reference_standard参考标准运行时输入否

3.4 QR码格式

QR码格式使用 {field_key} 占位符，打印时自动替换为实际字段值。

默认格式：{item_number}|{batch_number}|{production_date}|{box_number}|{net_weight}
示例结果：C100809|P20260601|2026/6/1|1|25KG

4. 产品标签方案

4.1 功能说明

产品标签方案将标签模板与具体产品（或产品+客户组合）绑定，可附加自定义字段。每个产品可以有多个方案，但同一产品+客户组合只能有一个方案。

4.2 方案类型

类型客户编号说明
客户专属方案填写客户编号为特定客户的特定产品指定标签方案
产品默认方案留空作为该产品的通用默认方案，适用于无专属方案的客户

4.3 新增方案操作

1
进入产品标签方案页面
菜单路径：主数据管理 → 包装管理 → 产品标签方案
2
点击"新增"按钮
在弹出的表单中填写方案信息
3
填写基本信息
方案名称（必填）：如"110103-客户A标签方案"
产品编号（必填）：从下拉列表选择
客户编号（可选）：选择客户后自动带出客户名称；留空表示默认方案
标签模板（必填）：从下拉列表选择已启用的模板
默认方案：设为"是"则该方案为该产品的默认方案
状态：启用/停用
4
添加自定义字段（可选）
点击"添加自定义字段"，填写字段名称、默认值、是否编入QR码
5
保存方案
点击确定保存方案

4.4 唯一性规则

业务约束：
· 同一产品+客户组合只能创建一个方案
· 同一产品无客户编号时只能创建一个方案
· 同一产品只能有一个"默认方案"（is_default=是且无客户编号）
· 创建时系统自动校验以上规则，违反时会提示错误

4.5 编辑与删除

编辑：在列表操作列点击"编辑"按钮，可修改方案信息、自定义字段。
删除：在列表操作列点击"删除"按钮，确认后删除方案及其自定义字段。若已有打印日志引用，仅清理自定义字段，不阻止删除。

5. 方案匹配规则

打印标签时，系统根据产品编号和客户编号自动匹配标签方案，匹配优先级如下：

优先级1：精确匹配
P1 条件：item_number + customer_number 完全匹配
说明：当方案中指定了客户编号，且打印时提供了相同客户编号，则直接使用该方案。
示例：产品 C100809 + 客户 AH001 → 匹配到 "C100809-AH001标签方案"
优先级2：默认匹配
P2 条件：item_number 匹配 + customer_number 为空 + is_default = 是
说明：当没有精确匹配的方案时，使用该产品的默认方案（无客户编号、标记为默认）。
示例：产品 110103（未指定客户）→ 匹配到 "110103-标签方案"（默认方案）
优先级3：全局默认
P3 条件：使用模板编码为 STANDARD_PRODUCT_LABEL 的系统预置模板
说明：当该产品没有任何方案时，使用全局默认模板。
示例：产品 999999（无任何方案）→ 使用"标准成品标签"模板

6. 标签打印操作

6.1 打印入口

标签打印功能位于"仓储管理 → 成品库存"页面，在库存记录的操作列中选择"打印标签"。

6.2 打印操作步骤

1
选择打印对象
在成品库存列表中，找到需要打印标签的库存记录，点击操作列的"打印标签"按钮
2
查看自动匹配结果
系统自动根据产品编号匹配标签方案，弹窗顶部显示匹配方式（精确匹配/默认匹配/全局默认）和方案名称
3
填写打印参数
· 产品编号（自动填充，不可修改）
· 批号（自动填充，不可修改）
· 生产日期（默认取库存更新日期，可修改）
· 箱号（默认为1，可修改）
· 净重（需手动输入，如"25KG"）
· 备注（可选，客户特定要求）
· 客户编号（可选，用于触发精确匹配）
· 标签模板（默认自动匹配，也可手动切换）
4
填写自定义字段（如有）
若匹配的方案包含自定义字段，表单底部会显示这些字段的输入框，可修改默认值
5
预览标签
点击"预览"按钮，右侧区域显示标签渲染效果和QR码内容。可反复修改参数并预览
6
确认打印
确认预览无误后，点击"打印"按钮。系统将：
① 记录打印日志到数据库
② 弹出浏览器打印窗口，选择打印机完成物理打印

6.3 打印弹窗布局

区域内容
左侧打印参数表单（产品编号、批号、日期、箱号、净重、备注、客户、模板、自定义字段）+ 预览/打印按钮
右侧匹配信息标签 + QR码内容 + 标签预览渲染区

6.4 手动切换模板

打印弹窗中的"标签模板"下拉框默认自动匹配方案对应的模板。如果需要临时使用其他模板打印，可手动从下拉框切换，切换后自动重新预览。

切换模板仅影响本次打印，不会修改方案配置。

7. 打印日志

7.1 日志内容

每次打印操作都会自动记录日志，包含以下信息：

字段说明
方案名称关联的产品标签方案
产品编号/名称打印的产品信息
批号打印时的批次号
生产日期打印时填写的生产日期
箱号打印时填写的箱号
净重打印时填写的净重
备注打印时填写的备注
自定义字段JSON格式保存的自定义字段值
QR码内容生成的QR码原始文本
打印时间打印操作的时间戳
操作人执行打印的用户
工厂操作时的工厂上下文

7.2 日志查询

通过后端API可查询打印日志，支持按产品编号、时间范围、关键词搜索筛选。

示例1：为新产品创建默认标签方案

1

进入标签模板管理，确认"标准成品标签"模板已启用（系统预置）
2
新建方案
进入产品标签方案 → 新增：
· 方案名称：110103-标签方案
· 产品编号：110103（油封）
· 客户编号：留空（默认方案）
· 标签模板：标准成品标签
· 默认方案：是
3
打印测试
在成品库存中选择该产品的库存记录 → 打印标签 → 系统自动匹配"110103-标签方案" → 预览确认 → 打印

1

· 模板名称：客户A定制标签

· QR格式：{item_number}|{batch_number}|{production_date}|{reference_standard}
· 添加字段：参考标准（runtime）、认证编号（custom）等客户要求字段

9. 常见问题

Q1：打印时提示"未找到匹配的标签方案"？

原因：该产品没有任何标签方案，且系统预置的"标准成品标签"模板被停用或删除。

解决：进入标签模板管理，确保至少有一个启用的模板；或为该产品创建标签方案。

Q2：打印标签时客户编号填错了，如何确保匹配正确方案？

说明：打印弹窗中输入客户编号后，需点击"预览"按钮重新匹配。匹配结果会显示在预览区上方的标签中。

Q3：同一产品能否有多个客户专属方案？

可以。同一产品可以为不同客户创建各自的专属方案（如C100809-AH001、C100809-BH002），打印时根据客户编号精确匹配。

Q4：如何修改产品的默认方案？

步骤：先将原默认方案的"默认方案"改为"否"，再将新方案设为"是"。同一产品只能有一个无客户的默认方案。

Q5：标签预览空白或没有QR码？

可能原因：模板字段全部设为不可见，或QR码格式中引用的字段键不存在。检查模板字段配置。

Q6：打印的标签内容与预览不一致？

可能原因：浏览器打印缩放比例不是100%。在浏览器打印对话框中将缩放设为"实际大小"或100%。

Q7：如何查看历史打印记录？

说明：通过后端API接口 GET /api/v1/label-print/logs 可查询打印日志，支持按产品编号、时间范围、关键词筛选。

Q8：删除方案后之前的打印日志会怎样？

说明：删除方案时，方案的自定义字段会被清理，但打印日志保留不变，日志中的 scheme_id 会指向已删除的方案（关联查询时方案名称显示为空）。
