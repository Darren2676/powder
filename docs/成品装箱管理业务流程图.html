1. 成品入库与批次号生成流程

生产完工报工后触发成品入库，系统自动生成批次号（FB-YYYYMMDD-NNN），写入批次库存表、更新汇总库存、记录库存流水。

3. 装箱单与箱状态流转

装箱单有三种主状态：草稿、已确认、已取消。确认后产生箱装库存，箱有三种子状态：在库、已出库、已拆箱。拆箱操作提供了"回退"能力，支持整单拆箱回退到草稿重新编辑，或逐箱拆箱仅恢复指定箱的批次库存。

4. 装箱确认与箱装库存入库流程

装箱单确认时，系统执行散装→箱装的库存形态转换：扣减批次库存、创建箱装库存记录（packing_box_inventory）、同步汇总库存。汇总库存（finished_goods_inventory）同时包含散装批次库存和箱装库存。

5. 拆箱业务流程（整单拆箱 / 逐箱拆箱）

装箱确认后，因复检等原因需拆箱处理。系统提供两种拆箱模式：整单拆箱将装箱单回退到草稿状态重新编辑；逐箱拆箱仅恢复指定箱的批次库存，装箱单保持已确认。已出库的箱不可拆箱。

6. 扫箱码发货出库流程
