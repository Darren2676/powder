# 移动端APP方案 — 生产单定位·备料·报工

## 一、系统定位

| 项目 | 说明 |
|------|------|
| **目标用户** | 车间操作员、班组长、仓管员 |
| **核心场景** | 在生产现场通过手机搜索定位生产单，执行备料确认和工序报工 |
| **技术路线** | Vue 3 + Vant 4 移动端 H5，复用现有后端API，可通过 Capacitor 封装为原生APP |
| **部署方式** | 独立移动端入口 `/mobile`，与PC端共享后端服务 |

---

## 二、功能清单

### 2.1 核心功能 (P0)

| 功能 | 说明 | 关联API |
|------|------|---------|
| 生产单搜索 | 按编号/产品/规格模糊搜索，按状态筛选 | `GET /api/orders` |
| 生产单详情 | 显示生产单基本信息 + 工序任务进度 + 备料概况 | `GET /api/orders/:id/overview` (新增) |
| 快速报工 | 选择工序任务 → 填写合格/不合格数量 → 提交 | `POST /api/work-reports` |
| 备料查看 | 查看备料单物料明细，按工序分组展示 | `GET /api/material-preparations/:id/details` |

### 2.2 辅助功能 (P1)

| 功能 | 说明 |
|------|------|
| 我的任务 | 按工作中心过滤当前操作员的待做工序任务 |
| 报工历史 | 查看当前操作员的历史报工记录 |
| 审批提交 | 对草稿状态的报工单执行提交审批 |
| 扫码定位 | 扫描生产单/工序任务条码快速定位 |

### 2.3 增强功能 (P2)

| 功能 | 说明 |
|------|------|
| 离线暂存 | 断网时报工数据暂存本地，联网自动同步 |
| 推送通知 | 新任务分配、审批结果推送 |
| 操作员快切 | 同一设备多操作员快速切换 |

**备料页交互逻辑：**
1. 从生产单详情点击「备料」进入，自动查询该生产单关联的备料单
2. 若无备料单且生产单已审批，显示「生成备料单」按钮（调用现有 `POST /generate-from-order`）
3. 物料明细按 `step_number` 分组展示，关键物料（`is_key_material=1`）标注高亮
4. 勾选物料后点击「确认领料」更新 `issued_quantity`（调用 `PUT /:id/details`）

**报工页交互逻辑：**
1. **入口一**：从生产单详情页点击工序任务进入，自动带入任务信息
2. **入口二**：从「我的任务」列表点击「报工」进入
3. 合格数量输入后实时校验：不得超过 `max_reportable`（剩余可报量）
4. 班次、操作员从下拉选择，默认记住上次选择值
5. 不合格原因、时间、备注为折叠区域，减少页面干扰

## 四、技术架构

### 4.1 技术栈

| 层级 | 选型 | 说明 |
|------|------|------|
| 框架 | Vue 3 + TypeScript | 与PC端一致，共享类型定义 |
| UI库 | Vant 4 | 专业移动端Vue组件库 |
| 路由 | Vue Router 4 | 独立移动端路由树 |
| 状态 | Pinia | 复用PC端Store |
| HTTP | Axios | 复用PC端请求封装（含JWT认证） |
| 构建 | Vite | 独立入口，HMR开发 |
| 离线 | Dexie.js (IndexedDB) | 本地暂存+断网续传 |
| 原生 | Capacitor (可选) | 打包iOS/Android APP |

#### 新增接口2: 快速报工

```
POST /api/work-reports/quick
```

请求：
```json
{
  "process_task_number": "PT-20260320-002",
  "qualified_quantity": 100,
  "unqualified_quantity": 0,
  "report_date": "2026-03-20",
  "schedules_id": "SCH-001",
  "operator_number": "EMP-001"
}
```

与现有 `POST /api/work-reports` 逻辑一致，但：
- 自动填充 `schedules_name`、`operator_name`、`group_name` 等冗余字段
- 自动计算 `cumulative_quantity`、`actual_hours`
- 减少移动端传参数量

#### 新增接口3: 备料物料按工序分组

```
GET /api/material-preparations/:id/details-grouped
```

返回按 `step_number` 分组的物料明细，适合移动端分组展示。

### 4.5 共享代码策略

```
现有PC端 (client/)              移动端 (client-mobile/)
─────────────────               ──────────────────────
src/api/*.ts          ──复用──→  src/api/*.ts (直接复制+扩展)
src/store/auth.ts     ──复用──→  src/store/auth.ts
src/utils/request.ts  ──复用──→  src/api/request.ts

不复用的部分：
- UI组件 (Ant Design Vue → Vant 4)
- 页面布局 (桌面表格 → 移动卡片)
- 路由结构 (桌面侧边栏 → 移动底部Tab)
```

### 4.6 离线策略

```
┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│   用户操作    │────→│  网络检测    │────→│  在线？      │
└──────────────┘     └──────────────┘     └──────┬───────┘
                                                  │
                                          是 ←────┼────→ 否
                                          │              │
                                    ┌─────▼─────┐  ┌────▼────┐
                                    │ 直接调API  │  │写入离线  │
                                    │ 返回结果   │  │队列     │
                                    └───────────┘  │显示暂存  │
                                                   └────┬────┘
                                                        │
                                              ┌─────────▼─────────┐
                                              │ 网络恢复时自动同步  │
                                              │ 逐条上传，标记结果  │
                                              └───────────────────┘
```

缓存策略：
- **班次/班组/员工**：本地缓存，每日首次启动同步
- **生产单列表**：按需加载，保留最近搜索的50条
- **工序任务**：按工作中心缓存当日任务

## 七、安全考虑

| 项目 | 措施 |
|------|------|
| 认证 | JWT Token，与PC端共用认证体系 |
