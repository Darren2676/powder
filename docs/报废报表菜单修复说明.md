# 质量模块API路径修复说明

## 问题描述
质量模块的所有菜单页面都出现404错误，提示"请求的资源不存在"。

## 根本原因
后端质量模块路由添加了 `/quality` 前缀，但前端大部分API调用路径还没有更新，导致API调用无法匹配后端路由。

### 修复前
- 前端API调用：`/api/v1/quality/quality-report/product-summary`
- 后端路由：`/api/v1/quality-report/product-summary`（缺少 `/quality` 前缀）
- 结果：**404 Not Found**

## 修复内容

### 1. 后端路由修复

**文件**：`server/src/routes/index.ts`

**修改前**（第27行）：
```typescript
router.use(qualityRoutes);
```

**修改后**：
```typescript
router.use('/quality', qualityRoutes);
```

### 2. 前端API路径修复（14个文件）

所有质量模块的API文件都已更新，在每个API路径前添加 `/quality` 前缀：

|------|------|---------|
| 1 | `client/src/api/quality/scrapOrder.ts` | `/scrap-orders` → `/quality/scrap-orders` |
