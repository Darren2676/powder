API密钥生成与使用流程操作手册

版本：1.0 | 最后更新：2026-05-13 | 适用系统：MES密封系统 v1.0

一、概述

MES系统提供基于API密钥（API Key）的第三方接口认证机制。第三方系统（如ERP、WMS等）通过获取API密钥，可以安全地访问MES系统提供的开放接口，包括生产工单查询、工序报工、备料单查询、BOM数据获取等功能。

认证方式：第三方系统在HTTP请求头中携带 X-API-Key 字段进行身份验证。

二、管理员操作流程

2.1 进入API密钥管理页面

  1. 使用管理员账号登录 MES管理后台
  2. 在左侧导航栏中找到 系统设置 → API密钥管理
  3. 点击进入API密钥管理页面
页面路由为 /api-keys，仅管理员角色可见，非管理员无法访问。

2.2 创建API密钥

  1. 点击"新建密钥"按钮
    在页面右上角点击 + 新建密钥 按钮，弹出创建表单。
  2. 填写密钥基本信息
    字段必填说明示例
    密钥名称是用于标识密钥用途，便于内部管理ERP系统对接
    客户端名称是使用此密钥的外部系统或公司名称XX科技有限公司
    描述否用途说明或备注信息用于同步生产工单与报工数据
  3. 配置访问权限
    为不同模块勾选对应的读写权限：
    模块读取权限写入权限可操作内容
    生产工单 获取工单列表、工单详情 创建工单、更新工单状态 /api/v1/open/orders
    工序报工 查询报工记录 提交工序报工 /api/v1/open/work-reports
    按工序备料 查询备料单、备料明细 创建备料申请 /api/v1/open/prep
    设计BOM 查询BOM主数据、BOM明细 同步BOM数据 /api/v1/open/bom
  4. 设置频率限制
    配置该密钥每分钟允许的最大请求数。默认值为 100次/分钟，可根据实际需求调整（范围：10~10000）。
  5. 配置IP白名单（可选）
    输入允许使用该密钥的第三方服务器IP地址，多个IP用英文逗号分隔。留空表示不限制IP。
    建议生产环境配置IP白名单，提高安全性。例如：192.168.1.100,10.0.0.50
  6. 设置过期时间（可选）
    选择密钥的有效期截止时间。留空表示永不过期。
    建议为临时对接或第三方测试环境设置过期时间，避免长期有效。
  7. 提交创建
    点击"确定"按钮提交表单。

2.3 保存完整密钥

密钥仅在创建成功时展示一次！关闭弹窗后将无法再次查看完整密钥值。
  1. 创建成功后，系统弹出"密钥创建成功"提示窗口
  2. 窗口中显示完整的密钥值，格式为 sk_ + 32位随机字符串
  3. 点击密钥值右侧的 复制 图标复制密钥
  4. 立即将密钥安全地提供给第三方系统管理员（如通过加密邮件、安全通讯工具等）
  5. 确认已妥善保存后，点击"我已复制保管"按钮关闭弹窗
切勿将密钥明文存储在本地文件、聊天工具或未加密的文档中！

2.4 查看密钥列表

创建完成后，可在密钥列表中查看已创建的所有密钥信息：

列名显示内容
密钥名称创建时填写的名称
客户端使用该系统的外部系统名称
密钥掩码格式，如 sk_****a1b2（仅显示前缀和后4位）
权限已授权的模块权限标签
状态启用 或 禁用
过期时间永不过期 / 具体日期（已过期显示红色）
频率限制次/分钟
最近使用最后一次调用时间，从未使用显示"从未使用"

2.5 编辑密钥

在密钥列表中点击某行的 编辑 按钮，可修改以下配置：

  • 访问权限（增删模块权限）
  • 频率限制（调整每分钟最大请求数）
  • IP白名单（添加或移除允许的IP）
  • 过期时间（延长或缩短有效期）
  • 启用/禁用状态
编辑操作不会改变密钥值，仅修改权限和配置参数。第三方系统无需更换密钥。

2.6 禁用/启用密钥

在密钥列表中点击某行的 更多 → 禁用 或 启用：

  • 禁用：该密钥立即失效，所有使用该密钥的API请求返回 401 Unauthorized
  • 启用：恢复密钥的有效性，允许继续调用
当发现密钥可能泄露或第三方系统异常时，应第一时间禁用密钥，排查问题后再决定是否重新启用。

2.7 重新生成密钥

在密钥列表中点击 更多 → 重新生成：

  1. 系统弹出确认提示："重新生成密钥后旧密钥将立即失效，确定继续？"
  2. 确认后，系统生成新的密钥值，旧密钥立即失效
  3. 弹出"密钥已重新生成"提示窗口，显示新的完整密钥
  4. 立即复制新密钥并通知第三方系统更新配置
重新生成后，旧密钥立即失效，所有依赖旧密钥的第三方系统将无法访问MES接口！
请务必在重新生成前与第三方系统负责人协调。

2.8 查看调用日志

在密钥列表中点击某行的 日志 按钮，可查看该密钥的API调用记录：

字段说明
时间API请求发生时间
端点被调用的接口路径
方法HTTP方法（GET/POST/PUT等）
状态码响应状态码（200成功，401认证失败，429频率超限等）
响应时间接口响应耗时（毫秒）
IP地址请求来源IP
通过调用日志可以监控第三方系统的调用频率、排查异常请求、发现可疑行为。

2.9 删除密钥

在密钥列表中点击 更多 → 删除：

  • 系统弹出确认提示："确定删除此密钥？删除后不可恢复"
  • 确认后，密钥及所有调用记录将被永久删除
  • 该密钥立即失效，无法再用于API认证
删除操作不可恢复。建议先禁用密钥，观察一段时间后再决定是否删除。

三、第三方系统对接指南

3.1 认证方式

第三方系统在调用MES开放接口时，需要在HTTP请求头中添加API密钥：

Header名称: X-API-Key
Header值: sk_XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX

3.2 请求示例

使用 cURL

curl -X GET "https://your-mes-domain.com/api/v1/open/orders" \
  -H "X-API-Key: sk_a1b2c3d4e5f6a7b8c9d0e1f2a3b4c5d6" \
  -H "Content-Type: application/json"

使用 Python (requests库)

import requests

url = "https://your-mes-domain.com/api/v1/open/orders"
headers = {
    "X-API-Key": "sk_a1b2c3d4e5f6a7b8c9d0e1f2a3b4c5d6",
    "Content-Type": "application/json"
}

response = requests.get(url, headers=headers)
print(response.json())

使用 Java (HttpClient)

HttpClient client = HttpClient.newHttpClient();
HttpRequest request = HttpRequest.newBuilder()
    .uri(URI.create("https://your-mes-domain.com/api/v1/open/orders"))
    .header("X-API-Key", "sk_a1b2c3d4e5f6a7b8c9d0e1f2a3b4c5d6")
    .header("Content-Type", "application/json")
    .GET()
    .build();

HttpResponse response = client.send(request, BodyHandlers.ofString());
System.out.println(response.body());

四、安全最佳实践

4.1 密钥管理

  • 切勿硬编码：不要在源代码、配置文件或版本控制中明文存储API密钥
  • 使用环境变量：通过环境变量或密钥管理系统（如Vault）存储和读取密钥
  • 定期轮换：建议每3-6个月重新生成一次密钥，降低泄露风险
  • 最小权限原则：仅为第三方系统分配其业务所需的最小权限

4.2 网络安全

  • 必须使用HTTPS：生产环境中所有API调用必须通过HTTPS加密传输
  • 配置IP白名单：限制密钥只能从已知的第三方服务器IP使用
  • 监控调用日志：定期检查调用日志，发现异常调用立即禁用密钥

4.3 密钥泄露应急处理

  1. 立即禁用密钥：在API密钥管理页面禁用该密钥
  2. 排查泄露范围：查看调用日志，确认是否有异常IP或异常频率的请求
  3. 重新生成密钥：生成新密钥并安全地通知第三方系统
  4. 通知相关方：告知第三方系统更新密钥配置，旧密钥已失效
  5. 审查日志：持续监控一周内的调用日志，确认无异常行为

五、常见问题（FAQ）

Q1：创建密钥后忘记保存，怎么办？

密钥仅在创建成功时展示一次，关闭弹窗后无法再次查看。您需要点击该密钥的"重新生成"按钮获取新的密钥值。重新生成后旧密钥立即失效。

Q2：如何查看某个密钥被调用了多少次？

在密钥列表中点击该密钥行的"日志"按钮，可查看该密钥的所有API调用记录，包括时间、接口、状态码等信息。

Q3：第三方系统反映调用接口返回401错误？

请按以下步骤排查：

  • 确认请求头中 X-API-Key 的拼写是否正确（注意大小写）
  • 确认密钥值是否完整复制（是否遗漏了 sk_ 前缀或末尾字符）
  • 在密钥列表中检查该密钥的状态是否为"启用"
  • 检查过期时间是否已过期
  • 如果配置了IP白名单，确认请求来源IP是否在白名单内

Q4：如何限制第三方系统只能访问特定接口？

在创建或编辑密钥时，仅勾选该第三方系统所需的模块权限。例如，如果只需要查询工单，则仅勾选"生产工单-读取"，其他权限保持未勾选状态。

Q5：频率限制设置为多少合适？

默认值为100次/分钟。建议根据第三方系统的实际业务量评估：

  • 低频同步（每天几次）：50~100次/分钟
  • 中频同步（每小时几次）：200~500次/分钟
  • 高频实时对接：1000~5000次/分钟

Q6：可以为同一个第三方系统创建多个密钥吗？

可以。建议为不同的环境（如测试环境、生产环境）或不同的业务模块分别创建独立的密钥，便于权限管理和问题排查。
