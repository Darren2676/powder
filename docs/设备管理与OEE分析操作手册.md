# 设备管理与OEE分析 功能操作使用手册

---

## 1. 模块概述

设备管理模块是 Seals MES 系统中负责设备全生命周期管理的核心模块，涵盖设备台帐、模具管理、设备停机记录、设备保养计划、模具维修记录和 OEE 分析六大子功能，实现从设备建档、状态监控、保养计划、故障记录到设备综合效率分析的全流程闭环管理。

### 1.1 功能架构

```
设备管理
├── 设备台帐管理      — 设备主数据建档与审核
├── 模具管理          — 模具主数据与寿命管理
├── 模具维修记录      — 模具保养/维修/翻新记录
├── 设备停机记录      — 停机事件记录与审核
├── 设备保养计划      — 保养计划生成与执行跟踪
└── OEE分析           — 设备综合效率计算与可视化
```

### 1.2 菜单路径

在系统左侧导航栏中，点击 **「设备管理」** 菜单展开子菜单：

| 子菜单 | 路由路径 |
|--------|---------|
| 设备台帐管理 | /equipments |
| 模具管理 | /moulds |
| 模具维修记录管理 | /mould-maintenance |
| 设备停机记录 | /equipment-downtime |
| 设备保养计划 | /equipment-maintenance-plan |
| OEE分析 | /equipment-oee |

## 2. 设备台帐管理

### 2.1 功能说明

设备台帐管理是设备管理的基础模块，用于维护企业所有设备的主数据信息，包括设备基本信息、状态管理、保养设置和审核流程。

### 2.2 数据列表

进入页面后，系统以表格形式展示所有设备记录。

**列表字段说明：**

| 字段 | 说明 |
|------|------|
| 行号 | 自动序号 |
| 设备编号 | 设备唯一编号，可排序 |
| 设备名称 | 设备名称 |
| 设备状态 | 运行/闲置/故障/保养/停用，彩色标签显示 |
| 位置 | 设备放置位置 |
| 部门 | 所属部门 |
| 登记日期 | 设备登记日期 |
| 设备类型 | 设备分类 |
| 设备型号 | 设备型号 |
| 出厂日期 | 设备出厂日期 |
| 日运行时长 | 每日运行小时数 |
| 保养周期(天) | 保养间隔天数 |
| 上次保养 | 最近一次保养日期 |
| 下次保养 | 下次保养日期，逾期显示红色 |
| 累计运行(h) | 设备累计运行小时数 |
| 备注 | 备注信息 |
| 审核状态 | 未审核/已审核，标签显示 |

### 2.3 搜索与筛选

- **搜索框**：输入设备编号、名称、类型或型号进行模糊搜索，按回车或点击搜索图标执行
- **重置**：清空搜索条件，刷新列表

### 2.4 列表操作按钮

| 按钮 | 功能 |
|------|------|
| 导出 | 将设备列表导出为 Excel 文件 |
| 导入 | 从 Excel 文件批量导入设备数据 |
| 新建 | 打开新建设备弹窗 |
| 列设置 | 打开列个性化设置抽屉 |

### 2.5 行操作

每行记录的操作列提供以下功能：

| 操作 | 说明 |
|------|------|
| 编辑 | 打开编辑弹窗，修改设备信息。**已审核记录不允许编辑** |
| 审核 | 将未审核的设备标记为"已审核"状态 |
| 撤消 | 将已审核的设备撤消审核，需二次确认 |
| 状态 | 变更设备运行状态（运行/闲置/故障/保养/停用） |
| 保养 | 设置保养周期和日运行时长 |
| 删除 | 删除设备记录。**已审核记录不允许删除** |

### 2.6 新建设备

1. 点击工具栏 **「新建」** 按钮
2. 在弹窗中填写以下信息：
   - **设备编号**（必填）：输入唯一编号
   - **设备名称**：输入设备名称
   - **登记日期**：选择日期
   - **设备类型**：输入类型
   - **设备型号**：输入型号
   - **出厂日期**：选择日期
   - **备注**：补充说明
3. 点击 **「确定」** 保存

### 2.7 状态变更

1. 在操作列点击 **「更多 → 状态」**
2. 选择目标状态：
   - **运行**（绿色）：设备正常运转
   - **闲置**（蓝色）：设备空闲
   - **故障**（红色）：设备故障停机，需填写故障原因
   - **保养**（橙色）：设备保养中
   - **停用**（灰色）：设备停用
3. 若选择"故障"，需填写故障原因
4. 点击 **「确定」** 保存

### 2.8 保养设置

1. 在操作列点击 **「更多 → 保养」**
2. 设置以下参数：
   - **保养周期(天)**：建议 30 天，最大 3650 天
   - **日运行时长(h)**：默认 24h，步进 0.5h
3. 点击 **「确定」** 保存

> 设置保养参数后，系统将自动计算下次保养日期，并在列表中以红色高亮显示已逾期保养的设备。

### 2.9 审核/撤消流程

- **审核**：将设备标记为已审核状态，锁定数据防止误改
- **撤消**：已审核的设备需先撤消审核才能编辑或删除，撤消时需二次确认

### 2.10 列个性化

1. 点击工具栏 **「列设置」** 按钮，打开列设置抽屉
2. 可进行以下操作：
   - **显示/隐藏列**：勾选或取消列的显示
   - **调整列顺序**：使用上下箭头调整列的排列顺序
   - **重置**：恢复默认列设置
3. 点击 **「保存」** 保存个性化设置
4. 拖动表头列边框可调整列宽，系统自动记忆

- **新建**：创建模具，支持产品搜索下拉、成型件搜索下拉、制造BOM搜索下拉
- **修改**：编辑模具信息
- **审核/撤消**：模具审核与撤消
- **复制**：快速复制模具创建新记录
- **模次更新**：手动更新模具当前模次
- **寿命设置**：设置模具最大模次和保养周期

### 3.4 模具寿命管理

模具寿命通过 **模次（strokes）** 进行管理：

1. 在 **「寿命设置」** 中设定模具的最大模次
2. 系统根据当前模次/最大模次计算寿命进度，以进度条形式展示
3. 寿命状态分为：
   - **正常**（绿色）：模次使用在合理范围内
   - **预警**（橙色）：接近最大模次
   - **到期**（红色）：已达到或超过最大模次

2. 系统根据设备台帐中设置的保养周期和上次保养日期，自动计算并生成到期设备的保养计划
3. 生成完成后列表自动刷新

### 6.6 新建保养计划

1. 点击 **「新建」** 按钮
2. 填写计划信息：
   - **设备编号**（必填）：下拉选择设备

3. 点击 **「确定」** 保存

### 6.7 计划执行流程

保养计划遵循以下状态流转：

```
待执行 → 执行中 → 已完成
   ↓         ↓
 已取消    已取消
```

| 操作 | 说明 | 可用状态 |
|------|------|---------|
| 执行 | 开始执行保养 | 待执行 |
| 完成 | 完成保养，需填写实际日期和完成备注 | 执行中 |
| 取消 | 取消保养计划，需二次确认 | 待执行/执行中 |
| 修改 | 编辑计划信息 | 任意（更多菜单中） |
| 审核 | 审核计划 | 未审核时 |
| 撤消 | 撤消审核 | 已审核时 |
| 删除 | 删除计划 | 任意（更多菜单中） |

### 6.8 完成保养

1. 在执行中状态的记录上点击 **「完成」** 按钮
2. 填写完成信息：
   - **实际日期**：选择实际完成日期，默认当天
   - **完成备注**：完成情况说明
3. 点击 **「确定」**，计划状态变更为"已完成"

## 7. OEE 分析

### 7.1 功能说明

OEE（Overall Equipment Effectiveness，设备综合效率）是衡量设备生产效率的核心指标，由可用率、性能率和质量率三个维度综合计算：

```
OEE = 可用率 × 性能率 × 质量率

可用率 = 实际运行时间 / 计划运行时间
性能率 = (实际产量 × 理想节拍) / 实际运行时间
质量率 = 合格产量 / 实际产量
```

### 7.2 页面布局

OEE 分析页面由上至下分为四个区域：

1. **筛选条件区**：选择设备、日期范围
2. **KPI 卡片区**：综合OEE、可用率、性能率、质量率
3. **设备OEE 排行区**：各设备 OEE 汇总对比
4. **OEE 记录明细区**：每日/每班 OEE 详细记录

### 7.3 筛选条件

| 筛选项 | 说明 |
|--------|------|
| 设备编号 | 下拉选择设备，可模糊搜索 |
| 开始日期 | 日期范围起始，默认最近30天 |
| 结束日期 | 日期范围截止，默认今天 |

> 点击 **「查询」** 刷新仪表盘和明细表，点击 **「重置」** 恢复默认条件。

### 7.4 KPI 卡片

页面顶部展示四个核心 KPI 指标卡片：

| 指标 | 含义 | 颜色规则 |
|------|------|---------|
| 综合OEE | 设备综合效率 | ≥85% 绿色 / ≥60% 橙色 / <60% 红色 |
| 可用率(A) | 设备可用时间比例 | 同上 |
| 性能率(P) | 设备性能发挥程度 | 同上 |
| 质量率(Q) | 产品质量合格比例 | 同上 |

每个指标卡片下方附带彩色进度条，直观展示指标水平。

### 7.5 设备 OEE 排行

以表格形式展示各设备的 OEE 汇总数据：

| 字段 | 说明 |
|------|------|
| 设备编号 | 设备编号 |
| 设备名称 | 设备名称 |
| 记录数 | OEE 记录条数 |

### 7.7 自动计算 OEE

1. 点击 **「自动计算」** 按钮
2. 系统根据生产报工数据自动计算选定日期和设备的 OEE：
   - 从报工记录中提取实际运行时间、产量和合格率
   - 结合设备停机记录计算可用率
   - 自动生成"自动"来源的 OEE 记录
3. 计算完成后仪表盘和明细表自动刷新

### 7.8 手动录入 OEE

1. 点击 **「手动录入」** 按钮
2. 在弹窗中填写数据：
   - **设备编号**（必填）：下拉选择设备
   - **日期**（必填）：选择记录日期
   - **班次**：如白班/夜班
   - **计划时间(分)**：默认 1440（24小时）
   - **停机时间(分)**：停机时长
   - **理想产量**：理想状态下的产量
   - **实际产量**：实际产量
   - **合格产量**：合格品数量
   - **备注**：补充说明
3. 点击 **「确定」** 保存

> 系统将自动计算可用率、性能率、质量率和 OEE。

## 9. 业务流程

### 9.1 设备全生命周期管理流程

```
设备建档 → 审核 → 状态监控（运行/闲置/故障/保养/停用）
                ↓
        保养设置（周期/日运行时长）
                ↓
    自动/手动生成保养计划 → 执行 → 完成
                ↓
        停机记录（故障/保养/计划停机）
                ↓
          OEE 自动计算/手动录入
                ↓
        OEE 分析（可用率/性能率/质量率）
```

### 9.2 模具全生命周期管理流程

```
模具建档 → 审核 → 生产使用（模次累计）
                ↓
        寿命设置（最大模次/保养周期）
                ↓
    寿命监控（正常 → 预警 → 到期）
                ↓
    维修记录（保养/维修/翻新）
                ↓
        翻新可重置模次
                ↓
          报废（寿命终止）
```

## 10. 常见问题

### Q1：已审核的设备如何修改？
A：需先在操作列点击「更多 → 撤消」撤消审核，然后再点击「编辑」进行修改。

### Q2：设备下次保养日期显示红色是什么意思？
A：表示该设备的下次保养日期已过，需要尽快安排保养。可通过「设备保养计划」页面自动生成保养计划。

### Q3：停机记录的结束时间为空显示"进行中"是什么意思？
A：表示该设备仍在停机状态，尚未恢复运行。当设备恢复后，编辑该记录填写结束时间即可。

### Q4：OEE 自动计算和手动录入有什么区别？
A：自动计算基于生产报工数据和停机记录自动生成 OEE 数据，数据来源标记为"自动"；手动录入适用于设备无法自动采集数据的场景，数据来源标记为"手动"。

### Q5：模具翻新时重置模次有什么作用？
A：模具翻新后性能恢复，重置模次将当前模次归零或设为指定值，重新开始寿命计算。不勾选重置则模次继续累计。

### Q6：设备保养计划的自动生成依据是什么？
A：系统根据设备台帐中设置的「保养周期(天)」和「上次保养日期」，自动计算到期需要保养的设备并生成计划。
