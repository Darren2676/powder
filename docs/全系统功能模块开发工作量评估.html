一、系统概述

Seals MES System 是面向橡胶密封件制造行业的制造执行系统（MES），涵盖主数据管理、销售管理、采购管理、生产管理、仓储管理、质量管理、设备管理、财务管理、计划排程、委外管理、系统集成等核心业务领域。

1.1 技术栈

层技术
前端Vue 3 + TypeScript + Ant Design Vue + Vite
后端Node.js + Express + TypeScript + Sequelize（raw SQL）
数据库SQL Server
公共服务审批引擎 / 工作流引擎 / 文档编号服务 / 事件驱动架构 / SSE 实时推送

二、评估方法

2.1 评估维度

维度权重说明
数据库复杂度20%表数量、外键关系、迁移脚本复杂度
