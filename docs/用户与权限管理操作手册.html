用户与权限管理操作使用手册

涵盖：部门管理 → 权限菜单管理 → 角色管理 → 用户管理 — 从新建用户到最终授权的完整流程

总体概览

四模块关系

系统的用户权限管理由四个模块组成，它们之间存在严格的依赖关系：

1 部门管理 → 2 权限菜单管理 → 3 角色管理 → 4 用户管理
模块导航路径作用
部门管理系统设置 → 部门管理建立公司组织架构树，定义部门层级关系。用户创建时可选择所属部门。
权限菜单管理系统设置 → 权限菜单管理定义系统所有菜单和功能页面，配置路由路径与图标。这是权限授权的"原材料"。
角色管理系统设置 → 角色管理创建角色（如管理员、生产经理、质检员），为每个角色分配可访问的权限树。一个角色 = 一组权限集合。
用户管理系统设置 → 用户管理创建系统登录用户，分配角色、部门，管理账户状态（激活/停用/禁用/锁定）。用户通过角色获得权限。

授权核心逻辑

用户登录后，系统根据其角色关联的权限列表，动态渲染菜单树并控制页面访问：

  1. 用户 拥有一个 角色（如 staff / manager / admin）
  2. 角色 拥有一个 权限集合（通过权限树勾选）
  3. 权限 分为四种类型：菜单（一级/二级模块）、页面（功能页面）、操作（增删改查按钮）、字段（敏感字段可见性）
  4. 系统根据用户的角色权限，仅显示该用户有权限访问的菜单和页面

一、部门管理

1.1 功能概述

部门管理用于建立公司的组织架构树，支持无限层级的父子部门结构。用户创建时可绑定所属部门，部门也可查看其下的所有用户。

1.2 页面布局

  • 左侧：部门树形结构，以树状图展示所有部门及其层级关系
  • 右侧：选中部门的子部门列表（表格形式），支持搜索和状态筛选
  • 顶部面包屑：显示当前选中部门的完整路径（如：生产部 > 注塑车间 > A班组）

1.3 新建部门

  1. 点击页面右上角 "新建" 按钮
  2. 在弹窗中填写部门信息
  3. 点击确定完成创建，左侧树和右侧列表自动刷新

部门表单字段说明

字段必填说明
部门编码是部门唯一编码，如 PROD、QA、HR
部门名称是部门显示名称，如 生产部、质检部
上级部门否树形选择器选择父部门。留空则为顶级部门。
排序号否数字越小越靠前，用于控制同级部门的显示顺序
描述否部门描述信息（可选）

快捷创建子部门

在右侧列表中，每个部门行提供 "添加子部门" 按钮，点击后自动将上级部门设置为当前部门，方便快速建立层级结构。

1.4 编辑与停用

  • 编辑：修改部门编码、名称、上级部门、排序、描述，还可切换启用/停用状态
  • 停用：将已启用的部门标记为停用。停用后的部门不会在用户创建/编辑的部门选择中出现。
  • 编辑上级部门时，系统会自动排除自身及其子部门，防止循环引用

1.5 查看部门人员

点击部门行的 "查看人员" 按钮，右侧滑出抽屉面板，列出该部门下所有用户，显示用户名、真实姓名、角色标签和邮箱。

提示：新建用户时，"部门"下拉列表的数据来源即为部门管理中状态为"启用"的部门。请确保在创建用户前已建立好部门结构。

二、权限菜单管理

2.1 功能概述

权限菜单管理用于定义系统所有的菜单项和功能页面，是整个权限体系的"原材料"。每个菜单/页面都会在角色管理的权限树中出现，供管理员分配给角色。

2.2 权限层级结构

权限采用树形层级结构：

顶级菜单（如：销售管理）
  ├── 二级菜单（如：销售订单）
  │     └── 页面（如：销售订单列表）
  └── 二级菜单（如：销售发货）
        └── 页面（如：发货单列表）

2.3 新建菜单

  1. 点击 "新建菜单" 按钮
  2. 权限类型选择 "菜单/子菜单"
  3. 可选选择父级菜单（留空为顶级菜单）
  4. 填写菜单信息，选择图标
  5. 点击确定保存

菜单表单字段

字段必填说明
权限名称是菜单显示名称，如"销售管理"、"生产管理"
权限编码是唯一编码，如 sales、production。创建后不可修改。
权限类型是菜单 或 页面
父级菜单否选择上级菜单，带缩进显示层级
菜单Key否用于路由匹配的唯一标识，如 sales-management
路由路径否前端路由路径，如 /sales-orders（页面类型必填）
图标否从40+图标库中选择，仅菜单类型可设置
排序否控制同级菜单的显示顺序

2.4 新建页面

在菜单行点击 "添加页面" 按钮，系统自动将权限类型设为"页面"、父级菜单设为当前菜单。页面类型需要填写路由路径。

2.5 编辑与删除

  • 编辑：修改权限名称、菜单Key、路由路径、图标、排序、状态（启用/禁用）
  • 删除：删除权限节点（含子节点将被级联删除）
  • 保存后系统自动刷新当前用户的菜单树和权限缓存，变更立即生效
注意：删除权限节点会同时删除其下所有子权限，且会影响已分配该权限的角色。请谨慎操作。

三、角色管理

3.1 功能概述

角色管理是权限体系的核心枢纽。每个角色代表一组权限的集合，用户通过被赋予角色来获得对应的菜单访问和操作权限。

3.2 角色列表信息

列说明
角色名称角色的显示名称，如"生产管理员"
角色编码角色唯一编码，如 production_admin
类型系统角色（系统预置，不可删除）/ 自定义（用户创建）
状态启用 / 禁用
用户数使用该角色的用户数量（蓝色徽标）
权限数该角色拥有的权限项数量（绿色徽标）

3.3 新建角色

  1. 点击 "新建角色" 按钮
  2. 填写角色名称、角色编码、描述、排序
  3. 点击确定保存
  4. 新创建的角色默认没有任何权限，需要执行"分配权限"操作

角色表单字段

字段必填说明
角色名称是如"生产操作员"、"质检主管"
角色编码是唯一编码，创建后不可修改
描述否对角色的说明
排序否数字越小越靠前
状态-编辑时可切换：启用/禁用

3.4 分配权限（核心操作）

点击角色行的 "分配权限" 按钮，弹出权限分配对话框：

  1. 系统加载完整的权限树（来自权限菜单管理模块）
  2. 权限树按四种类型显示，配以颜色图例：
    • 菜单 一级/二级模块
    • 页面 功能页面
    • 操作 增删改查按钮
    • 字段 敏感字段
  3. 勾选需要的权限节点（父节点会自动半选/全选）
  4. 支持 "全选" 和 "取消全选" 快捷操作
  5. 顶部实时显示已选权限数量
  6. 点击确认保存，系统自动分配权限并刷新缓存
智能权限计算：系统根据用户勾选的叶子节点，自动向上推导所有需要选中的父节点ID。保存后，用户的菜单树和权限缓存会立即刷新生效。

3.5 编辑与删除

  • 编辑：修改角色名称、描述、排序、状态
  • 删除：仅自定义角色可删除，系统角色不可删除

用户管理是系统账户的全生命周期管理中心，包含三个子标签页：用户管理、登录日志、安全设置。

五、完整授权流程演示

5.1 场景说明

假设需要为质检部的新员工"张三"创建系统账户，他只应看到质量管理相关的功能。按照以下四步完成从零到授权的完整流程：

5.2 第一步：建立部门结构

  1. 进入 系统设置 → 部门管理
  2. 如果"质检部"不存在，点击"新建"：
    • 部门编码：QA
    • 部门名称：质检部
    • 上级部门：留空（作为顶级部门）
    • 排序号：10
  3. 如需子部门（如"来料检验组"），选中"质检部"后点击"新建"或在质检部行点击"添加子部门"：
    • 部门编码：QA-IN
    • 部门名称：来料检验组
    • 上级部门：自动设为"质检部"

5.3 第二步：确认权限菜单

  1. 进入 系统设置 → 权限菜单管理
  2. 检查是否已存在"质量管理"菜单及其子页面。如不存在：
    • 新建菜单：权限名称="质量管理"，编码=quality，类型=菜单
    • 在"质量管理"菜单下添加页面：来料检验、生产检验、不合格处理等
  3. 确认每个页面的路由路径已正确填写
提示：通常权限菜单在系统初始化时已配置完整，此步骤主要是确认必要的菜单和页面是否都已存在且启用。

5.4 第三步：创建角色并分配权限（关键步骤）

  1. 进入 系统设置 → 角色管理
  2. 点击 "新建角色"：
    • 角色名称：质检操作员
    • 角色编码：qc_operator
    • 描述：负责来料检验和生产检验的操作人员
    • 排序：20
  3. 角色创建后，点击该角色的 "分配权限" 按钮
  4. 在权限树中展开"质量管理"节点，勾选质检员需要的页面：
    • ☑ 来料检验通知
    • ☑ 收料检验方案
    • ☑ 生产检验管理
    • ☑ 不合格品待处理
  5. 还可以勾选基础数据中与质量相关的页面（如检验规范、缺陷分类等）
  6. 确认已选权限数量，点击确定保存

5.5 第四步：创建用户并授权

  1. 进入 系统设置 → 用户管理
  2. 点击 "新增" 按钮，填写：
    • 用户名：zhangsan
    • 密码：abc123456（至少6位）
    • 选择员工：搜索并选择"张三"（自动填充姓名和部门）
    • 手机号：13800138000
    • 角色：选择系统预置的 staff 或自定义的 qc_operator
    • 部门：来料检验组
    • 状态：激活
  3. 点击"创建"完成
  4. 用户"张三"使用用户名 zhangsan 和密码 abc123456 登录系统
  5. 登录后系统菜单仅显示分配给他的角色权限范围内的功能
验证授权效果：创建完成后，可以让张三登录系统，确认他只能看到质量管理相关的菜单。如果他需要额外的权限，只需在角色管理中为"质检操作员"角色分配更多权限，该角色下所有用户的权限会自动同步更新。

5.6 完整流程图

1 创建部门
（质检部/来料检验组） → 2 确认权限菜单
（质量管理相关页面） → 3 创建角色+分配权限
（质检操作员 → 勾选菜单） → 4 新建用户+指定角色
（张三 → 质检操作员） → ✓ 完成
用户登录仅见授权菜单

5.7 日常维护操作

场景操作影响
员工调岗编辑用户 → 修改部门和角色即时生效，新角色权限立即应用
员工离职更多 → 停用（保留数据）/ 删除（清除用户）停用后无法登录，数据保留
忘记密码更多 → 重置密码管理员为用户设置临时密码
登录锁定更多 → 解锁解除锁定，用户恢复登录能力
新增功能页面权限菜单管理 → 新建页面 → 角色管理 → 为相关角色勾选新页面角色下所有用户同步获得新权限
收回权限角色管理 → 分配权限 → 取消勾选角色下所有用户同步失去该权限
调整安全策略用户管理 → 安全设置标签页全局生效，影响所有用户
