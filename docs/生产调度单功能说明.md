# 生产调度单功能说明

## 一、功能概述

生产调度单是在现有生产单管理基础上，扩展**设备**和**模具**信息，实现从"计划"到"执行"的调度指派。

**核心目标**：每条生产单关联具体的设备和模具，自动带出模具的成型工艺参数（成型件规格、成型件单耗、实际模腔数、实际模穴数、实际班产），形成完整的生产调度指令。

**典型业务场景**：计划员创建生产单后，调度员为每条生产单指定使用的设备和模具，系统自动填充模具工艺参数，生成可下发到车间的生产调度单。

---

## 二、功能入口

- **位置**: 左侧导航菜单 → 生产单管理
- **说明**: 在现有"生产单管理"页面上扩展，不新建独立页面
- **权限**: 与现有生产单管理权限一致

## 三、数据库表扩展

### 3.1 production_order 表新增字段

在现有 `production_order` 表基础上新增 **8 个字段**：

| 字段名 | 中文名称 | 数据类型 | 来源 | 说明 |
|--------|---------|----------|------|------|
| `equipment_number` | 设备编号 | NVARCHAR(50) | 设备台账 `equipment.equipment_number` | 用户选择，AutoComplete 搜索 |
| `equipment_name` | 设备名称 | NVARCHAR(100) | 设备台账 `equipment.equipment_name` | 选择设备后自动填充 |
| `mould_number` | 模具编号 | NVARCHAR(50) | 模具管理 `mould.item_number` | 用户选择，AutoComplete 搜索 |
| `formed_part_specifications` | 成型件规格 | NVARCHAR(200) | 模具管理 `mould.formed_part_specifications` | 选择模具后自动填充 |
| `formed_part_unit_consumption` | 成型件单耗 | NVARCHAR(50) | 模具管理 `mould.formed_part_materia_consumption` | 选择模具后自动填充 |
| `actual_cavity_count` | 实际模腔数 | NVARCHAR(50) | 模具管理 `mould.formed_parts_number` | 选择模具后自动填充 |
| `actual_hole_count` | 实际模穴数 | NVARCHAR(50) | 模具管理 `mould.actual_cavities_number` | 选择模具后自动填充 |
| `actual_daily_output` | 实际班产 | NVARCHAR(50) | 模具管理 `mould.actual_production_number` | 选择模具后自动填充 |

### 3.2 DDL 语句

```sql

ALTER TABLE production_order ADD mould_number NVARCHAR(50) NULL;
```

## 四、字段自动填充规则

### 4.1 选择设备

| 触发方式 | 操作说明 |
|---------|---------|
| 输入搜索 | 在"设备编号"字段输入关键字，AutoComplete 从 `equipment` 表模糊查询（匹配设备编号或设备名称） |
| 选中填充 | 选择一条设备记录后，自动填充"设备名称" |
| 清空联动 | 清空设备编号时，同步清空设备名称 |

### 4.2 选择模具

| 触发方式 | 操作说明 |
|---------|---------|
| 输入搜索 | 在"模具编号"字段输入关键字，AutoComplete 从 `mould` 表模糊查询（匹配模具编号或模具名称） |
| 选中填充 | 选择一条模具记录后，自动填充以下 5 个字段 |
| 清空联动 | 清空模具编号时，同步清空以下 5 个字段 |

**模具选中后自动填充映射：**

| 目标字段 | 来源字段 | 说明 |
|---------|---------|------|
| 成型件规格 | `mould.formed_part_specifications` | 只读，跟随模具 |
| 成型件单耗 | `mould.formed_part_materia_consumption` | 只读，跟随模具 |
| 实际模腔数 | `mould.formed_parts_number` | 只读，跟随模具 |
| 实际模穴数 | `mould.actual_cavities_number` | 只读，跟随模具 |
| 实际班产 | `mould.actual_production_number` | 只读，跟随模具 |

## 六、功能影响范围

### 6.1 新建生产单

- 新建弹窗增加"设备信息"和"模具信息"两个分组
- 设备编号和模具编号均为 **可选字段**，不强制填写
- 选择设备/模具后自动填充关联字段

### 6.2 编辑生产单

- 编辑弹窗同步显示设备和模具信息
- 仅草稿状态可修改
- 支持更换设备/模具，自动更新关联字段

### 6.3 拆分功能

- 拆分新增行 **自动继承** 原始行的全部 8 个新字段
- 拆分对话框列表中显示设备编号和模具编号列

### 6.4 从计划导入

- 从计划导入时，设备和模具字段默认为空
- 导入后可通过编辑功能补充

### 6.5 Excel 导入导出

- 导出文件增加 8 个新列
- 导入文件支持包含新字段（可选，不填则为空）

## 十、操作规则与约束

| 规则 | 说明 |
|------|------|
| 设备/模具可选 | 两个字段均非必填，允许空值 |
| 仅草稿可编辑 | 与现有规则一致，已审批记录不可修改 |
| 自动填充只读 | 设备名称和模具关联的 5 个字段均为禁用状态，仅通过选择自动填充 |
| 清空联动 | 清空设备编号时清空设备名称；清空模具编号时清空 5 个模具字段 |
| 拆分继承 | 拆分功能新增行完整继承全部 8 个字段 |
| Excel 兼容 | 导入旧格式 Excel（无新字段列）时新字段默认为空，不报错 |
