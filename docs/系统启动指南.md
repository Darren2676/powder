## 三、后端服务启动

### 3.1 环境配置

后端环境变量配置文件位于 `server/.env`：

```env
PORT=3000
DB_HOST=127.0.0.1
DB_PORT=1433
DB_NAME=SEALSMES
DB_USER=sa
DB_PASSWORD=cowork
JWT_SECRET=ticket-system-jwt-secret-key-2024
JWT_EXPIRES_IN=24h
UPLOAD_DIR=uploads
MAX_FILE_SIZE=10485760
```

| 变量名          | 说明                     | 默认值                              |
| --------------- | ------------------------ | ----------------------------------- |
| PORT            | 后端服务端口             | 3000                                |
| DB_HOST         | 数据库地址               | 127.0.0.1                           |
| DB_PORT         | 数据库端口               | 1433                                |
| DB_NAME         | 数据库名称               | SEALSMES                            |
| DB_USER         | 数据库用户名             | sa                                  |
| DB_PASSWORD     | 数据库密码               | cowork                              |
| JWT_SECRET      | JWT 签名密钥             | ticket-system-jwt-secret-key-2024   |
| JWT_EXPIRES_IN  | JWT 过期时间             | 24h                                 |
| UPLOAD_DIR      | 文件上传目录             | uploads                             |
| MAX_FILE_SIZE   | 上传文件大小限制（字节） | 10485760（10MB）                    |

### 3.2 安装依赖

```bash
cd "Seals MES System/server"
npm install
```

### 3.3 开发模式启动（推荐开发阶段使用）

```bash
npm run dev
```

- 使用 `nodemon + ts-node` 直接运行 TypeScript 源码
- 文件修改后自动重启服务
- 监听所有 `.ts` 和 `.json` 文件变动

### 3.4 生产模式启动

```bash
# 第一步：编译 TypeScript
npm run build

# 第二步：运行编译产物
npm start
```

- `npm run build` 将 TypeScript 编译到 `dist/` 目录
- `npm start` 运行 `node dist/server.js`

### 3.5 启动成功标志

控制台依次输出以下信息表示启动成功：

```
数据库连接成功
数据库同步完成
服务器运行在端口 3000
API地址: http://localhost:3000/api
```

### 3.6 默认管理员账户

首次启动时系统自动创建默认管理员账号：

| 项目   | 值                |
| ------ | ----------------- |
| 用户名 | admin             |
| 密码   | admin123          |
| 邮箱   | admin@system.com  |
| 姓名   | 系统管理员        |
| 角色   | admin             |

> 注意：仅在数据库中不存在管理员角色时自动创建。

## 四、前端服务启动

### 4.1 安装依赖

```bash
cd "Seals MES System/client"
npm install
```

### 4.2 开发模式启动

```bash
npm run dev
```

- Vite 开发服务器默认启动在 `http://localhost:5173`
- 自动将 `/api` 前缀的请求代理到后端 `http://localhost:3000`
- 支持 HMR（热模块替换），修改代码后页面自动更新

### 4.3 构建生产版本

```bash
# TypeScript 类型检查 + Vite 构建
npm run build

# 预览构建产物
npm run preview
```

构建产物输出到 `client/dist/` 目录，可部署到任意静态文件服务器。

## 五、完整启动流程

### 5.1 快速启动（开发模式）

```bash
# 1. 确保 SQL Server 服务已启动，SEALSMES 数据库已创建

# 2. 启动后端（终端 1）
cd "Seals MES System/server"
npm install        # 首次启动需要
npm run dev

# 3. 启动前端（终端 2）
cd "Seals MES System/client"
npm install        # 首次启动需要
npm run dev

# 4. 浏览器访问
# http://localhost:5173
# 使用 admin / admin123 登录
```

### 5.2 启动顺序

```
SQL Server 数据库  →  后端服务（端口 3000）  →  前端服务（端口 5173）
```

> **重要**：必须先启动后端再启动前端。如果后端未启动，前端代理请求会报 `ECONNREFUSED` 错误（后端启动后自动恢复，不影响使用）。

## 八、常见问题

### Q1: 端口 3000 被占用

```powershell
# 查看占用端口的进程
netstat -ano | findstr :3000

# 强制杀掉所有 node 进程
Get-Process -Name node | Stop-Process -Force
```

或修改 `server/.env` 中的 `PORT` 配置。

### Q2: 数据库连接失败

1. 确认 SQL Server 服务已启动
2. 确认 `SEALSMES` 数据库已创建
3. 确认 SQL Server 已启用 TCP/IP 协议（端口 1433）
4. 确认 `sa` 账户已启用且密码正确
5. 检查 `server/.env` 中的数据库配置

### Q3: 前端代理报 ECONNREFUSED

原因：前端先于后端启动，后端服务尚未就绪。

解决：等待后端启动完成即可，前端会自动恢复连接。

### Q4: npm install 失败

```bash
# 清除缓存后重试
npm cache clean --force
rm -rf node_modules package-lock.json
npm install
```

### Q5: TypeScript 编译错误

```bash
# 后端类型检查
cd server && npx tsc --noEmit

# 前端类型检查
cd client && npx vue-tsc --noEmit
```

### Q6: 首次启动数据库表不存在

系统首次启动时 Sequelize 会自动同步模型创建用户表等基础表。业务表（如 production_plan、production_task、production_order 等）需要确保已在数据库中预先创建。
