流程概述：质量检验发现不合格品后自动生成NC单，选择"报废"处理方式后系统自动创建报废入库单（草稿状态）。入库单审批通过后，系统自动执行库存更新：写入报废批次库存（quality_status='不合格品'）→ 更新汇总库存 → 记录库存流水 → 更新NC单状态为已完成。后续在报废处置页面查看库存、创建处置申请、确认处置后系统自动执行FIFO批次扣减，完成报废仓出库。全流程数据可追溯，支持4类报表统计。

反审规则：
  • 仅已审批状态的单据可执行反审

FIFO扣减规则：
  • 按入库日期从早到晚（inbound_date ASC）排序批次
  • 同日期批次按ID升序（id ASC）排序
  • 逐个批次扣减，直到处置数量全部扣完
  • 批次数量扣减为0时，DELETE该批次记录
  • 若批次已被其他处置单消耗，阻止该批次相关的入库单反审

九、报表统计功能

9.1 报废单管理报表

  • 数据源：stock_in (stock_in_type='报废入库') + stock_in_detail + nonconforming_product
  • 功能：报废入库单列表（草稿/审批中/已审批），按物料统计报废数量，按来源统计（来料/生产/委外）
  • 页面：/quality/scrap-orders (ScrapOrder/List.vue)

9.2 报废仓库存报表

  • 数据源：finished_batch_inventory + finished_goods_inventory + inventory_transaction
  • 功能：按物料汇总当前库存，批次明细查询（批次号/数量/入库日期），库存流水查询（入库→处置），库存预警（超期积压）
  • 页面：/warehouse/scrap-disposal (ScrapDisposal/List.vue) - 库存TAB页

9.3 报废处置报表

  • 数据源：scrap_disposal + scrap_disposal_detail
  • 功能：处置申请单列表（待确认/已确认/已驳回），按原因统计处置数量，处置效率统计（申请→确认时长），确认人/时间追踪
  • 页面：/warehouse/scrap-disposal (ScrapDisposal/List.vue) - 处置单TAB页

9.4 质量统计分析报表

  • 数据源：nonconforming_product + stock_in + inspection tables
  • 功能：
    • 不合格品处理统计（5种方式占比饼图）
    • 报废率分析（按物料/供应商/生产线柱状图）
    • 月度报废趋势（12个月折线+柱状组合图）
    • 物料报废TOP 10（横向柱状图）
    • KPI卡片（不合格品总数/已处理数量/报废总数/待处理数量）
  • 页面：/quality/scrap-quality-stats (ScrapQualityStats/Index.vue)

十、关键业务规则汇总

10.1 检验不合格品处理规则

  • 检验不合格时自动生成不合格品单（nonconforming_product），handling_status='待处理'
  • 来料检验可选：挑选 / 拒收 / 报废 / 特采 / 退货（5种）
  • 生产检验可选：返修 / 报废 / 让步接收（3种）
  • 委外检验可选：来料+生产的所有方式（8种）
  • 返修必须指定返修工序号，退货必须指定退货单号
  • 报废处理自动生成报废入库单（stock_in_type='报废入库'）

10.2 报废入库审批规则

  • 报废入库单自动生成时为草稿状态，需提交审批
  • 审批通过后自动触发库存更新（scrapInventoryHandler.onStockInApproved）
  • 库存更新4步：写入批次库存 → 更新汇总库存 → 记录库存流水 → 回写批次号
  • 报废入库的 quality_status 固定为 '不合格品'
  • 审批驳回返回草稿状态，可修改后重新提交

10.3 报废入库反审规则

  • 仅已审批状态的单据可执行反审
  • 反审前检查批次是否已被报废处置消耗
  • 若批次数量 < 原始入库数量（已被部分处置），阻止反审
  • 回退操作：删除批次库存 → 扣减汇总库存 → 标记流水作废 → 更新单据状态为已撤销

10.4 报废处置FIFO规则

  • 按入库日期从早到晚（inbound_date ASC）排序批次
  • 同日期批次按ID升序（id ASC）排序
  • 逐个批次扣减，直到处置数量全部扣完
  • 批次数量扣减为0时，DELETE该批次记录
  • 处置数量不能超过库存数量

10.5 删除与取消规则

  • 草稿状态的报废入库单可直接删除，已审批的需先反审
  • 待确认状态的报废处置单可删除/驳回，已确认的不可删除
  • 已审批的报废入库单在未处置前可反审，已处置的阻止反审
