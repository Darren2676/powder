# 销售订单状态体系说明

## 概述

销售订单模块包含 **3 个层级的状态管理**，分别服务于流程控制、业务跟踪和执行明细跟踪。

---

## 1. 审批状态 `approval_status`（订单头部）

**所属表**: `sales_order`

**职责**: 流程控制，管理单据的审批生命周期，决定订单是否可编辑。

| 状态值 | 说明 | 允许的操作 |
|--------|------|-----------|
| 草稿 | 新建订单，尚未提交审批 | 自由编辑所有字段、删除、提交审核 |
| 待审批/审批中 | 已提交，等待审批人审核 | 撤回提交 |
| 已审批 | 审批通过，订单生效 | 仅限修改白名单字段（交货日期、备注等）、反审退回 |

**状态流转**:

```
草稿 ──提交审核──→ 待审批/审批中 ──审核通过──→ 已审批
 ↑                    │                        │
 └────撤回提交─────────┘                        │
 ↑                                             │
 └──────────反审退回────────────────────────────┘
```

**编辑权限控制逻辑**:
- `草稿`: 全字段可编辑，明细行可增删改
- `待审批/审批中`: 不允许编辑
- `已审批`: 仅允许更新白名单字段（交货日期、承诺交货日期、备注），明细行不可新增/删除

---

## 2. 订单状态 `order_status`（订单头部）

**所属表**: `sales_order`

**职责**: 业务状态，反映整张订单的执行进度。

| 状态值 | 说明 | 颜色标识 |
|--------|------|---------|
| 待执行 | 订单已创建/审批通过，尚未开始执行 | 灰色(default) |
| 生产中 | 订单关联的产品正在生产 | 蓝色(blue) |
| 已完成 | 所有明细行均已完成 | 绿色(green) |
| 已取消 | 订单已取消 | 红色(red) |

**说明**: 订单状态由用户在新建/编辑时手动设置，也可由系统根据明细行的整体完成情况进行更新。

---

## 3. 明细行状态（订单明细）

**所属表**: `sales_order_detail`

每一行明细拥有 **4 个独立的状态维度**，分别跟踪不同业务环节的执行进度：

### 3.1 行状态 `status`

反映该明细行的总体执行状态。

| 状态值 | 说明 | 颜色标识 |
|--------|------|---------|
| 未开始 | 明细行尚未进入任何业务流程 | 灰色(default) |
| 进行中 | 生产/发货等环节正在执行中 | 蓝色(blue) |
| 已完成 | 该行所有业务环节均已完成 | 绿色(green) |
| 已作废 | 该行已作废，不再执行 | 红色(red) |

### 3.2 发货状态 `shipping_status`

跟踪该明细行的发货进度。

| 状态值 | 说明 | 颜色标识 |
|--------|------|---------|
| 未申请 | 尚未创建发货申请 | 灰色(default) |
| 部分发货 | 已发货数量 < 订单数量 | 蓝色(blue) |
| 全部发货 | 已发货数量 = 订单数量 | 绿色(green) |
| 超额发货 | 已发货数量 > 订单数量 | 橙色(orange) |

### 3.3 生产状态 `production_status`

跟踪该明细行关联的生产计划执行情况。

| 状态值 | 说明 | 颜色标识 |
|--------|------|---------|
| 未加入计划 | 尚未纳入生产计划 | 灰色(default) |
| 待排产 | 已加入计划，等待排产 | 橙色(orange) |
| 计划中 | 已排产，等待执行 | 青色(cyan) |
| 待生产 | 已分配生产资源，等待开工 | 青色(cyan) |
| 生产中 | 正在生产 | 蓝色(blue) |
| 生产完成 | 生产已完成 | 绿色(green) |

### 3.4 退货状态 `return_status`

跟踪该明细行的退货情况。

| 状态值 | 说明 | 颜色标识 |
|--------|------|---------|
| 未申请 | 无退货记录 | 灰色(default) |
| 部分退货 | 存在退货，但退货数量 < 发货数量 | 橙色(orange) |
| 全部退货 | 退货数量 = 发货数量 | 红色(red) |
| 未退货 | 有发货但无退货 | 蓝色(blue) |

## 状态关联关系

```
┌─────────────────────────────────────────────────────────┐
│                    订单头部 (sales_order)                 │
│                                                         │
│  审批状态 (approval_status)    订单状态 (order_status)    │
│   - 草稿                       - 待执行                  │
│   - 待审批/审批中               - 生产中                  │
│   - 已审批                      - 已完成                  │
│                                 - 已取消                  │
│                                                         │
│  审批状态控制"能不能改"          订单状态反映"整单进展"     │
└───────────────────────┬─────────────────────────────────┘
                        │
          订单状态由明细行状态汇总决定
                        │
┌───────────────────────┴─────────────────────────────────┐
│               订单明细行 (sales_order_detail)             │
│                                                         │
│  ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐   │
│  │ 行状态    │ │ 发货状态  │ │ 生产状态  │ │ 退货状态  │   │
│  │ (status) │ │(shipping)│ │(production│ │ (return) │   │
│  │          │ │          │ │          │ │          │   │
│  │ 未开始   │ │ 未申请   │ │ 未加入计划│ │ 未申请   │   │
│  │ 进行中   │ │ 部分发货 │ │ 待排产   │ │ 部分退货 │   │
│  │ 已完成   │ │ 全部发货 │ │ 计划中   │ │ 全部退货 │   │
│  │ 已作废   │ │ 超额发货 │ │ 生产中   │ │ 未退货   │   │
│  │          │ │          │ │ 生产完成 │ │          │   │
│  └──────────┘ └──────────┘ └──────────┘ └──────────┘   │
│                                                         │
│  行状态 = 生产状态 + 发货状态 + 退货状态 的综合反映       │
└─────────────────────────────────────────────────────────┘
```

---

## 核心逻辑总结

| 维度 | 层级 | 职责 | 影响范围 |
|------|------|------|---------|
| 审批状态 | 订单头部 | 流程控制：决定单据是否可编辑 | 控制整单及所有明细行的编辑权限 |
| 订单状态 | 订单头部 | 业务跟踪：反映整单的执行进度 | 由明细行的整体完成情况汇总决定 |
| 行状态 | 明细行 | 行级跟踪：反映单行的总体执行状态 | 综合反映该行的生产、发货、退货情况 |
| 发货状态 | 明细行 | 发货环节：跟踪该行的发货进度 | 由发货申请/发货单更新 |
| 生产状态 | 明细行 | 生产环节：跟踪该行的生产计划执行 | 由生产计划/工单更新 |
| 退货状态 | 明细行 | 退货环节：跟踪该行的退货情况 | 由退货单更新 |

---

## 典型业务流程

```
1. 新建订单 → 审批状态=草稿, 订单状态=待执行
2. 提交审核 → 审批状态=待审批
3. 审核通过 → 审批状态=已审批 (订单生效，可开始执行)
4. 纳入生产计划 → 明细行生产状态=计划中, 行状态=进行中
5. 开始生产 → 明细行生产状态=生产中, 订单状态=生产中
6. 生产完成 → 明细行生产状态=生产完成
7. 发货 → 明细行发货状态=部分发货/全部发货
8. 全部完成 → 明细行状态=已完成, 订单状态=已完成
```
