# Seals MES System -- 采购管理方案设计文档

## 一、业务流程总览

```
采购申请单(PR)  -->  采购单(PUR)  -->  来料入库单(SI)
   |                   |                   |
 生产备料需求        供应商确认         物料库存更新
 安全库存补充                        (material_inventory)
 手动创建                           (material_batch_inventory)
                                    (material_inventory_transaction)
```

**核心流转**：
1. **采购申请** -- 由生产备料缺料、安全库存预警或手动发起，描述"需要买什么、买多少"
2. **采购订单** -- 选定供应商、确认价格和交期，从采购申请转化或手动创建
3. **来料入库** -- 供应商送货到仓，检验后入库，自动更新现有物料库存体系

## 三、业务流程详细设计

### 3.1 采购申请流程

```
创建申请(草稿) -> 添加物料明细行 -> 提交审批(待审批) -> 审批通过(已审批)
                                                         |
                                               选择明细行 -> 转采购订单
                                                         |
                                          更新 ordered_quantity 和行状态
```

**状态流转**：
- `approval_status`: 草稿 -> 待审批 -> 已审批 / 已驳回
- `order_status`: 未执行 -> 部分转单 (部分明细已转) -> 已转单 (全部明细已转)
- 草稿状态可编辑/删除，审批后不可修改

**转采购订单逻辑**：
- 用户在已审批的申请单上选择一行或多行，选择供应商，一键生成采购订单
- 同一申请的不同明细行可以转给不同的供应商（生成多个采购订单）
- 转单后自动更新 `ordered_quantity`，当所有行 `ordered_quantity >= request_quantity` 时，主表 `order_status` 变为"已转单"

### 3.2 采购订单流程

```
创建订单(草稿) -> 添加物料明细行 -> 提交审批(待审批) -> 审批通过(已审批)
                   |                                    |
        从采购申请转入                          选择明细行 -> 创建入库单
        或手动创建                                        |
                                            更新 received_quantity 和到货状态
```

**创建方式**：
- **从采购申请转入**：自动填充供应商、物料信息、数量，并记录 `source_req_number`
- **手动创建**：手动选择供应商，添加物料明细行

**状态流转**：
- `approval_status`: 草稿 -> 待审批 -> 已审批 / 已驳回
- `order_status`: 待执行 -> 执行中 (部分到货入库) -> 已完成 (全部入库) / 已关闭 (手动关闭)
- `receive_status` (明细行): 未到货 -> 部分到货 -> 已到货

### 3.3 来料入库流程

```
选择采购订单 -> 自动带出未入库明细 -> 填写本次入库数量/合格数量 -> 选择仓库 -> 确认入库
                                                                              |
                                                     +------------------------+--------+
                                                     |                        |        |
                                               生成物料批次号          更新物料库存  写入库存流水
                                              (material_batch        (material_   (material_inventory
                                               _inventory)            inventory)   _transaction)
                                                     |
                                        回写采购订单 received_quantity
```

**与现有库存系统集成**（复用现有表和函数，不新建）：
- 入库确认后，调用现有 `materialWarehouse.controller.ts` 中的逻辑：
  - `generateBatchNumber('MB')` -- 生成物料批次号
  - 插入 `material_batch_inventory` -- 新增批次库存记录
  - `syncMaterialInventorySummary()` -- 同步汇总到 `material_inventory`
  - `generateMaterialTxnNumber()` -- 生成流水号
  - 插入 `material_inventory_transaction` -- 写入库存流水 (source_type='采购入库', source_number=入库单号)
- 回写 `purchase_order_detail.received_quantity += 本次合格入库数量`
- 判断采购订单所有行是否全部到货，更新 `purchase_order.order_status`
