采购收货到质量特性判定全流程逻辑流程图

睿信橡胶密封件MES系统 | 采购收货 → 来料检验判定 → 质量特性启用 → 自动判定合格/不合格 → NC分流处理的全链路业务流程
文档说明：本文档完整展示采购收货到质量特性判定的7个阶段：
阶段1 采购收货通知：供应商送货 → 创建入库单 → 自动报检
阶段2 检验判定与入库分流：是否需检验 → 免检入默认仓 / 待检入待检仓
阶段3 质量特性启用判定：物料主数据优先 → 方案次之 → 确定是否启用质量特性录入
阶段4 质量特性录入与自动判定：计量型上下限判定 / 计件型标准值判定 / 全部合格→检验合格
阶段5 检验结论与NC创建：合格品转仓入库 / 不合格品创建NC单
阶段6 NC分流处理：挑选 / 拒收 / 报废 / 特采 / 退货 5种处理方式
阶段7 撤销回退：安全检查 → 反转关联单据 → 状态回退
涵盖状态流转、数据变更矩阵、关键业务规则及各环节的数据实体关系。

enable_quality_chars 优先级规则：
① 物料主数据 > 检验方案：若 item_master.enable_quality_chars = 'Y'，则不论方案设置如何，均启用

自动判定规则说明：
① 计量型：实测值必须在 [lower_limit, upper_limit] 区间内，超出任一边界即为不合格
② 计件型/计点型：实测值 ≤ standard_value 为合格，超出标准值为不合格
③ 空白实测值：不自动判定，is_qualified 保持空，需人工填写
④ 结论汇总：启用质量特性时，所有特性行全部合格才判定检验合格，任一不合格即判定检验不合格
⑤ 完成检验必填：启用质量特性时，所有特性行必须填写实测值才能完成检验（前端+后端双重校验）
