# 调度单多模板打印方案

## 一、需求分析

| 现状 | 痛点 | 目标 |
|------|------|------|
| 所有生产单使用统一的详细打印格式 | 不同产品类型（油封、O型圈、骨架油封等）的工序/备料差异大，统一格式存在冗余或缺失 | 支持按产品类型/工艺特征自动匹配不同的打印模板 |

**典型场景：**
- **油封类产品**：需要突出模具信息、成型件规格、硫化参数
- **O型圈类产品**：需要突出尺寸规格、硬度、颜色
- **骨架油封**：需要突出骨架供应商、粘合工艺参数
- **杂件类**：工序简单，不需要复杂的工序任务表

## 二、方案对比

| 方案 | 实现复杂度 | 灵活度 | 维护成本 | 推荐度 |
|------|-----------|--------|---------|--------|
| A. 按产品分类自动匹配模板 | 低 | 中 | 低 | ★★★★★ |
| B. 调度单派发时手动选择模板 | 中 | 高 | 中 | ★★★★ |
| C. 完全可视化拖拽配置模板 | 高 | 极高 | 高 | ★★ |
| D. 按工艺路线特征动态生成 | 中 | 高 | 中 | ★★★ |

## 三、推荐方案：按产品分类自动匹配模板（方案 A）

### 3.1 核心思路

在**产品分类**（`product_class`）或**产品主数据**（`item_master`）上关联**打印模板标识**，调度单打印时根据产品所属分类自动匹配对应的 HTML 模板。

```
产品分类（product_class）
  ├── 油封类 → 模板: "seal-oil"
  ├── O型圈类 → 模板: "seal-o-ring"
  ├── 骨架油封类 → 模板: "seal-skeleton"
  └── 杂件类 → 模板: "seal-misc"
```

### 3.2 数据库设计

**方案 1：在产品分类表扩展字段（推荐）**

```sql
-- 在 product_class 表新增字段
ALTER TABLE product_class ADD COLUMN print_template VARCHAR(50) NULL;
-- 注释: 关联的打印模板标识，如 'seal-oil', 'seal-o-ring'
```

**方案 2：新增模板配置表（更灵活）**

```sql
CREATE TABLE print_template_config (
  id INT IDENTITY(1,1) PRIMARY KEY,
  template_code VARCHAR(50) NOT NULL UNIQUE,     -- 模板标识: seal-oil
  template_name NVARCHAR(100) NOT NULL,          -- 模板名称: 油封类调度单
  product_class_ids NVARCHAR(500),               -- 关联的产品分类ID列表: 1,2,3
  description NVARCHAR(500),
  is_default BIT DEFAULT 0,                      -- 是否默认模板
  created_at DATETIME DEFAULT GETDATE(),
  updated_at DATETIME DEFAULT GETDATE()
);

-- 插入模板配置
INSERT INTO print_template_config (template_code, template_name, product_class_ids, is_default)
VALUES 
  ('default', '默认模板', NULL, 1),
  ('seal-oil', '油封类模板', '1,2', 0),
  ('seal-o-ring', 'O型圈类模板', '3', 0),
  ('seal-skeleton', '骨架油封类模板', '4', 0);
```

### 3.3 后端接口调整

**`GET /api/orders/print-data` 接口改造：**

```typescript
// 在 getPrintData 中增加模板匹配逻辑
export const getPrintData = async (req: Request, res: Response, next: NextFunction) => {
  try {
    const { production_order_numbers } = req.body;
    
    const results: any[] = [];
    
    for (const orderNum of production_order_numbers) {
      // 1. 查询生产单基本信息
      const [orders]: any = await sequelize.query(
        `SELECT po.*, pc.print_template 
         FROM production_order po
         LEFT JOIN item_master im ON po.item_number = im.item_number
         LEFT JOIN product_class pc ON im.product_class_id = pc.product_class_id
         WHERE po.production_order_number = :orderNum`,
        { replacements: { orderNum } }
      );
      
      const order = orders[0];
      
      // 2. 查询备料清单
      const [materials] = await sequelize.query(/* ... */);
      
      // 3. 查询工序任务
      const [tasks] = await sequelize.query(/* ... */);
      
      results.push({
        order,
        materials,
        tasks,
        template: order.print_template || 'default'  // <-- 返回模板标识
      });
    }
    
    res.json(success({ items: results }, '获取打印数据成功'));
  } catch (err) { next(err); }
};
```

### 3.4 前端实现

**在 `DispatchPrint/Index.vue` 中改造 `triggerDetailPrint`：**

```typescript
const triggerDetailPrint = () => {
  const items = detailPrintData.value
  if (!items || items.length === 0) return

  const printWindow = window.open('', '_blank', 'width=800,height=1000')
  if (!printWindow) { /* ... */ return }

  let pagesHtml = ''
  items.forEach((item: any, pageIdx: number) => {
    const templateCode = item.template || 'default'
    
    // 根据模板标识选择不同的渲染函数
    switch (templateCode) {
      case 'seal-oil':
        pagesHtml += renderSealOilTemplate(item, pageIdx, items.length)
        break
      case 'seal-o-ring':
        pagesHtml += renderSealORingTemplate(item, pageIdx, items.length)
        break
      case 'seal-skeleton':
        pagesHtml += renderSealSkeletonTemplate(item, pageIdx, items.length)
        break
      default:
        pagesHtml += renderDefaultTemplate(item, pageIdx, items.length)
    }
  })

  printWindow.document.write(/* 通用 HTML 框架 + pagesHtml */)
  printWindow.document.close()
}
```

## 四、备选方案：调度单手动选择模板（方案 B）

如果在派发时就需要指定打印格式，可在**生产单**表增加字段：

```sql
ALTER TABLE production_order ADD COLUMN print_template VARCHAR(50) NULL DEFAULT 'default';
```

在**派发编辑弹窗**中增加模板选择：

```vue
<a-select v-model:value="row.print_template" size="small" style="width:120px">
  <a-select-option value="default">默认</a-select-option>
  <a-select-option value="seal-oil">油封专用</a-select-option>
  <a-select-option value="seal-o-ring">O型圈专用</a-select-option>
</a-select>
```

**适用场景**：同一产品分类下仍有差异化打印需求，或生产计划员需要手动控制打印格式。

## 五、实施建议

| 阶段 | 任务 | 工时 |
|------|------|------|
| **Phase 1** | 产品分类表扩展 `print_template` 字段 + 基础数据配置界面 | 0.5 天 |
| **Phase 2** | 后端 `getPrintData` 接口返回 `template` 标识 | 0.5 天 |
| **Phase 3** | 前端重构：将 `triggerDetailPrint` 拆分为模板渲染函数族 | 1~2 天 |
| **Phase 4** | 开发第 1 个差异化模板（如油封类）并验证 | 1 天 |
| **Phase 5** | 按需开发其他产品类型模板 | 每模板 0.5 天 |
