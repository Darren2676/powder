采购收货到检验入库全流程逻辑流程图

睿信橡胶密封件MES系统 | 采购收货通知 → 来料检验 → 合格入库 → 不合格品处理 → 撤销回退的全链路业务流程
文档说明：本文档完整展示采购收货到检验入库的6个阶段：
阶段1 采购收货通知：供应商送货 → 创建入库单 → 自动报检
阶段2 确认入库：免检物料直接入默认仓库 / 需检验物料入待检仓
阶段3 来料检验：检验通知 → 执行检验 → 提交结果 → 合格/不合格分流
阶段4 合格品入库：待检仓→默认仓库转仓 + PO回写
阶段5 不合格品处理：挑选/拒收/报废/特采/退货 5种处理方式及其关联单据创建
阶段6 撤销处理：安全检查 → 反转关联单据 → 状态回退
涵盖状态流转、数据变更矩阵、关键业务规则及各环节的数据实体关系。

⚠ 撤销安全检查要点：
① 入库单保护：若NC关联的入库单（报废/特采）已确认入库（approval_status≠草稿），拒绝撤销，需先撤回入库单
② 退货单保护：若NC关联的采购退货单已提交/审批（approval_status≠草稿），拒绝撤销，需先撤回退货单
③ 数量恢复：特采撤销时需扣减检验单的qualified_quantity、恢复unqualified_quantity
④ 事务保证：所有反转操作在同一数据库事务中执行，任一步失败则全部回滚

11.7 撤销处理规则

规则说明
前置条件NC单 handling_status = 已完成 或 处理中
入库单保护关联的 stock_in 若 approval_status ≠ 草稿 → 拒绝撤销
退货单保护关联的 purchase_return 若 approval_status ≠ 草稿 → 拒绝撤销
数量恢复特采：qualified -= specialQty, unqualified += specialQty
挑选：恢复原始 qualified/unqualified
事务保证所有反转在同一事务中执行，任一失败全部回滚
撤销后状态NC单 handling_status → 待处理，清空所有处理字段
