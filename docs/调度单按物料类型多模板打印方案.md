# 调度单按物料类型多模板打印方案

## 一、需求理解

系统中物料主数据（`item_master`）的 `item_type` 包含：成品、原材料、骨架、预成型件、半成品、包材。

当前"调度单打印"仅支持**生产调度单**（成品视角）一种格式。实际业务中需要按物料类型打印不同单据：

| 物料类型 | 业务单据 | 打印内容特征 |
|---------|---------|-------------|
| **成品** | 生产调度单 | 完整格式：基本信息 + 备料清单 + 工序任务 + 不良品记录 |
| **原材料（胶料）** | 胶料领料单 | 突出：供应商、批次、硬度、密度、硫化参数、存储条件 |
| **骨架** | 骨架领料标签 | 突出：供应商、材质、表面处理、尺寸公差、来料检验状态 |
| **预成型件** | 预成型件流转卡 | 突出：来源BOM、半成品规格、成型参数、下道工序 |
| **半成品** | 半成品流转卡 | 突出：来源工单、工序进度、检验结果、转入下工序确认 |

## 二、两种实现方案

### 方案 A：调度单页面增加多类型打印按钮（推荐）

在现有"调度单打印"列表页，根据勾选的记录自动识别物料类型，提供不同的打印按钮。

```
调度单打印页面
├── 列表勾选记录
├── 打印按钮组
│   ├── 【打印生产调度单】→ 成品格式
│   ├── 【打印胶料领料单】→ 原材料格式（仅勾选了胶料备料行时可用）
│   ├── 【打印骨架标签】→ 骨架格式（仅勾选了骨架备料行时可用）
│   └── 【打印预成型件流转卡】→ 预成型件格式
```

**适用场景**：同一生产单下包含多种物料，需要分别打印不同单据。

### 方案 B：按生产单产品类型自动匹配模板

在`production_order`上扩展`print_template`字段，根据生产的产品类型自动匹配模板。

```
生产单（产品类型=成品）→ 生产调度单模板
生产单（产品类型=预成型件）→ 预成型件流转卡模板
生产单（产品类型=半成品）→ 半成品流转卡模板
```

**适用场景**：不同产品类型的生产流程差异大，需要完全不同的单据格式。

### 3.3 后端接口调整

**新增接口：`POST /api/orders/material-print-data`**

用途：按物料类型获取打印数据（从生产单的备料清单中筛选指定类型的物料）

```typescript
export const getMaterialPrintData = async (req: Request, res: Response, next: NextFunction) => {
  try {
    const { production_order_numbers, material_type } = req.body;
    
    const results: any[] = [];
    
    for (const orderNum of production_order_numbers) {
      // 1. 查询生产单基本信息
      const [orders]: any = await sequelize.query(
        `SELECT * FROM production_order WHERE production_order_number = :orderNum`,
        { replacements: { orderNum } }
      );
      const order = orders[0];
      
      // 2. 查询指定类型的备料物料（从备料单/BOM明细中筛选）
      const [materials]: any = await sequelize.query(
        `SELECT pm.*, im.* 
         FROM production_material pm
         LEFT JOIN item_master im ON pm.material_number = im.item_number
         WHERE pm.production_order_number = :orderNum 
         AND im.item_type = :materialType`,
        { replacements: { orderNum, materialType: material_type } }
      );
      
      // 3. 查询胶料质量参数（如果是胶料）
      let qualityParams = null;
      if (material_type === '原材料') {
        const [params]: any = await sequelize.query(
          `SELECT * FROM rubber_compound_params 
           WHERE production_order_number = :orderNum`,
          { replacements: { orderNum } }
        );
        qualityParams = params[0] || null;
      }
      
      results.push({ order, materials, qualityParams });
    }
    
    res.json(success({ items: results }, '获取物料打印数据成功'));
  } catch (err) { next(err); }
};
```

### 3.4 数据库检查清单

需要确认以下表/字段是否存在：

| 数据项 | 用途 | 检查方式 |
|--------|------|---------|
| `item_master.item_type` | 区分物料类型 | 已确认存在（成品/原材料/骨架/预成型件/半成品/包材） |
| `production_order` ↔ `item_master` 关联 | 获取产品类型 | 通过 `item_number` 关联 |
| 备料单/生产物料明细表 | 获取生产单的物料清单 | 需确认表名（如 `production_material` / `material_requisition`） |
| 胶料质量参数表 | 胶料领料单中的硬度/密度等参数 | 需确认是否存在（可能在 `item_master` 扩展字段或独立表） |
| 骨架供应商/材质信息 | 骨架标签中的供应商和材质 | 可能在 `item_master` 或 `supplier` 关联表中 |
