采购入库业务全流程逻辑流程图

睿信橡胶密封件MES系统 | 从供应商送货到收货通知、确认入库、来料检验、检验转仓、入库撤回的全链路业务流程
文档说明：本文档完整展示采购入库业务的5个阶段：
阶段1 采购收货通知：供应商送货 → 创建入库单 → 自动报检
阶段2 确认入库：免检物料直接入默认仓库 / 需检验物料入待检仓
阶段3 来料检验：检验通知 → 执行检验 → 提交结果 → 不合格品NC处理
阶段4 检验后转仓：合格品待检仓→默认仓库 / 不合格品退货/让步/报废
阶段5 入库撤回：安全检查 → 7步反转 → 状态回退
涵盖状态流转、数据变更矩阵、关键业务规则及各环节的数据实体关系。
