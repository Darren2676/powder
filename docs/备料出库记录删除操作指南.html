备料出库记录删除操作指南

Seals MES System — 睿信橡胶密封件制造执行系统
文档版本: v1.0 | 适用日期: 2026年4月

一、功能概述

备料出库记录删除（即"撤回领料"）功能，允许操作人员在发现领料错误时，将已生成的备料出库单完全回退，包括：

回退项说明
物料库存恢复批次库存 / 汇总库存数量还原，同时生成入库对冲流水记录
备料明细回退issued_quantity 扣减对应领料数量
备料单状态重算preparation_status 从「已领料」退回「部分领料」或「未领料」
生产单状态回退plan_status 从「已备料」退回「已派发」（条件触发）
线边仓对冲创建「出线边」对冲记录，冲销领料入线边
领料单删除物理删除 material_issue 和 material_issue_detail 记录
注意：撤回操作不可逆。确认撤回后，领料单据将被物理删除，仅保留对冲流水作为审计线索。

二、WEB 端操作步骤

2.1 入口一：通过「生产备料」菜单

1 打开菜单

点击左侧菜单栏：生产管理 → 生产备料

页面 URL：/production/material-issue

2 搜索生产单

在顶部搜索框输入/扫码 生产单编号（如 P20260504008），点击 「查询」 按钮。

3 定位到历史领料记录表格

查询成功后，页面从上到下依次显示：

  • 生产单基本信息（编号、产品、规格、计划数量等）
  • 备料单信息摘要卡片（备料单编号、BOM、物料种类、状态标签、「开始备料」按钮）
  • 📋 历史领料记录表格 — 撤回按钮在此处
4 执行撤回

在「历史领料记录」表格中，每一行的 最后一列 有一个红色 「撤回」 按钮：

  1. 点击 撤回 按钮
  2. 弹出确认框：「确认要撤回此领料单吗？物料库存、备料单状态、生产单状态将同步回退。」
  3. 点击 「确认撤回」
  4. 系统开始回退，按钮显示加载状态
  5. 成功后页面自动刷新，领料记录从列表中消失

三、APP 端操作步骤

3.1 唯一入口：通过「按工序备料」进入

1 打开首页入口

在 APP 首页中，点击功能入口 「按工序备料」。

2 选择生产单

在按工序备料列表页中，找到并点击目标生产单（如 P20260504008），进入详情操作页。

3 滑动到页面最底部

进入详情页后，页面从上到下依次显示：

  • 生产单信息卡片（编号、产品、规格、备料进度）
  • 工序步骤条（当前选中工序高亮）
  • 当前工序物料列表 / 已备料完成提示
  • 全部完成区域（🎉 所有工序备料已完成）
  • ⚠️ 继续向下滑动
  • 📋 历史领料记录列表 — 撤回按钮在此处
4 执行撤回
  1. 在「历史领料记录」列表中，每条记录右侧有一个红色 「撤回」 按钮
  2. 点击 撤回 → 弹出对话框：「确认要撤回领料单 MI-xxx 吗？物料库存、备料单状态将同步回退。」
  3. 点击 「确认撤回」
  4. 撤回成功后页面自动刷新，状态和数据同步回退

四、撤回后验证方法

验证项验证方法预期结果
领料单是否删除 刷新页面，历史领料记录中该条消失 领料单不再显示
备料单状态回退 查看备料单摘要卡片的状态标签 「已领料」→「部分领料」或「未领料」
备料明细已领量回退 打开「开始备料」弹窗，查看物料的已领量 issued_quantity 减少对应数量
生产单状态回退 查看生产单信息中的 plan_status 标签 「已备料」→「已派发」（条件触发）
物料库存恢复 在仓库管理页面查看对应物料库存 库存数量增加对应领料数量
物料流水对冲记录 查询 material_inventory_transaction 表 存在 transaction_type='入库', source_type='领料撤回' 的对冲流水

五、常见问题

Q1: 看不到「历史领料记录」表格

原因：该生产单尚未执行过任何备料出库操作。只有至少执行过一次领料后，历史记录表格才会出现。

Q2: 点击「撤回」后报错

常见原因：

  • 网络连接异常 → 刷新页面后重试
  • 该领料单已被他人撤回 → 刷新页面确认记录是否已消失
  • 服务器异常 → 联系系统管理员查看后端日志

Q3: WEB 端菜单中找不到「生产备料」或「按工序备料」

原因：当前登录角色没有对应菜单权限。请联系管理员在 系统管理 → 权限菜单 中为该角色分配菜单权限。

Q4: 撤回后备料单状态没有回退

如果撤回后仍有其他领料单覆盖了对应物料的需求量，备料单状态可能保持不变。例如：全部物料需求量为 10，第一次领了 8，第二次领了 2。撤回第二次后，第一次的 8 仍然满足全部需求，状态保持「已领料」不变。这是正常行为。
