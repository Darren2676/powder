## 📋 需求概述

### 业务场景

仓库管理员在委外发料和收回时，通过手机 APP 扫描物料条码或委外订单二维码，快速完成发料和收回操作，提高工作效率。

### 核心功能

1. **委外发料扫码**
   - 扫描委外订单二维码获取订单信息
   - 扫描物料条码确认发料物料
   - 输入发料数量
   - 确认发料（扣减库存）

2. **委外收回扫码**
   - 扫描委外订单二维码获取订单信息
   - 扫描物料条码确认收回物料
   - 输入收回数量
   - 确认收回（触发质检）

### 3. 扫码逻辑

```typescript
import { Html5Qrcode } from 'html5-qrcode'

const openScanner = () => {
  scannerVisible.value = true
  nextTick(() => {
    const qrReader = new Html5Qrcode('qr-reader-outsourcing')
    qrReader.start(
      { facingMode: 'environment' },
      { fps: 10, qrbox: { width: 250, height: 250 } },
      (decodedText) => {
        // 扫码成功
        onScanSuccess(decodedText)
        qrReader.stop()
      },
      (errorMessage) => {
        // 扫码失败（忽略）
      }
    )
  })
}

const onScanSuccess = async (decodedText: string) => {
  // 解析二维码内容
  // 委外订单二维码格式: {"type":"outsourcing_order","number":"OS-20260429-001"}
  // 物料条码格式: {"type":"item","number":"M001"}
  
  try {
    const data = JSON.parse(decodedText)
    if (data.type === 'outsourcing_order') {
      await loadOrder(data.number)
    } else if (data.type === 'item') {
      await scanItem(data.number)
    }
  } catch (e) {
    showToast('二维码格式错误')
  }
}
```

## 📱 二维码规范

### 委外订单二维码

**格式**: JSON
```json
{
  "type": "outsourcing_order",
  "number": "OS-20260429-001",
  "supplier": "供应商名称",
  "item": "产品编号",
  "quantity": 1000
}
```

### 物料条码

**格式**: JSON
```json
{
  "type": "item",
  "number": "M001",
  "name": "物料名称",
  "batch": "批次号"
}
```

## 🎨 UI/UX 设计要点

### 设计原则

1. **简化操作** - 尽量减少输入，多用扫码
2. **清晰反馈** - 扫码成功/失败有明确提示
3. **防错设计** - 数量输入有校验，避免误操作
4. **离线支持** - 网络不稳定时缓存数据

### 交互细节

- **扫码反馈**: 震动 + 音效 + 绿色边框闪烁
- **数量输入**: 数字键盘，支持 +/- 按钮
- **确认操作**: 二次确认弹窗，显示关键信息
- **成功提示**: Toast 提示 + 自动返回
