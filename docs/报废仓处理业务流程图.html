🔍 来料/生产/委外检验
步骤 1
采购收货 / 生产报工 / 委外收货
物料到达或生产完成，触发检验流程
→
步骤 2
质量检验
按检验规范执行检验，记录合格/不合格数量
表：purchase_inspection production_inspection outsourcing_inspection
→
判定
检验结果
合格 vs 不合格
⬇️
合格 → 正常入库流程（合格品仓），结束本流程
不合格 → 自动生成不合格品记录，进入阶段二
⚠️ 不合格品处理单
步骤 3
自动生成不合格品单
检验不合格时自动创建NC单，记录不合格数量
表：nonconforming_product
来源：来料检验 / 生产检验 / 委外检验
状态：待处理
→
步骤 4
选择处理方式
质量管理员选择处理方式（5种可选）
→
处理选择
5种处理方式
挑选 / 拒收 / 报废 / 特采 / 退货
⬇️
挑选→ 分拣后合格品入库
拒收→ 退回供应商
报废→ 生成报废入库单，进入阶段三（本流程主线）
特采→ 让步接收，合格品入库
退货→ 退货入库到待检仓

步骤 5
生成报废入库单
选择"报废"后自动创建入库单（stock_in_type='报废入库'）
表：stock_in
类型：报废入库
仓库：08号报废仓库（warehouse_type='报废仓库'）
状态：草稿
→
步骤 6
提交审批
提交报废入库单审批
状态：草稿 → 审批中
表：approval_log
→
审批
审批结果
通过 / 驳回 / 反审
⬇️
审批通过 → 自动更新库存（Phase 3 核心）
🔧 自动库存更新流程（审批通过后自动执行）
自动 6A
写入报废批次库存
为报废物料生成批次号，写入 finished_batch_inventory
quality_status = 不合格品
表：finished_batch_inventory
→
自动 6B
更新汇总库存
更新不合格品汇总数量
表：finished_goods_inventory
quality_status = 不合格品
→
自动 6C
记录库存流水
写入库存事务流水记录，完整可追溯
source_type = '报废入库'
表：inventory_transaction
→
自动 6D
更新NC单状态
更新不合格品单状态为"已完成"
表：nonconforming_product
handling_status = '已完成'
⬇️
反审 → 自动回退库存：删除/扣减批次库存 → 同步汇总库存 → 标记流水作废 → 若批次已被消耗则阻止反审
🔧 报废仓处置出库
步骤 7
查看报废仓库存
按物料汇总查看报废仓库存，可点击批次明细查看具体批次
接口：GET /scrap-disposal/inventory
查询条件：warehouse_type = '报废仓库'
→
步骤 8
创建报废处置申请
选择要处置的物料和数量，填写处置原因
接口：POST /scrap-disposal/disposals
表：scrap_disposal + scrap_disposal_detail
单号：SD-YYYYMMDD-NNN
状态：待确认
→
步骤 9
确认处置（执行出库）
确认后执行FIFO批次扣减，更新库存
接口：POST /scrap-disposal/disposals/:number/confirm
扣减逻辑：FIFO先进先出
状态：待确认 → 已确认
⬇️
自动 9A
FIFO批次扣减
按入库日期从早到晚扣减批次库存
表：finished_batch_inventory
扣减顺序：inbound_date ASC, id ASC
批次为0时删除记录
→
自动 9B
同步汇总库存
同步更新不合格品汇总数量
表：finished_goods_inventory
quality_status = 不合格品
→
自动 9C
记录出库流水
写入库存事务流水记录
source_type = '报废处置'
表：inventory_transaction
流水类型：出库

🔄 数据流向总结
1. 检验不合格 → 不合格品记录
purchase_inspection / production_inspection → nonconforming_product
字段映射：unqualified_quantity → handling_quantity, handling_status = '待处理'
2. 选择报废 → 报废入库单
nonconforming_product → stock_in (stock_in_type='报废入库')
仓库：warehouse_type='报废仓库' (08号仓), approval_status='草稿'
3. 审批通过 → 自动更新库存
stock_in → finished_batch_inventory (新增批次, quality_status='不合格品')
stock_in → finished_goods_inventory (汇总数量增加)
stock_in → inventory_transaction (source_type='报废入库')
4. 报废处置 → FIFO出库
scrap_disposal → finished_batch_inventory (FIFO批次扣减, quantity减少)
scrap_disposal → finished_goods_inventory (汇总数量减少)
scrap_disposal → inventory_transaction (source_type='报废处置')
5. 报表统计 → 多表联查
nonconforming_product + stock_in + scrap_disposal + inventory_transaction + finished_batch_inventory
