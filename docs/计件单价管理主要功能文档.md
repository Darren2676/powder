# 计件单价管理 — 主要功能文档

## 1. 模块概述

计件单价管理是 MES 系统中**计件工资体系的基础数据模块**，用于定义和维护各物料在各工序上的计件单价表。审批通过的价目表将作为计件工资计算的依据，实现"按件计酬"的工资核算模式。

**核心定位**：计件工资的"价目表"——定义谁做什么东西、在哪个工序、合格品多少钱、次品多少钱。

---

## 2. 业务流程

```
┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│   创建价目表  │───→│   提交审批    │───→│   审批通过    │
│   （草稿）    │    │  （待审批）   │    │  （已审批）   │
└─────────────┘    └─────────────┘    └──────┬──────┘
       ↑                                     │
       │            ┌─────────────┐          │ 生效，参与
       ├── 撤回 ────│  反审批/撤消  │←────────┘ 工资计算
       │            └─────────────┘
       │
       └── 草稿状态可编辑、删除
```

**计件工资计算链路**：

```
计件单价表（定义单价） → 生产报工记录（工人产出） → 匹配单价计算工资
```

匹配维度：**物料 + 工序 + 日期 + 员工（可选）**

工资公式：`行工资 = 合格品数量 × 合格品单价 + 次品数量 × 次品单价`

## 3. 数据结构

### 3.1 价目表头（piece_rate_price_header）

| 字段 | 类型 | 说明 |
|------|------|------|
| price_list_number | NVARCHAR(50) | 价目表编号，主键，格式 `PR-YYYYMMDD-###` |
| price_list_name | NVARCHAR | 价目表名称 |
| effective_date | DATE | 生效日期 |
| expiration_date | DATE | 失效日期 |
| approval_status | NVARCHAR | 审批状态：草稿 / 待审批 / 已审批 |
| remark | NVARCHAR | 备注 |
| creation_date | NVARCHAR | 创建日期时间 |
| creation_man | NVARCHAR | 创建人 |

### 3.2 价目表明细（piece_rate_price_detail）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INT IDENTITY | 明细ID，主键 |
| price_list_number | NVARCHAR(50) | 关联价目表编号，外键 |
| line_number | INT | 行号，步长10 |
| item_number | NVARCHAR | 物料编号 |
| item_name | NVARCHAR | 物料名称 |
| standard_process_number | NVARCHAR | 工序编号 |
| standard_process_name | NVARCHAR | 工序名称 |
| item_category | NVARCHAR | 物料分类 |
| equipment_number | NVARCHAR | 设备编号（可选） |
| equipment_name | NVARCHAR | 设备名称 |
| employee_number | NVARCHAR | 人员编号（可选，员工专属定价） |
| employee_name | NVARCHAR | 人员名称 |
| qualified_piece_rate | DECIMAL(18,6) | 合格品计件单价 |
| defective_piece_rate | DECIMAL(18,6) | 次品计件单价 |
| drawing_number | NVARCHAR | 图号 |
| version | NVARCHAR | 版本 |
| specifications | NVARCHAR | 规格 |
| material_type | NVARCHAR | 材质 |
| custom_field | NVARCHAR | 自定义项 |

## 4. 功能清单

### 4.1 列表页

| 功能 | 说明 |
|------|------|
| 分页查询 | 默认每页20条，支持切换页大小 |
| 模糊搜索 | 按价目表编号或名称搜索 |
| 审批状态筛选 | 下拉筛选：草稿 / 待审批 / 已审批 |
| 列个性化 | 列排序、显示/隐藏、列宽调整，设置持久化 |
| 行选择 | 勾选行支持跨页保持，显示已选数量 |
| 刷新 | 手动刷新列表数据 |

### 4.2 新建价目表

1. 填写表头：名称（必填）、生效日期（必填）、失效日期（必填）、备注
2. 系统自动生成编号，格式 `PR-YYYYMMDD-###`（如同日已有3条则下一条为004）
3. 添加明细行：
   - 选择物料（下拉搜索，自动填充物料名称、分类、规格）
   - 选择工序（下拉搜索，自动填充工序名称）
   - 选择设备（可选，下拉搜索，自动填充设备名称）
   - 选择人员（可选，下拉搜索，自动填充人员名称——用于员工专属定价覆盖）
   - 填写合格品单价、次品单价（精度6位小数）
   - 填写图号、版本、规格、材质、自定义项（可选）
4. 保存后状态为"草稿"

### 4.3 编辑价目表

- 仅"草稿"状态可编辑
- 编辑时先删除原明细再重新写入（全量替换策略）
- 已提交或已审批的价目表不允许编辑

### 4.4 删除价目表

- 仅"草稿"状态可删除
- 删除时级联删除所有明细行（事务保护）

### 4.5 查看价目表

- 任何状态均可查看
- 弹窗内所有字段只读

### 4.6 审批流程

| 操作 | 条件 | 说明 |
|------|------|------|
| 提交审批 | 草稿 | 状态变更为"待审批" |
| 审核 | 待审批 | 状态变更为"已审批"，价目表生效 |
| 撤回 | 待审批 | 退回草稿状态，可继续编辑 |
| 反审批 | 已审批 | 退回草稿状态，需重新提交审批 |

### 4.7 导出

| 功能 | 说明 |
|------|------|
| 全量导出 | 导出所有价目表（含明细），生成 Excel 文件 |
| 选择导出 | 勾选指定价目表后导出，仅导出选中部分 |

导出字段：价目表编号、价目表名称、物料编号、物料名称、工序编号、工序名称、物料分类、设备编号、设备名称、人员编号、人员名称、自定义项、合格品计件单价、次品计件单价、图号、版本、规格、材质、审批状态

### 4.8 导入

1. 选择 Excel 文件（.xlsx / .xls）
2. 解析后自动创建新价目表（状态为"草稿"）
3. Excel 模板列：物料编号、物料名称、工序编号、工序名称、物料分类、设备编号、设备名称、人员编号、人员名称、自定义项、合格品计件单价、次品计件单价、图号、版本、规格、材质
4. 导入成功返回创建的价目表编号和导入行数

## 5. 定价匹配规则

计件工资计算时，系统按以下优先级匹配单价：

1. **精确匹配**：物料编号 + 工序编号 + 人员编号（员工专属定价优先）
2. **通用匹配**：物料编号 + 工序编号（人员编号为空的通用行）
3. **日期校验**：报工日期须在价目表的 effective_date ~ expiration_date 范围内
4. **状态校验**：仅"已审批"状态的价目表参与匹配

## 6. 与其他模块的关系

| 关联模块 | 关系 | 说明 |
|---------|------|------|
| 计件工资 | 消费方 | 按报工记录匹配价目表，自动计算行工资 |
| 生产报工 | 数据源 | 提供工人产出数据（物料+工序+合格/次品数量+报工日期） |
| 物料主数据 | 基础数据 | 明细行物料下拉选择，自动填充名称/分类/规格 |
| 工序 | 基础数据 | 明细行工序下拉选择，自动填充工序名称 |
| 设备管理 | 基础数据 | 明细行设备下拉选择（可选），支持按设备差异化定价 |
| 员工管理 | 基础数据 | 明细行人员下拉选择（可选），支持员工专属定价覆盖 |
| 审批系统 | 流程控制 | 提交/审核/撤回/反审批的统一审批服务 |

---

## 7. 编号规则

格式：`PR-YYYYMMDD-###`

- `PR-` 前缀
- `YYYYMMDD` 创建日期
- `###` 当日序号（3位，从001开始递增）

示例：`PR-20260514-001`、`PR-20260514-002`
