## 📋 项目概述

委外全流程管理模块实现了从委外发料、委外收回、委外质检到委外结算的完整业务流程，覆盖委外加工的全生命周期管理。

### 核心业务流程

```
生产单 → 工序任务 
  ↓
委外申请 ✅ (已有)
  ↓
委外订单 ✅ (已有)
  ↓
委外发料 ✅ (新建) → 扣减线边仓库存
  ↓
供应商加工
  ↓
委外收回 ✅ (新建) → 自动触发质检
  ↓
委外质检 ✅ (新建) → 合格品入库
  ↓
委外结算 ✅ (新建) → 付款完成订单
```

**功能清单：**
- ✅ 结算单 CRUD
- ✅ 自动计算金额（总金额、税额、含税金额）
- ✅ 结算单审核

- 仅合格品计费（不合格不计费）

- 自动计算：税额 = 总金额 × 税率
- 自动计算：含税金额 = 总金额 + 税额
- 付款完成后自动更新订单为"已完成"

**技术实现：**
- 支持分批付款，自动判断付款状态
- 付款完成后自动回写订单结算状态

## 🔑 关键技术特性

### 1. 事务一致性

所有涉及库存的操作都使用数据库事务，确保数据一致性：

```typescript
const transaction = await sequelize.transaction();
try {
  // 扣减库存
  await sequelize.query(`UPDATE inventory SET quantity = quantity - :qty`, { transaction });
  
  // 更新发料单状态
  await sequelize.query(`UPDATE outsourcing_material_issue SET status = N'已发料'`, { transaction });
  
  // 更新订单状态
  await sequelize.query(`UPDATE outsourcing_order SET issued_quantity = :qty`, { transaction });
  
  await transaction.commit();
} catch (e) {
  await transaction.rollback();
  throw e;
}
```

### 2. 状态自动回写

子单据操作后自动更新主订单状态：

- **发料确认后** → 更新 `issued_quantity` 和 `issue_status`
- **收回审核后** → 更新 `received_quantity` 和 `receipt_status`
- **质检完成后** → 更新 `qualified_quantity`
- **付款完成后** → 更新 `settlement_quantity` 和 `settlement_status`

### 3. 库存联动

- **发料** → 扣减线边仓库存
- **质检合格** → 增加成品仓库存

### 4. 自动触发

- **收回审核** → 自动创建质检单
- **付款完成** → 自动标记订单为"已完成"

### 5. 文档编号

使用统一的编号生成服务：

- 发料单：`OMI-20260429-001`
- 收回单：`ORC-20260429-001`
- 质检单：`OQI-20260429-001`
- 结算单：`OST-20260429-001`
