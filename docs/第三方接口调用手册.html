第一章 接入准备

1.1 获取 API 密钥

在对接 MES Open API 之前，需要向 MES 系统管理员申请 API 密钥。申请时请提供以下信息：

  • 密钥名称：标识用途（如 "ERP系统对接"）
  • 客户端名称：贵方系统/公司名称
  • 需要的权限：需要访问哪些模块的读/写权限
  • 贵方服务器IP：用于配置IP白名单（可选但推荐）
  • 期望频率限制：每分钟请求数量（默认100）

管理员审核通过后，您将收到一个 sk- 开头的密钥字符串。

请务必妥善保管密钥，不要将密钥提交到公开代码仓库（如 GitHub）。如果密钥泄露，请立即联系MES管理员处理。

1.2 环境信息

项目说明
API基础地址http(s)://mes.company.com/api/v1/open
认证方式请求头 X-API-Key: sk-xxxx
数据格式JSON（Content-Type: application/json）
字符编码UTF-8
速率限制默认100次/分钟，超限返回429

1.3 认证方式

所有 Open API 请求必须在 HTTP 请求头中携带 API 密钥：

X-API-Key: sk-a4f92352a2126695318836e026a78f8e1027fa439f96e1c9
密钥必须通过请求头传递，不要将密钥放在 URL 参数中，避免被日志记录泄露。

1.4 通用响应格式

所有接口响应均为 JSON 格式：

// 成功响应
{
  "success": true,
  "message": "操作成功",
  "data": { ... }
}

// 失败响应
{
  "success": false,
  "message": "错误描述"
}

1.5 分页格式

列表接口统一使用分页，返回格式：

{
  "success": true,
  "data": {
    "items": [ ... ],
    "pagination": {
      "total": 150,
      "page": 1,
      "limit": 20,
      "totalPages": 8
    }
  }
}

分页参数通过 Query String 传递：?page=1&limit=20，limit 最大值为 100。

第二章 生产工单接口

2.1 查询工单列表

GET/api/v1/open/orders权限：order:read

请求参数

参数类型必填说明
pageint否页码，默认1
limitint否每页条数，默认20，最大100
searchstring否搜索关键词（匹配工单号/生产号/产品编号/产品名称）
plan_statusstring否计划状态筛选
production_datestring否生产日期筛选（YYYY-MM-DD）

请求示例

curl -X GET "http://mes.company.com/api/v1/open/orders?page=1&limit=10&search=110103" \
  -H "X-API-Key: sk-your-api-key"

响应示例

{
  "success": true,
  "message": "获取工单列表成功",
  "data": {
    "items": [
      {
        "production_order_number": "PO20260508001",
        "production_number": "",
        "item_number": "110103",
        "item_name": "油封",
        "basic_unit": "PCS",
        "specifications": "",
        "planned_quantity": 1000,
        "production_date": "2026-05-08",
        "plan_status": "待执行",
        "completion_status": "",
        "approval_status": "草稿",
        "remark": ""
      }
    ],
    "pagination": { "total": 1, "page": 1, "limit": 10, "totalPages": 1 }
  }
}

2.2 查询工单详情

GET/api/v1/open/orders/:id权限：order:read

其中 :id 为生产工单编号（production_order_number）。

请求示例

curl -X GET "http://mes.company.com/api/v1/open/orders/PO20260508001" \
  -H "X-API-Key: sk-your-api-key"

2.3 创建工单

POST/api/v1/open/orders权限：order:write

请求体

字段类型必填说明
item_numberstring必填产品编号
item_namestring否产品名称
planned_quantitynumber否计划数量
basic_unitstring否基本单位
specificationsstring否规格
equipment_numberstring否设备编号
mould_numberstring否模具编号
planned_completion_timestring否计划完成时间
plan_statusstring否计划状态，默认"待执行"
remarkstring否备注

请求示例

curl -X POST "http://mes.company.com/api/v1/open/orders" \
  -H "X-API-Key: sk-your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "item_number": "110103",
    "item_name": "油封",
    "planned_quantity": 500,
    "basic_unit": "PCS",
    "plan_status": "待执行"
  }'

响应示例

{
  "success": true,
  "message": "创建工单成功",
  "data": {
    "production_order_number": "PO20260508002"
  }
}
工单编号由系统自动生成，格式为 PO + 日期 + 三位序号，如 PO20260508002。创建后默认为"草稿"审批状态。

2.4 更新工单

PUT/api/v1/open/orders/:id权限：order:write
仅"草稿"状态的工单可以更新。已提交审批或已审批的工单不允许修改。
curl -X PUT "http://mes.company.com/api/v1/open/orders/PO20260508002" \
  -H "X-API-Key: sk-your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "planned_quantity": 800,
    "remark": "调整计划数量"
  }'

第六章 错误处理

6.1 HTTP 状态码一览

状态码含义触发原因处理建议
200成功请求正常处理—
400请求参数错误缺少必填字段、数据格式错误检查请求体和参数格式
401未认证缺少X-API-Key头、密钥无效/过期/已禁用检查密钥是否正确、是否过期
403权限不足密钥没有对应模块的读/写权限、IP不在白名单联系管理员开通权限或添加IP白名单
404资源不存在查询的编号不存在检查编号是否正确
429请求频率超限每分钟请求数超过限制降低请求频率或联系管理员提高限制
500服务器错误服务端异常联系MES管理员排查

6.2 错误响应格式

{
  "success": false,
  "message": "缺少API密钥，请在请求头 X-API-Key 中提供"
}

6.3 重试策略

建议对可重试的错误实现指数退避策略：

错误类型是否重试策略
400 参数错误否修正请求参数后重试
401 认证失败否检查密钥配置
403 权限不足否联系管理员
404 资源不存在否确认编号正确
429 频率超限是等待60秒后重试，逐步增加等待时间
500 服务器错误是等待5秒后重试，最多3次
网络超时是等待5秒后重试，最多3次

第七章 完整代码示例

7.1 Python 对接示例

import requests
import time

class MesApiClient:
    """Seals MES Open API 客户端"""

    def __init__(self, base_url: str, api_key: str):
        self.base_url = base_url.rstrip('/')
        self.headers = {
            'X-API-Key': api_key,
            'Content-Type': 'application/json'
        }

    def _request(self, method: str, path: str, **kwargs):
        url = f"{self.base_url}{path}"
        resp = requests.request(method, url, headers=self.headers, **kwargs)
        data = resp.json()
        if not data.get('success'):
            raise Exception(f"API错误: {data.get('message', '未知错误')}")
        return data.get('data')

    # ---- 生产工单 ----
    def get_orders(self, page=1, limit=20, search=None, plan_status=None):
        params = {'page': page, 'limit': limit}
        if search: params['search'] = search
        if plan_status: params['plan_status'] = plan_status
        return self._request('GET', '/api/v1/open/orders', params=params)

    def get_order(self, order_number: str):
        return self._request('GET', f'/api/v1/open/orders/{order_number}')

    def create_order(self, **data):
        return self._request('POST', '/api/v1/open/orders', json=data)

    def update_order(self, order_number: str, **data):
        return self._request('PUT', f'/api/v1/open/orders/{order_number}', json=data)

    # ---- 工序报工 ----
    def get_work_reports(self, page=1, limit=20, production_order_number=None):
        params = {'page': page, 'limit': limit}
        if production_order_number:
            params['production_order_number'] = production_order_number
        return self._request('GET', '/api/v1/open/work-reports', params=params)

    def get_work_report(self, report_number: str):
        return self._request('GET', f'/api/v1/open/work-reports/{report_number}')

    def create_work_report(self, **data):
        return self._request('POST', '/api/v1/open/work-reports', json=data)

    # ---- 按工序备料 ----
    def get_preparations(self, page=1, limit=20, production_order_number=None):
        params = {'page': page, 'limit': limit}
        if production_order_number:
            params['production_order_number'] = production_order_number
        return self._request('GET', '/api/v1/open/material-preparations', params=params)

    def get_preparation_details(self, prep_number: str):
        return self._request('GET', f'/api/v1/open/material-preparations/{prep_number}/details')

    def generate_preparation(self, production_order_number: str):
        return self._request('POST', '/api/v1/open/material-preparations/generate-by-process',
                             json={'production_order_number': production_order_number})

    # ---- 设计BOM ----
    def get_bom_list(self, page=1, limit=20, search=None):
        params = {'page': page, 'limit': limit}
        if search: params['search'] = search
        return self._request('GET', '/api/v1/open/bom', params=params)

    def get_bom_detail(self, bom_number: str):
        return self._request('GET', f'/api/v1/open/bom/{bom_number}')

    def get_bom_tree(self, bom_number: str):
        return self._request('GET', f'/api/v1/open/bom/{bom_number}/tree')

    def get_bom_flatten(self, bom_number: str):
        return self._request('GET', f'/api/v1/open/bom/{bom_number}/flatten')


# 使用示例
if __name__ == '__main__':
    client = MesApiClient(
        base_url='http://mes.company.com',
        api_key='sk-your-api-key-here'
    )

    # 查询工单
    orders = client.get_orders(search='110103')
    print(f"工单数量: {orders['pagination']['total']}")

    # 查询BOM树
    tree = client.get_bom_tree('110103')
    print(f"BOM: {tree['header']['item_name']}")

    # 创建报工
    report = client.create_work_report(
        production_order_number='PO20260508001',
        step_number=10,
        standard_process_name='硫化',
        qualified_quantity=480,
        operator_name='张三'
    )
    print(f"报工编号: {report['work_report_number']}")

public class MesApiClient
{
    private readonly HttpClient _http;
    private readonly string _baseUrl;

    public MesApiClient(string baseUrl, string apiKey)
    {
        _baseUrl = baseUrl.TrimEnd('/');
        _http = new HttpClient();
        _http.DefaultRequestHeaders.Add("X-API-Key", apiKey);
        _http.DefaultRequestHeaders.Accept.Add(
            new MediaTypeWithQualityHeaderValue("application/json"));
    }

    public async Task<JsonElement> GetAsync(string path, Dictionary<string,string>? queryParams = null)
    {
        var url = $"{_baseUrl}{path}";
        if (queryParams != null && queryParams.Count > 0)
        {
            var qs = string.Join("&", queryParams.Select(kv => $"{kv.Key}={kv.Value}"));
            url += $"?{qs}";
        }
        var resp = await _http.GetAsync(url);
        var json = JsonDocument.Parse(await resp.Content.ReadAsStringAsync());
        return json.RootElement;
    }

    public async Task<JsonElement> PostAsync(string path, object data)
    {
        var content = new StringContent(
            JsonSerializer.Serialize(data), Encoding.UTF8, "application/json");
        var resp = await _http.PostAsync($"{_baseUrl}{path}", content);
        var json = JsonDocument.Parse(await resp.Content.ReadAsStringAsync());
        return json.RootElement;
    }

    // 使用示例
    public async Task Example()
    {
        // 查询工单列表
        var orders = await GetAsync("/api/v1/open/orders",
            new Dictionary<string,string> { {"page","1"}, {"limit","10"} });

        // 查询BOM树
        var tree = await GetAsync("/api/v1/open/bom/110103/tree");

        // 创建报工
        var report = await PostAsync("/api/v1/open/work-reports", new {
            production_order_number = "PO20260508001",
            step_number = 10,
            qualified_quantity = 480,
            operator_name = "张三"
        });
    }
