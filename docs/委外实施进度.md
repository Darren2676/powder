## 🎯 关键技术要点

### 事务一致性
所有涉及库存操作的功能必须使用数据库事务：
```typescript
const transaction = await sequelize.transaction();
try {
  // 数据库操作
  await transaction.commit();
} catch (e) {
  await transaction.rollback();
  throw e;
}
```

### 状态回写
委外订单的状态需要根据子单据自动更新：
- 发料后更新 `issued_quantity` 和 `issue_status`
- 收回后更新 `received_quantity` 和 `receipt_status`
- 质检后更新 `qualified_quantity`
- 结算后更新 `settlement_quantity` 和 `settlement_status`

### 库存联动
- 发料确认：扣减线边仓库存
- 收回入库：增加成品仓库存
- 必须保证库存数量 >= 0
