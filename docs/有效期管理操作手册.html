一、有效期管理概述

1.1 功能定位

有效期管理是 Seals MES System 中贯穿基础数据 → 采购入库 → 生产入库 → 库存管理 → 报告预警的全链路功能。系统通过物料主数据中设置的启用有效期和有效天数，结合入库时录入的生产日期，自动计算到期日，并在有效期管理报告中按已到期 / 即将到期（30天内）/ 未到期三种状态分类展示。

1.2 核心计算规则

计算项规则说明
到期日生产日期 + 有效天数（优先）有生产日期时使用生产日期计算
到期日（回退）入库日期 + 有效天数无生产日期时回退使用入库日期
已到期到期日 < 今天■ 红色标记
即将到期到期日 - 30天 ≤ 今天 < 到期日■ 橙色标记
未到期到期日 - 30天 > 今天■ 绿色标记
提示：即将到期预警天数固定为 30天，当前不可配置。

1.3 涉及的数据表

表名有效期相关字段用途
item_masterenable_shelf_life (Y/N)、shelf_life_days物料有效期基础设置
stock_in_detailproduction_date采购入库明细生产日期
material_batch_inventoryproduction_date、inbound_date原材料/半成品批次库存
finished_batch_inventoryproduction_date、inbound_date成品批次库存
semi_production_inbound_order_detailproduction_date半成品生产入库明细

二、基础数据设置 — 物料有效期配置

2.1 操作入口

路径：基础数据 → 物料主数据 → 创建/编辑物料

在物料主数据的创建/编辑表单中，找到 "库存基础" 折叠面板，其中包含有效期相关字段：

2.2 字段说明

字段名类型默认值说明
启用有效期下拉选择（是/否）否设为"是"后，该物料将纳入有效期管理报告统计范围
有效天数数字输入0仅当启用有效期=是时显示；输入正整数天数
操作步骤：
① 进入物料主数据列表页 → 点击"创建"或某条记录的"编辑"
② 展开 "库存基础" 折叠面板
③ 将 "启用有效期" 下拉框选为 "是"
④ 在 "有效天数" 输入框中输入天数（如 90、180、365）
⑤ 填写其他必填字段后，点击保存/提交审批
注意：只有 enable_shelf_life = 'Y' 的物料才会出现在有效期管理报告中。未启用有效期的物料即使有批次库存也不会被统计。

2.3 配置示例

物料类型物料编号启用有效期有效天数说明
原材料RM-NBR-001是180丁腈橡胶，保质期6个月
半成品SF-SL-001是90混炼胶半成品，保质期3个月
成品FG-OR-001是365O型密封圈成品，保质期1年
原材料RM-STEEL-001否0金属骨架，无有效期要求

三、采购入库 — 生产日期录入

3.1 操作入口

路径：采购管理 → 收货通知 → 确认收货

3.2 生产日期录入方式

在确认收货弹窗中，提供两种生产日期录入方式：

方式操作适用场景
批量设置在弹窗顶部"批量设置生产日期"日期选择器中选取日期，所有明细行自动填充同一批次物料生产日期相同
逐行设置在明细表格的"生产日期"列逐行点击日期选择器不同物料生产日期不同
操作步骤：
① 在收货通知列表页，点击某条记录的 "确认收货" 按钮
② 在弹出窗口中，先选择 "批量设置仓库"（下拉选择目标仓库）
③ 选择 "批量设置生产日期"（日期选择器），或逐行设置
④ 核对合格数量/不合格数量
⑤ 点击 "确认入库" 按钮提交

3.3 数据流转

收货通知确认 → stock_in_detail.production_date → confirmStockIn → material_batch_inventory.production_date → 有效期管理报告
技术说明：确认收货时，系统将 line_production_dates 按物料编号映射传递到后端，写入 stock_in_detail.production_date。后续执行 confirmStockIn 时，从 stock_in_detail 读取 production_date，同步写入 material_batch_inventory.production_date。
重要：如果确认收货时未填写生产日期，该批次在有效期管理报告中将回退使用 入库日期 计算到期日，可能导致到期日不准确。

四、生产入库 — 半成品/成品生产日期

4.1 半成品生产入库

路径：仓储管理 → 材料仓 → 生产入库（半成品入库）

半成品生产完工后，通过生产入库功能将半成品纳入库存。入库时可填写生产日期（通常为生产完工日期）。

操作步骤：
① 进入材料仓 → 半成品待入库列表
② 勾选待入库的生产单行项
③ 选择目标仓库
④ （可选）填写生产日期
⑤ 点击"确认入库"

4.2 成品入库

路径：仓储管理 → 成品仓 → 入库

成品入库时，生产日期随成品入库单录入，写入 finished_batch_inventory.production_date。

4.3 数据流转

生产完工 → 生产入库单 (production_date) → material_batch_inventory / finished_batch_inventory → 有效期管理报告

五、其他出入库操作中的有效期管理

5.1 原材料手工入库

路径：仓储管理 → 材料仓 → 入库

原材料手工入库时，支持逐行填写生产日期字段。该日期将写入 material_batch_inventory.production_date。

提示：手工入库适用于非采购流程的物料入库场景（如盘点盈余、赠送样品等），同样需要填写生产日期以确保有效期计算准确。

5.2 成品/原材料出库

出库操作（材料出库、成品出库、退货出库等）不涉及生产日期的录入或修改。出库时系统按 FIFO（先进先出）规则选择批次，自动扣减对应批次的库存数量。

5.3 库存查询中的生产日期

路径：仓储管理 → 成品仓 → 库存查询

在库存查询页面，点击某条库存记录的"批次明细"，弹出窗口中会显示每个批次的生产日期字段：

  • 对于原材料/半成品：显示 material_batch_inventory.production_date
  • 对于成品：显示 finished_batch_inventory.production_date
注意：如果某批次入库时未填写生产日期，批次明细中该字段显示为 "-"。

5.4 涉及生产日期的操作汇总

操作类型路径是否录入生产日期写入目标表
采购收货确认采购管理 → 收货通知 → 确认收货✅ 是stock_in_detail → material_batch_inventory
原材料手工入库仓储管理 → 材料仓 → 入库✅ 是material_batch_inventory
半成品生产入库仓储管理 → 材料仓 → 生产入库✅ 是material_batch_inventory
成品入库仓储管理 → 成品仓 → 入库✅ 是finished_batch_inventory
材料出库仓储管理 → 材料仓 → 出库❌ 否—（仅扣减数量）
成品出库仓储管理 → 成品仓 → 出库❌ 否—（仅扣减数量）
退货出库仓储管理 → 材料仓 → 退货出库❌ 否—（仅扣减数量）
盘点仓储管理 → 盘点❌ 否—（仅调整数量）

六、有效期管理报告

6.1 操作入口

路径：仓储管理 → 有效期管理报告

报告页面包含以下筛选器和数据列：

筛选器

6.3 操作说明

查看全部有效期报告：
① 进入"仓储管理 → 有效期管理报告"页面
② 页面默认加载所有启用有效期物料且库存>0的批次
③ 通过筛选器按仓库/物料类型/到期状态缩小范围
④ 在搜索框中输入物料编号或名称进行精确查找
⑤ 点击"查询"按钮刷新数据
⑥ 点击"重置"按钮清空所有筛选条件
查看即将到期的物料：
① 在"到期状态"下拉框中选择 "即将到期"
② 系统显示所有距到期日≤30天的批次
③ 橙色标记表示需要优先处理
查看已到期的物料：
① 在"到期状态"下拉框中选择 "已到期"
② 系统显示所有到期日已过期的批次
③ 红色标记表示需要立即处置

6.4 数据来源

报告通过 UNION ALL 查询合并两类数据源：

数据源表JOIN条件覆盖类型
原材料+半成品material_batch_inventoryJOIN item_master ON item_number原材料、半成品
成品finished_batch_inventoryJOIN item_master ON item_number成品
筛选逻辑：报告仅展示 item_master.enable_shelf_life = 'Y' 且 batch.quantity > 0 的批次记录。

6.5 到期状态判定逻辑

-- 到期日计算（优先使用生产日期）
CASE WHEN production_date IS NOT NULL
  THEN DATEADD(DAY, shelf_life_days, production_date)
  ELSE DATEADD(DAY, shelf_life_days, inbound_date)
END AS expiry_date

-- 到期状态判定
CASE
  WHEN expiry_date < GETDATE()                         THEN '已到期'
  WHEN DATEADD(DAY, -30, expiry_date) < GETDATE()      THEN '即将到期'
  ELSE                                                      '未到期'
END AS expire_status

七、有效期管理数据流全景

基础数据层

物料主数据：enable_shelf_life=Y, shelf_life_days=90

入库操作层（录入生产日期）

业务场景操作生产日期来源写入表
采购入库收货通知 → 确认收货确认弹窗手动选择stock_in_detail → material_batch_inventory
原材料手工入库材料仓 → 入库入库表单手动填写material_batch_inventory
半成品生产入库材料仓 → 生产入库入库表单手动填写material_batch_inventory
成品入库成品仓 → 入库入库表单手动填写finished_batch_inventory

报告展示层

有效期管理报告 = material_batch_inventory + finished_batch_inventory（JOIN item_master）

计算公式

到期日 = production_date(优先) 或 inbound_date(回退) + shelf_life_days → 到期状态 = 已到期 / 即将到期(≤30天) / 未到期

八、完整操作流程示例

8.1 场景：采购一批橡胶原料并跟踪有效期

第一步：设置物料有效期（基础数据）
进入"基础数据 → 物料主数据"，编辑物料 RM-NBR-001：
• 启用有效期：是
• 有效天数：180
• 保存并提交审批
第二步：采购收货并录入生产日期（采购管理）
① 创建采购订单 → 生成收货通知
② 在收货通知列表页，点击"确认收货"
③ 在弹窗中选择目标仓库（如：原材料仓-04）
④ 批量设置生产日期：选择物料的生产日期（如：2026-05-15）
⑤ 核对合格数量后点击"确认入库"
第三步：验证库存批次（仓储管理）
① 进入"仓储管理 → 成品仓 → 库存查询"
② 搜索物料 RM-NBR-001
③ 点击"批次明细"查看生产日期已正确显示为 2026-05-15
第四步：查看有效期报告（仓储管理）
① 进入"仓储管理 → 有效期管理报告"
② 到期日显示为 2026-11-11（2026-05-15 + 180天）
③ 到期状态显示为"未到期"（绿色标记）
④ 随着时间推移，距到期日≤30天时自动变为"即将到期"（橙色标记）
⑤ 超过2026-11-11后变为"已到期"（红色标记）

九、常见问题与注意事项

9.1 为什么物料在报告中没有显示？

排查步骤：
① 检查物料主数据中 "启用有效期" 是否设为 "是"
② 检查 "有效天数" 是否大于 0
③ 检查该物料是否有库存（quantity > 0）
④ 检查物料审批状态是否为"已审核"

9.2 为什么到期日不准确？

排查步骤：
① 确认入库时是否填写了生产日期（若未填写，系统回退使用入库日期计算）
② 确认物料主数据中的有效天数是否正确
③ 注意：入库日期 ≠ 生产日期，两者可能相差较大

9.3 如何修正已入库批次的生产日期？

注意：当前系统不支持在前端直接修改已入库批次的生产日期。如需修正，请联系系统管理员通过数据库直接更新 material_batch_inventory.production_date 或 finished_batch_inventory.production_date 字段。

9.4 出库时如何选择批次？

系统按 FIFO（先进先出）规则自动选择批次出库。出库操作不涉及生产日期的修改，也不支持按有效期手动选择批次。

9.5 半成品在报告中属于什么类型？

半成品的批次库存存储在 material_batch_inventory 表中（item_type = '半成品'），在有效期管理报告的第一部分（与原材料 UNION 查询）中展示。筛选时选择"半成品"类型即可过滤。
