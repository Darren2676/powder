塑粉工艺参数管理功能 — 开发工作量评估

Seals MES System  |  2026年5月

一、功能概述

业务描述：管理塑粉工艺生产过程中的参数标准，包含三大子模块——工艺参数（主从结构，定义产品/工序级参数标准值与范围）、塑粉参数（单表，定义塑粉检测参数字典）、工艺分类（单表，对工艺参数按分类维度归组）。三者通过编码关联，形成完整的塑粉工艺参数体系。

1.1 模块关系

工艺分类 (plastic_process_category)
    │ category_code
    ▼
工艺参数明细 (process_parameter_detail)
    │ param_code ──── 塑粉参数 (plastic_powder_parameter)
    ▼                   │ param_code 自动填充 param_name / unit
工艺参数主表 (process_parameter_header)
    │ item_number ──── 物料主数据
    │ process_route_number ──── 工艺路线
    ▼
生产执行时引用工艺参数标准值

1.2 三大子模块定位

子模块数据结构核心功能审批导入导出
工艺参数主从表（header + detail）CRUD + 按产品/路线查询 + 12个API✅ 简单审批/撤审✅ 导出(每参数一Sheet) + 下载模板 + 导入(主从Excel)
塑粉参数单表CRUD + 下拉联动✅ 简单审批/撤审✅ 导出 + 导入
工艺分类单表CRUD✅ 简单审批/撤审❌

三、API 设计

七、关键影响因素

因素影响说明
主从表结构⚠️ 增耗时工艺参数为 header + detail 主从结构，创建/更新需事务内批量保存明细，比单表 CRUD 多约 2 天
多Sheet Excel导出⚠️ 增耗时工艺参数导出按每个参数生成一个 Sheet（主表信息行 + 明细数据），需 exceljs 多Sheet处理，比普通单Sheet导出多约 1 天
主从表Excel导入⚠️ 增耗时导入模板为"主表2行+空行+明细列头"结构，解析时需 sheet_to_json(range:3) 分离主表与明细，事务写入，比普通导入多约 1 天
3个下拉联动⚠️ 增耗时工艺参数明细页有工艺分类下拉、塑粉参数下拉（自动填充名称/单位）、单位下拉、工艺路线下拉，联动逻辑增加前端详情页复杂度约 1 天
option-label-prop显示分离⚠️ 增耗时工艺分类编码列/参数编码列使用 option-label-prop="label" + :label="code" 实现下拉展开显示"编码-名称"但选中后仅显示编码，需逐列调试约 0.3 天
简单审批而非工作流✅ 省时直接用 UPDATE approval_status 实现审批/撤审，不走工作流引擎，免去审批节点编排约 2-3 天
复用现有基础设施✅ 省时复用 useTableList/useColumnPreference/useModalDrag 组合式函数 + exceljs 工具 + documentNumber.service，减少重复编码
无移动端适配✅ 省时基础方案不含 client-mobile
